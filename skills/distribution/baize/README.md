# 白泽（Baize）

传说黄帝在东海遇见白泽。白泽通晓天下鬼神精怪，向黄帝讲述了 11,520 种精怪的名称、形态、习性及应对方法，黄帝命人把这些内容绘制、记录，形成《白泽图》。

这个 Skill 借用了同一种思路：把原本面向人浏览、散落在导航和页面中的 Wiki 知识逐一辨识、归类、记录，转换成 Agent 能快速检索和按需阅读的知识 Skill。

## 它会生成什么

- 与原 Wiki 导航层级对应的 Markdown 目录树
- 面向 Agent 的 `SKILL.md` 和全文检索脚本
- 列出全部文档、路径和来源的 `references/INDEX.md`
- 记录每篇文档 SHA-256 的 `references/wiki-manifest.json`
- 支持手动或定期同步的增量更新流程
- 自动安装到当前 Agent；目标本来就在当前 Agent Skills 目录时不重复复制

新 Skill 默认按 Wiki 的产品或知识域命名，并以 `-wiki` 结尾，例如 `qoder-wiki`。白泽先盘点完整导航，再把正文抓到临时目录；覆盖率不完整时不会把结果冒充成完整 Wiki Skill。

本地脚本只依赖 Python 3.10+ 标准库，不要求额外安装 Python 包。

## 更新语义

白泽比较的是规范化后的 Markdown 内容，而不是抓取时间。没有变化时，正文、索引和 JSON 清单都不会被重写。上游删页或改路径属于可能丢失内容的变更，默认停止；获得授权后才会把旧文件移入可恢复归档。

## 边界

- 只处理公开资料或用户有权访问的 Wiki，不绕过登录、付费墙或访问控制。
- 公开网页不自动等于可公开再分发；许可证不清楚时只做本地私有 Skill。
- 单篇网页摘要、普通文章解读不应触发白泽。
- 自动更新只在用户明确提出后配置，不会默默创建后台任务。
