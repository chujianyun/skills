# 共享Ontology

共享Ontology是一种特殊类型的Ontology，允许多个[组织](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#organizations)在共享的工作流上进行协作。共享Ontology位于专门为工作流创建的专用共享[空间](https://www.palantir.com/docs/foundry/security/orgs-and-spaces/#spaces)下。共享Ontology使多个组织的资源可以在工作流中使用，而一个Ontology仅对一个组织私有，并且只包含该组织的资源。

当创建一个新的共享空间时，会自动创建一个共享Ontology。它拥有与共享空间相同的组织[权限标记](https://www.palantir.com/docs/foundry/security/markings/)和[角色授予](https://www.palantir.com/docs/foundry/security/projects-and-roles/#roles)。

有关如何设置安全协作工作流的更多详细信息，请参见[跨组织协作](https://www.palantir.com/docs/foundry/security/cross-organization-collaboration/)。
