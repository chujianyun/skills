# 将地图模板添加到Marketplace产品 \[Beta]

使用[Foundry DevOps](https://www.palantir.com/docs/foundry/devops/overview/)将您的[地图模板](Templates%20%26%20Workshop%20widget/%E5%9C%B0%E5%9B%BE%E6%A8%A1%E6%9D%BF.md)包含在[Marketplace产品](https://www.palantir.com/docs/foundry/devops/core-concepts/#product)中，以便其他用户安装和重用。[了解如何创建您的第一个产品。](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)

## 支持的功能

所有地图模板功能均受支持，唯[地图图层](Integrate%20data%20for%20the%20map/%E5%9C%B0%E5%9B%BE%E5%9B%BE%E5%B1%82%E7%BC%96%E8%BE%91%E5%99%A8.md)除外。

## 将地图模板添加到产品中

要将地图模板添加到产品中，首先[创建一个产品](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)，然后选择如下所示的**地图模板**内容类型。
