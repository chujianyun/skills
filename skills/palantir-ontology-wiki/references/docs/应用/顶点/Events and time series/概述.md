# 概述

Vertex 包含一套功能，旨在帮助您了解您的组织如何随时间变化。这对于分析过去的事件和预测未来的事件特别有帮助，尤其是结合 Vertex 对[情景](../Scenarios/%E6%A6%82%E8%A7%88.md)的支持。

您应该熟悉两种主要的时间数据类型：**事件**和**时间序列**。

* 事件是本体中配置的[Object类型](../../../%E5%AE%9A%E4%B9%89%E6%9C%AC%E4%BD%93/%E5%AF%B9%E8%B1%A1%E9%93%BE%E6%8E%A5%E7%B1%BB%E5%9E%8B/Object%20types/%E6%A6%82%E8%A7%88.md)，包含时间信息——至少两个时间戳，表示事件的开始和结束。
* [时间序列](https://www.palantir.com/docs/foundry/time-series/time-series-overview/)表示随时间测量的值，可以在本体中配置为[时间序列属性](https://www.palantir.com/docs/foundry/time-series/time-series-setup/)。

通过学习如何[配置事件](%E9%85%8D%E7%BD%AE%E4%BA%8B%E4%BB%B6.md)来开始，然后了解如何在 Vertex 中使用事件和时间序列：

* [探索相关时间序列](%E6%8E%A2%E7%B4%A2%E7%9B%B8%E5%85%B3%E6%97%B6%E9%97%B4%E5%BA%8F%E5%88%97.md)
