# 部署 Foundry Rules

:::callout{theme="neutral"}
Foundry Rules 的预计总部署时间约为 30 分钟。
:::

部署 Foundry Rules 涉及到部署每个[组件](../Core%20concepts/%E6%A6%82%E8%BF%B0.md)，特别是 Workshop 应用、支持的 Objects 和操作，以及 Foundry Rules 工作流配置。这是通过首先部署模板，然后配置工作流，最后编写和运行规则来完成的。以下文档中描述了这些步骤：

1. [部署工作流模板：](%E9%83%A8%E7%BD%B2%E5%B7%A5%E4%BD%9C%E6%B5%81.md) <em class="bp3-text-muted"> 预计时间 ~ 3 分钟</em>
2. [配置工作流：](%E9%85%8D%E7%BD%AE%E5%B7%A5%E4%BD%9C%E6%B5%81.md) <em class="bp3-text-muted"> 预计时间 ~ 10 分钟</em>
3. [编写并运行规则：](%E7%BC%96%E5%86%99%E5%B9%B6%E8%BF%90%E8%A1%8C%E8%A7%84%E5%88%99.md) <em class="bp3-text-muted"> 预计时间 ~ 10 分钟</em>

如果在部署过程中遇到任何问题，请查看[故障排除参考](../%E6%95%85%E9%9A%9C%E6%8E%92%E9%99%A4%E5%8F%82%E8%80%83.md)页面。

有关如何修改 Foundry Rules 产品的信息（例如，启用非必填功能、添加自定义属性或更改编辑权限），请查看[自定义 Foundry Rules](../Settings%20%26%20customization/%E5%AE%9A%E5%88%B6%20Foundry%20Rules.md)页面。

:::callout{theme="neutral"}
在 2022 年 7 月之前，Foundry Rules（之前称为 Taurus）需要更多配置，包括用户编写的变换。如果您在此日期之前部署了 Foundry Rules，请了解更多关于这些[配置和概念](../Legacy%20Foundry%20Rules%20Setup%20%28Taurus%29/%E6%97%A7%E7%89%88%20Foundry%20%E8%A7%84%E5%88%99%E8%AE%BE%E7%BD%AE%20%28Taurus%29.md)的信息。
:::
