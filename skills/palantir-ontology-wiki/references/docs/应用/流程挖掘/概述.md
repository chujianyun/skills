# 概述

许多现实世界的事件可以被视为流程，例如业务流程、政府操作、医疗程序等等。在流程中，文档、设备或个人等实体随着时间的推移而经历状态的更改。机械工具可以帮助您理解和管理流程的各个方面，识别不需要的行为，并朝着预期结果进行改进。支持的工作流包括：

* 从日志中挖掘正在进行的流程
* 在Foundry中实现流程
* 在图表上可视化状态、转换和操作的流动
* 定义和监控性能指标和期望，以识别瓶颈
* 将您的流程自定义视图纳入运营应用程序
* 通过AIP自动化重复步骤并优化任务

## 应用案例

大多数产生事件日志数据的流程都可以通过流程挖掘进行分析和优化。Machinery的示例应用案例和工作流包括：

* **采购到付款**（采购、财务）：简化从申请到付款的采购流程，以提高效率并降低成本。
* **订单到现金**（销售、财务）：优化从订单接收到付款收取的销售流程，提高客户满意度和现金流。
* **应付账款**（财务）：分析和改进发票处理和支付活动，以减少出错并优化现金管理。
* **应收账款**（财务）：增强发票开具和付款收取流程，以减少应收账款天数（DSO）并改善现金流。
* **客户服务**（客服支持）：识别和解决客户服务流程中的低效之处，以改善解决时间和客户满意度。
* **库存管理**（供应链、物流）：分析和优化库存水平和补货流程，以减少缺货和降低持有成本。
* **生产计划**（制造）：简化生产流程和资源分配，以减少交货时间并提高制造效率。
* **员工入职**（人力资源）：评估和优化员工入职流程，以缩短生产力时间并改善员工体验。
* **索赔处理**（保险）：捕捉保险索赔从初始提交到最终决策的流程，包括相关文档的OCR、半自动化处理和人工批准。
