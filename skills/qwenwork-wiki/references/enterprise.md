# 企业管理、API 与订阅

资料核对：2026-09-16。先区分个人空间、企业标准版、企业旗舰版和当前角色。

## 企业标准版

管理员从账号菜单进入企业后台，主要处理成员、积分、组织设置和 SSO。加入组织不等于已获坐席，未分配坐席的成员不能使用组织积分。邀请链接通常需审批，邮箱邀请采用另一流程；邀请、审批和分配坐席应分步核对。

来源：[企业管理后台](https://qwenwork.cn/docs/enterprise/admin)。

## 积分与限额

余额是实际资源，限额是使用上限；调高限额不会充值。文档有组织、团队与成员层级，成员限额不能超过上级。降低组织上限前先检查下级设置，批量调整先确认筛选范围和预览人数。具体最低额度属于易变信息，操作时查看页面。

来源：[积分管理](https://qwenwork.cn/docs/enterprise/credits)。

## 企业旗舰版

先核对企业及客户端服务地址，再配置用户来源、身份认证、席位、模型与 AI 资产，最后用普通成员验证登录和资源可见性。开启通讯录同步后，部分成员增删需要在来源系统进行。找不到菜单先查管理员角色和开通能力。

用户同步、SSO、可信设备、Hooks、模型策略、日志审计等详细配置已收入官方索引；本地没有这些页面的完整操作说明，涉及具体配置须读取对应原页。

来源：[旗舰版管理指南](https://qwenwork.cn/docs/enterprise/flagship)。

## 企业管理 API

这是管理后台服务端接口，不是模型推理 API。创建应用并授予独立 Scope，再用该应用 API Key 做 Bearer 认证。组织身份由服务端依据应用凭据确定，不信任请求中自行填写的组织标识。

部分写接口要求 `Idempotency-Key`；重试须沿用相同键与请求内容。通过响应头 `X-Request-Id` 排查；401 先查凭据，403 查 Scope，参数错误先修正，只有明确可重试错误才有限退避重试。精确 Method、Path、字段、Scope 与重试条件必须读取单接口页。目录标题只帮助定位，不能充当 Schema。

来源：[开发者接入概览](https://qwenwork.cn/docs/developer/enterprise)。

## 个人套餐与升降级

个人权益页比较免费、标准和高级档，包括积分、存储、网页和并行任务。赠送和登录奖励带有限时条件，不把它们当永久权益。回答当前价格时读取权益页及实际订单页。

来源：[个人版权益](https://qwenwork.cn/docs/benefits/personal)。

取消续订通常不立即结束已付费权益。升降级页面的概述与跨周期升级表对截止日期有不同描述，不能笼统承诺所有升级都保留截止日；按用户当前套餐、购买周期与订单确认页核对。不要代用户购买或取消，除非已有对应授权。

来源：[套餐升降级](https://qwenwork.cn/docs/benefits/plan-upgrade-downgrade)。
