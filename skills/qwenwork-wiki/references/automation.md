# 定时任务与 IM 频道

资料核对：2026-09-16。

## 网页端定时任务

任务在云端执行，关浏览器或退出登录不影响已启用计划。可通过表单、自然语言或模板创建。每次运行生成独立会话，不自动继承其他日常对话的上下文；数据来源、输出位置和发送对象应写进指令。

“立即执行”额外运行一次，不改变周期；删除任务停止后续调度，但已生成的执行记录与会话保留。结果默认留在会话，指定外发需相应连接器和授权。

来源：[网页定时任务](https://qwenwork.cn/docs/web/scheduled-tasks)。

## 桌面端定时任务

由本地客户端按系统时区调度，需要设备保持唤醒；休眠或关机错过的任务不自动补跑，可手动立即运行。可设工作目录、附件，使用已配置的技能和连接器。运行消耗 Credits，应先把任务手动跑通再设置周期。

浏览器自动化任务还依赖 Chrome 运行及有效登录状态。没有按时触发时，先查唤醒状态、时区、启用开关和执行记录，再查数据源与权限。

来源：[桌面定时任务](https://qwenwork.cn/docs/desktop/scheduled-tasks)。

## 跨端边界

Web 和桌面客户端的定时任务及会话暂不互相同步。因此“关闭浏览器仍执行”只说明网页云端调度，不能套用到桌面休眠。

来源：[常见问题](https://qwenwork.cn/docs/faq)。

## IM 频道与远程接管

文档列出钉钉、飞书、Lark、微信、企业微信、Slack、WhatsApp；具体可用类型受企业策略影响。各聊天有独立上下文，结果一般回到发起聊天；普通桌面任务默认不会自动发到 IM。

配对以会话为单位，批准群聊意味着群内成员可使用。`/bind` 列出可绑定的桌面任务，再用 `/bind <编号>` 接管；`/unbind` 恢复独立聊天。绑定后任务回复会同步到 IM，绑定前检查该任务是否含不宜分享的内容。移除配置需重新接入，临时停用可关闭开关。

来源：[IM 频道](https://qwenwork.cn/docs/desktop/im-channels)。
