# 工作台

资料核对：2026-09-16。以下为桌面端工作台专页。

## 设计

输入框选择“设计”，可指定工作目录、风格、保真度与组件库。支持直接运行，也支持先澄清并确认 Design Plan。后续可圈选局部调整，用 Nudge 修改样式参数，或查看工程文件与运行预览。默认未选组件库时采用 HTML-first，不能承诺所有输出必然为 React。

来源：[设计工作台](https://qwenwork.cn/docs/workspaces/design)。

## 幻灯片 / PPT

切换“幻灯片”后，描述受众、主题、页数和关键结论，可选模板与工作目录。先确认大纲，再按页生成。画布默认为 16:9 HTML，文档写明可导出 PPTX、PDF、HTML，也可放映或保存为模板。用户需要可编辑 PPT 时，应实际检查导出文件，不能将 HTML 预览等同于最终 PPTX。

来源：[幻灯片工作台](https://qwenwork.cn/docs/workspaces/slides)。

## 写作

切换“写作”，设定受众、语气和工作目录。正文存为 `outputs/` 下的 Markdown，可在编辑模式手改，再让 Agent 继续。界面可查看不同版本，专页说明导出 PDF。不要把其他工作台的 PPTX 或 Office 导出能力迁移到这里。

来源：[写作工作台](https://qwenwork.cn/docs/workspaces/writing)。
