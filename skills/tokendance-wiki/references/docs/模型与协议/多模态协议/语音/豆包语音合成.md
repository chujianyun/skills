# 豆包语音合成

<!-- model-detail-quickstart:start -->

这个接口通过 SSE 返回音频。请求体填写文本、音色和输出格式；客户端收到音频片段后，按顺序写入文件或播放器。

### 开始调用

:::group

```bash title="cURL"
curl -N https://tokendance.space/gateway/ark/v3/tts/unidirectional \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "X-Api-Resource-Id: MODEL_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "req_params": {
      "text": "今天天气真好，适合出门走走。",
      "speaker": "zh_female_vv_uranus_bigtts",
      "audio_params": {
        "format": "mp3",
        "sample_rate": 24000
      }
    }
  }'
```

```python title="Python"
import base64
import json

import requests

resp = requests.post(
    "https://tokendance.space/gateway/ark/v3/tts/unidirectional",
    headers={
        "Authorization": "Bearer YOUR_KEY",
        "X-Api-Resource-Id": "MODEL_ID",
    },
    json={
        "req_params": {
            "text": "今天天气真好，适合出门走走。",
            "speaker": "zh_female_vv_uranus_bigtts",
            "audio_params": {"format": "mp3", "sample_rate": 24000},
        }
    },
    stream=True,
)

audio = bytearray()
for line in resp.iter_lines():
    if not line.startswith(b"data: "):
        continue
    frame = json.loads(line[6:])
    if frame["code"] == 20000000:      # 合成完成
        break
    if frame.get("data"):              # 音频片段，按顺序拼接
        audio += base64.b64decode(frame["data"])

with open("out.mp3", "wb") as f:
    f.write(audio)
```

```javascript title="Node.js"
import { writeFileSync } from "node:fs";

const resp = await fetch(
  "https://tokendance.space/gateway/ark/v3/tts/unidirectional",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer YOUR_KEY",
      "X-Api-Resource-Id": "MODEL_ID",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      req_params: {
        text: "今天天气真好，适合出门走走。",
        speaker: "zh_female_vv_uranus_bigtts",
        audio_params: { format: "mp3", sample_rate: 24000 },
      },
    }),
  },
);

const chunks = [];
for await (const chunk of resp.body) {
  for (const line of Buffer.from(chunk).toString().split("\n")) {
    if (!line.startsWith("data: ")) continue;
    const frame = JSON.parse(line.slice(6));
    if (frame.code === 20000000) break;   // 合成完成
    if (frame.data) chunks.push(Buffer.from(frame.data, "base64"));
  }
}
writeFileSync("out.mp3", Buffer.concat(chunks));
```

:::

### 处理返回数据

每条 SSE 消息的 `data` 都是一段 JSON：

- `code: 0` 且包含 `data`：将 `data` 做 Base64 解码，按收到的顺序拼接
- `code: 20000000`：合成结束，停止读取响应

::: warning
`20000000` 是成功完成的标志，不是错误码。如果按「`code` 非 0 就是出错」来判断，每次正常合成都会被当成失败。
:::

### 常用参数

输出格式、采样率、语速和音量都放在 `req_params.audio_params`：

| 参数 | 范围 | 说明 |
|---|---|---|
| `format` | `mp3` / `wav` / `pcm` / `ogg_opus` | 默认 `mp3` |
| `sample_rate` | `8000` / `16000` / `22050` / `24000` / `32000` / `44100` / `48000` | 默认 `24000` |
| `speech_rate` | -50 ~ 100 | `0` 是原速，`100` 是 2 倍速，`-50` 是 0.5 倍速 |
| `loudness_rate` | -50 ~ 100 | 同上，`100` 是 2 倍音量 |

`req_params.additions` 用于设置句尾静音、Markdown 和 Emoji 过滤、语言或方言、音调等选项。

更多参数说明见 [上游官方文档](https://www.volcengine.com/docs/6561/1598757)。
