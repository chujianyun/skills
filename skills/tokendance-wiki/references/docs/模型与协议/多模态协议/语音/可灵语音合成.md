# 可灵语音合成

<!-- model-detail-quickstart:start -->

可灵语音合成将文本转换为音频，一次请求同步返回完整结果。

### 合成音频

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v1/audio/tts \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "MODEL_ID",
    "text": "欢迎使用可灵数字人，让创意开口说话。",
    "voice_id": "YOUR_VOICE_ID",
    "voice_language": "zh",
    "voice_speed": 1
  }'
```

将 `YOUR_VOICE_ID` 替换为可用音色 ID。成功时 `data.task_status` 为 `succeed`，
音频地址位于 `data.task_result.audios[].url`，无需轮询。音频 `id` 可作为[数字人请求](../%E5%9B%BE%E5%83%8F%E4%B8%8E%E8%A7%86%E9%A2%91/%E5%8F%AF%E7%81%B5%E6%95%B0%E5%AD%97%E4%BA%BA.md)的 `audio_id`。

支持按成功合成次数或生成音频的实际秒数计费，具体计价方式和价格以模型价格页为准。

[可灵语音合成官方文档](https://klingai.com/document-api/api/video/avatar/text-to-speech)
