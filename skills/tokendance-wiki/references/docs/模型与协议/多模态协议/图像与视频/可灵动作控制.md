# 可灵动作控制

<!-- model-detail-quickstart:start -->

可灵动作控制使用角色图片和动作参考视频生成短片，当前支持 `kling-3.0`。任务采用异步生成。

### 提交任务

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v1/motion-control \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "MODEL_ID",
    "contents": [
      {"type": "image", "url": "https://example.com/character.png"},
      {"type": "video", "url": "https://example.com/motion.mp4"}
    ],
    "settings": {
      "character_orientation": "video",
      "resolution": "720p"
    }
  }'
```

将示例图片和视频 URL 换成公网可访问的素材地址。

### 查询任务

将 `TASK_ID` 替换为提交响应中的 `data.id`：

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v1/motion-control/TASK_ID \
  -H "Authorization: Bearer YOUR_KEY"
```

任务成功后，视频地址位于 `data[0].outputs[]` 中 `type` 为 `video` 的结果的 `url`。请及时下载或转存。

[可灵动作控制官方文档](https://kling.ai/document-api/api/video/motion-control)
