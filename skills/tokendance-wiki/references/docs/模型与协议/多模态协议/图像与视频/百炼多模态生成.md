# 百炼多模态生成

使用 `dashscope:multimodal-generation` 调用 Qwen/Wan 图像生成、编辑和短音频识别。
将 `YOUR_KEY` 替换为词元跳动 API Key，`model` 填写所选模型的 ID。

<!-- model-detail-quickstart:start -->

### 文生图

```bash title="cURL"
curl https://tokendance.space/gateway/alibaba/api/v1/services/aigc/multimodal-generation/generation \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "input": {"messages": [{
      "role": "user",
      "content": [{"text": "白色背景上的红色陶瓷杯，简洁产品照片。"}]
    }]},
    "parameters": {"size": "1024*1024", "n": 1, "watermark": false}
  }'
```

输出图片地址位于 `output.choices[].message.content[].image`，请及时下载保存。

<!-- model-detail-quickstart:end -->

### 参考图编辑

将 `REFERENCE_IMAGE_URL` 替换为可访问的参考图地址。

```bash title="cURL"
curl https://tokendance.space/gateway/alibaba/api/v1/services/aigc/multimodal-generation/generation \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "input": {"messages": [{
      "role": "user",
      "content": [
        {"image": "REFERENCE_IMAGE_URL"},
        {"text": "把参考图中的红色杯子改成蓝色，保持其他内容。"}
      ]
    }]},
    "parameters": {"size": "1024*1024", "n": 1, "watermark": false}
  }'
```

### 短音频识别

将 `ASR_MODEL_ID` 替换为所选 ASR 模型的 ID，`format` 必须与音频格式一致。

```bash title="cURL"
curl https://tokendance.space/gateway/alibaba/api/v1/services/aigc/multimodal-generation/generation \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ASR_MODEL_ID",
    "input": {"messages": [{
      "role": "user",
      "content": [{"type": "input_audio", "input_audio": {
        "data": "https://au-tokendance.tos-cn-shanghai.volces.com/example/audio.wav"
      }}]
    }]},
    "parameters": {"format": "wav"}
  }'
```

识别文本位于 `output.text`。支持流式输出的模型可加 `X-DashScope-SSE: enable` 请求头，并使用 `curl -N`。

完整参数和各模型的流式要求见 [Qwen 图像官方文档](https://www.alibabacloud.com/help/en/model-studio/qwen-image-generation-and-editing-api-reference)、
[Wan 2.7 官方文档](https://help.aliyun.com/zh/model-studio/wan-image-generation-and-editing-api-reference)、
[Wan 2.6 官方文档](https://help.aliyun.com/zh/model-studio/wan-image-generation-api-reference)和
[ASR 官方文档](https://help.aliyun.com/zh/model-studio/fun-asr-flash-recorded-speech-recognition-http-api)。
