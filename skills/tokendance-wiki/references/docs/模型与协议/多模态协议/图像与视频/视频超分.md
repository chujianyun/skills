# 视频超分

<!-- model-detail-quickstart:start -->

异步协议——提交任务后使用返回的 `task_id` 轮询，成片下载地址有效期为 24 小时。

### 提交任务

```bash title="cURL"
curl https://tokendance.space/gateway/v1/video-enhance \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "video_url": "https://example.com/input.mp4",
    "resolution": "1080p"
  }'
```

`resolution` 是目标分辨率，可选 `720p`、`1080p`、`4k`；档位约束画面高度，宽度按源视频比例缩放。
`video_url` 必须能从公网直接下载。提交成功后，从响应的 `data.task_id` 取得任务 ID：

```json
{"code": 0, "msg": "success", "data": {"task_id": "TASK_ID"}}
```

### 查询任务

```bash title="cURL"
curl https://tokendance.space/gateway/v1/video-enhance/TASK_ID \
  -H "Authorization: Bearer YOUR_KEY"
```

`data.status` 依次经过 `pending`、`downloading`、`running`、`uploading`，最终为 `succeeded` 或 `failed`。
任务成功后，`data.output` 是成片下载地址：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "task_id": "TASK_ID",
    "status": "succeeded",
    "progress": 100,
    "duration": 10.03,
    "output_resolution": "1964x1080",
    "output": "https://tokendance.space/gateway/resources/..."
  }
}
```

任务失败时 `data.status` 为 `failed`，`data.message` 是失败原因，例如源视频无法下载。

### 调用地址

| 操作 | 方法与地址 |
| --- | --- |
| 创建任务 | `POST https://tokendance.space/gateway/v1/video-enhance` |
| 查询任务 | `GET https://tokendance.space/gateway/v1/video-enhance/{TASK_ID}` |

按源视频时长计费，单价随目标分辨率变化，任务完成后按实际时长结算。创建接口没有客户端幂等键，
网络超时后不要自动重试 `POST`，否则可能重复创建并计费。
