# 可灵视频特效

<!-- model-detail-quickstart:start -->

可灵视频特效按模板生成短片。先选择 `effect_scene`，再按该模板要求填写 `input` 素材，任务采用异步生成。

### 提交任务

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v1/videos/effects \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "MODEL_ID",
    "effect_scene": "color_mixing",
    "input": {
      "image": "https://example.com/portrait.png"
    }
  }'
```

`effect_scene` 填写不含空格的模板标识，`input` 按接口文档填写该模板所需素材；
示例素材 URL 请换成公网可访问的地址。

### 查询任务

将 `TASK_ID` 替换为提交响应中的 `data.task_id`：

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v1/videos/effects/TASK_ID \
  -H "Authorization: Bearer YOUR_KEY"
```

查询状态位于 `data.task_status`；成功为 `succeed`，失败为 `failed`。
成功后从 `data.task_result.videos[].url` 获取视频，失败原因见 `data.task_status_msg`。

按所选模板的固定价格预扣，成功按预扣金额结算，失败退款。模板价格参考[特效计价表](https://agentuniverse.feishu.cn/wiki/Z6bkwo5DmiPClLkjpp6cN93OnSd)，实际费用还会应用模型费率与账户折扣。

[可灵视频特效接口文档](https://tcnxnzs113h4.feishu.cn/wiki/SB8fwteTyiAKjSk3StgcI7OWn0b)
