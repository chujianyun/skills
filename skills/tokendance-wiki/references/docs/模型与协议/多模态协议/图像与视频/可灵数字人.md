# 可灵数字人

<!-- model-detail-quickstart:start -->

可灵数字人使用人物图片和音频生成说话视频，任务采用异步生成。

### 提交任务

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v1/videos/avatar/image2video \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "MODEL_ID",
    "image": "https://example.com/portrait.png",
    "sound_file": "https://example.com/speech.mp3",
    "mode": "std"
  }'
```

将素材 URL 换成公网可访问的地址。也可将[语音合成](../%E8%AF%AD%E9%9F%B3/%E5%8F%AF%E7%81%B5%E8%AF%AD%E9%9F%B3%E5%90%88%E6%88%90.md)返回的音频 `id` 填入
`audio_id`，替代 `sound_file`；两者只能提供一个。

### 查询任务

将 `TASK_ID` 替换为提交响应中的 `data.task_id`：

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v1/videos/avatar/image2video/TASK_ID \
  -H "Authorization: Bearer YOUR_KEY"
```

查询状态位于 `data.task_status`；成功为 `succeed`，失败为 `failed`。
成功后从 `data.task_result.videos[].url` 获取视频，请及时下载或转存。

TokenDance 会将供应商的数字人响应转换为上述客户端协议，不要直接按供应商上游的 `taskId` 或 `outputs` 结构解析。

按 `mode`（`std` / `pro`）和成片实际秒数计费，价格以模型价格页为准。
