# 可灵图生视频 V2

<!-- model-detail-quickstart:start -->

可灵图生视频 V2 适用于 Kling 4.0，采用异步生成：提交任务后，使用返回的任务 ID 查询结果。

分辨率支持 `720p`、`1080p`，输出时长为 3–30 整数秒。输入视频按实际时长、输出视频按总时长向下取整计费。

### 提交任务

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v2/image2video \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model_name": "MODEL_ID",
    "contents": [
      {"type": "prompt", "text": "猫咪抬起前爪，慢慢转头看向镜头"},
      {"type": "first_frame", "url": "https://example.com/cat.jpg"}
    ],
    "settings": {
      "resolution": "720p",
      "duration": 5,
      "aspect_ratio": "16:9"
    }
  }'
```

将示例图片 URL 换成公网可访问的素材地址。

### 查询任务

将 `TASK_ID` 替换为提交响应中的 `data.id`：

```bash title="cURL"
curl https://tokendance.space/gateway/kling/v2/image2video/TASK_ID \
  -H "Authorization: Bearer YOUR_KEY"
```

任务成功后，视频地址位于 `data[0].outputs[]` 中 `type` 为 `video` 的结果的 `url`。请及时下载或转存。

[可灵图生视频官方文档](https://www.klingai.com/document-api/apiReference/model/imageToVideo)
