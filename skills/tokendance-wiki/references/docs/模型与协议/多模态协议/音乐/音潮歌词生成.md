# 音潮歌词生成

<!-- model-detail-quickstart:start -->

音潮歌词生成会同步返回歌名和歌词，无需轮询任务。

请求中的 `model` 请填写 TokenDance [模型目录](../../%E9%80%89%E6%8B%A9%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE%E6%A6%82%E8%A7%88.md)中支持音潮歌词生成的模型 ID。

### 生成歌词

```bash title="cURL"
curl https://tokendance.space/gateway/yinchao/v1/lyric/generate \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "prompt": "创作一首轻快的流行音乐，主题是夏天的海边"
  }'
```

成功响应中的 `title` 是歌名，`lyric` 是歌词：

```json
{
  "title": "半透明的薄雾",
  "lyric": "[VERSE]\n赤脚踩碎细浪的光\n海风偷走发梢的谎\n..."
}
```

生成的 `lyric` 可以传给[音潮歌曲生成](%E9%9F%B3%E6%BD%AE%E6%AD%8C%E6%9B%B2%E7%94%9F%E6%88%90.md)接口继续生成歌曲。

完整请求字段、歌词格式和模型能力以[音潮开放平台协议文档](https://platform.yinchaoyongxian.com/docs/quickstart/quickstart)为准。通过 TokenDance 调用时，请继续使用本页的请求地址、API Key 和模型 ID。
