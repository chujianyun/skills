# 音潮歌曲生成

<!-- model-detail-quickstart:start -->

音潮歌曲生成采用异步模式：提交任务后，使用返回的任务 ID 查询生成进度和歌曲地址。

请求中的 `model` 请填写 TokenDance [模型目录](../../%E9%80%89%E6%8B%A9%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE%E6%A6%82%E8%A7%88.md)中支持音潮歌曲生成的模型 ID。

### 提示词生成歌曲

```bash title="cURL"
curl https://tokendance.space/gateway/yinchao/v1/song/generate \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "task_type": "normal",
    "prompt": "一首轻快的流行歌曲，主题是夏日海边的回忆",
    "n": 2
  }'
```

### 参考音频仿写

参考音频请使用可公开访问的 URL：

```bash title="cURL"
curl https://tokendance.space/gateway/yinchao/v1/song/generate \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "task_type": "reference",
    "prompt": "保持参考曲的律动感，改成柔和的爵士风格",
    "reference_audio": {
      "audio_type": "audio_url",
      "audio_content": "https://example.com/reference.mp3"
    },
    "similarity": 0.8,
    "n": 2
  }'
```

### 扩写歌曲

待扩写音频请使用可公开访问的 URL：

```bash title="cURL"
curl https://tokendance.space/gateway/yinchao/v1/song/extend \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "origin_audio": {
      "audio_type": "audio_url",
      "audio_content": "https://example.com/origin.mp3"
    },
    "lyric": "[CHORUS]\n继续唱下去\n让旋律不停歇",
    "extend_at": 60.0,
    "n": 2
  }'
```

### 生成纯音乐

```bash title="cURL"
curl https://tokendance.space/gateway/yinchao/v1/song/instrumental \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "prompt": "轻快的原声吉他 BGM，适合咖啡馆氛围",
    "n": 2
  }'
```

### 查询任务

将 `TASK_ID` 替换为提交响应中的 `id`。建议每隔 2～5 秒查询一次，并在所有歌曲完成或失败后停止轮询。

```bash title="cURL"
curl "https://tokendance.space/gateway/yinchao/v1/task/query?task_id=TASK_ID" \
  -H "Authorization: Bearer YOUR_KEY"
```

响应示例：

```json
{
  "id": "TASK_ID",
  "task_type": "normal",
  "choices": [
    {
      "id": "SONG_ID",
      "status": "done",
      "error": "",
      "error_code": 0,
      "audio_url": "https://example.com/audio.mp3",
      "pipe_url": "",
      "title": "半透明的薄雾",
      "lyric": "[VERSE]\n赤脚踩碎细浪的光\n...",
      "size": 0,
      "duration": 0,
      "create_at": 1710000000,
      "finish_at": 1710000000
    }
  ],
  "create_at": 1710000000
}
```

每首歌曲的状态位于 `choices[].status`：

- `stream`：可使用 `pipe_url` 播放生成中的音频；
- `done`：可使用 `audio_url` 下载完整歌曲；
- `fail`：查看 `error` 和 `error_code`。

同一任务生成多首歌曲时，各首歌曲的进度可能不同。请分别读取每个 `choice` 当前已经返回的地址。

### 播放生成中的音频

状态为 `stream` 时，使用该歌曲返回的完整 `pipe_url`，并携带 TokenDance API Key：

```bash title="cURL"
curl -L "PIPE_URL" \
  -H "Authorization: Bearer YOUR_KEY" \
  --output preview.mp3
```

完整请求字段、取值范围和模型能力以[音潮开放平台协议文档](https://platform.yinchaoyongxian.com/docs/quickstart/quickstart)为准。通过 TokenDance 调用时，请继续使用本页的请求地址、API Key 和模型 ID。
