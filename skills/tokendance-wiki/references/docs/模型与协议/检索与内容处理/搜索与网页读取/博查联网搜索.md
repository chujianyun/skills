# 博查联网搜索

:::group

```bash title="cURL"
curl https://tokendance.space/gateway/bocha/v1/web-search \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "阿里巴巴2024年的esg报告",
    "freshness": "noLimit",
    "summary": true,
    "count": 10
  }'
```

```python title="Python"
import requests

response = requests.post(
    "https://tokendance.space/gateway/bocha/v1/web-search",
    headers={"Authorization": "Bearer YOUR_KEY"},
    json={
        "query": "阿里巴巴2024年的esg报告",
        "freshness": "noLimit",
        "summary": True,
        "count": 10,
    },
)
print(response.json())
```

```javascript title="Node.js"
const response = await fetch('https://tokendance.space/gateway/bocha/v1/web-search', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    query: '阿里巴巴2024年的esg报告',
    freshness: 'noLimit',
    summary: true,
    count: 10,
  }),
});
const data = await response.json();
console.log(data);
```

:::

请求字段：`query` 为搜索词（必填），`freshness` 限定时间范围（推荐 `noLimit`），`summary=true` 时返回网页文本摘要，`count` 控制返回条数（1-50），`include` / `exclude` 限定或排除域名（多个用 `|` 或 `,` 分隔）。
