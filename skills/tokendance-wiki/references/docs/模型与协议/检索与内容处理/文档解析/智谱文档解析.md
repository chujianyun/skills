# 智谱文档解析

:::group

```bash title="cURL"
curl https://tokendance.space/gateway/zai/v4/layout_parsing \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "file": "https://example.com/document.pdf"
  }'
```

```python title="Python"
import requests

response = requests.post(
    "https://tokendance.space/gateway/zai/v4/layout_parsing",
    headers={"Authorization": "Bearer YOUR_KEY"},
    json={"model": "MODEL_ID", "file": "https://example.com/document.pdf"},
)
print(response.json())
```

```javascript title="Node.js"
const response = await fetch('https://tokendance.space/gateway/zai/v4/layout_parsing', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    model: 'MODEL_ID',
    file: 'https://example.com/document.pdf',
  }),
});
const data = await response.json();
console.log(data);
```

:::

`file` 字段支持公网可访问的 URL 或 base64（带 data URI 前缀，如 `data:image/png;base64,...`）。
