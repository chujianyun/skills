# 模型与协议概览

词元跳动聚合了来自多个供应商的大模型，你可以在 [模型列表](https://tokendance.space/models) 页面浏览所有可用模型，也可以通过 API 查询。

## 浏览模型 {#browse-models}

模型列表页面展示所有可用模型，包括模型名称、上下文长度、支持的协议等信息。点击模型可查看详情，包括各供应商的定价和延迟数据。

## 模型 API {#models-api}

```bash title="获取所有模型"
curl https://tokendance.space/gateway/v1/models
```

::: note
该接口无需鉴权，可以直接访问。
:::

### 响应格式 {#response-format}

```json title="响应示例"
{
  "data": [
    {
      "id": "deepseek-v3.2",
      "name": "DeepSeek: DeepSeek V3.2",
      "created": 1774283167,
      "description": "DeepSeek-V3.2 是 DeepSeek 的最新旗舰模型...",
      "context_length": 163840,
      "supported_protocols": ["openai:chat-completions"]
    }
  ]
}
```

### 字段说明 {#field-description}

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 模型唯一标识，API 请求时使用 |
| name | string | 模型展示名称 |
| created | number | 模型添加时间（Unix 时间戳） |
| description | string | 模型描述 |
| context_length | number | 最大上下文窗口（token 数） |
| supported_protocols | string[] | 支持的协议列表 |

## 协议标识 {#protocol-ids}

每个模型的 `supported_protocols` 字段标明了该模型支持哪些协议。根据协议选择对应的 SDK 即可调用。

| 协议标识 | 说明 | 对应 SDK |
|---|---|---|
| openai:chat-completions | OpenAI Chat Completions | OpenAI SDK |
| openai:responses | OpenAI Responses | OpenAI SDK |
| openai:image-generations | OpenAI Image Generations | OpenAI SDK |
| anthropic:messages | Anthropic Messages | Anthropic SDK |
| gemini:generate-content | Google Gemini | Google GenAI SDK |
| typesafe:systemone | TypeSafe Jev 结构化评估 | cURL / 自定义 HTTP 客户端 |
| ark:image-generations | 火山引擎 Ark 图像生成 | 火山引擎 SDK / cURL |
| minimax:t2a_v2 | MiniMax 同步语音合成 | cURL / 自定义 HTTP 客户端 |
| unifuncs:web-search | UniFuncs 实时搜索 | cURL / 自定义 HTTP 客户端 |
| unifuncs:web-reader | UniFuncs 网页阅读 | cURL / 自定义 HTTP 客户端 |
| deepseek:web-search | DeepSeek 网页搜索 | cURL / 自定义 HTTP 客户端 |
| deepseek:web-fetch | DeepSeek 网页抓取 | cURL / 自定义 HTTP 客户端 |

::: tip
详细的协议使用方式请参考 [多协议支持](%E5%8D%8F%E8%AE%AE%E6%80%BB%E8%A7%88.md) 文档。
:::

## 模型定价 {#pricing}

每个模型由词元跳动独立定价，你可以在 [模型列表](https://tokendance.space/models) 或模型详情页查看具体的输入/输出 token 价格。

费用按模型的计费单位计算，从你的额度余额中扣除。文本模型通常按 token 计费，DeepSeek 网页搜索与抓取按有结果的成功请求次数计费。调用完成后可在 [调用日志](https://tokendance.space/activity) 中查看每次请求的详细费用。

::: note
不同模型使用不同的 tokenizer，相同文本在不同模型上的 token 数可能不同，因此实际费用会有所差异。
:::
