# 协议总览

TokenDance 原生支持多种模型协议，不要求把所有请求转换成同一种格式。使用 OpenAI SDK 时走 OpenAI 协议，
使用 Anthropic SDK 时走 Anthropic Messages；各协议的流式事件、工具调用、多模态参数和异步任务结构会按
原协议处理。

## 选择协议 {#choose}

- 已有项目优先保留当前 SDK 和协议，只替换 API Key、base URL 和模型 ID；
- 通用文本对话优先使用 OpenAI Chat Completions 或 Responses；
- Claude 原生能力与 Claude Code 使用 Anthropic Messages；
- Gemini 原生多模态使用 Google GenerateContent；
- 图像、视频、语音、搜索和文档解析使用对应供应商的原生协议；
- 结构化判断使用 [TypeSafe Jev](../%E7%BB%93%E6%9E%84%E5%8C%96%E8%AF%84%E4%BC%B0/TypeSafe%20Jev%20%E7%BB%93%E6%9E%84%E5%8C%96%E8%AF%84%E4%BC%B0.md)，它不是对话生成协议；
- 以模型目录返回的 `supported_protocols` 为准，不根据模型名称猜测。
