# 平台介绍

TokenDance（词元跳动）是一个 LLM API 中转平台，提供统一的 API 入口调用所有主流大模型。我们相信未来是多模型、多供应商的。

## 核心优势 {#core-advantages}

### 多协议原生支持 {#multi-protocol}

不同于其他中转站只支持 OpenAI 格式，词元跳动原生支持 OpenAI、Anthropic (Claude)、Google GenAI (Gemini) 等多种协议。你可以直接使用各家官方 SDK，只需修改 base URL 和 API Key，无需任何协议转换。

::: note
了解更多关于多协议支持的内容，请参阅 [多协议支持文档](../../%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E9%80%89%E6%8B%A9%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E5%8D%8F%E8%AE%AE%E6%80%BB%E8%A7%88.md)。
:::

### 有竞争力的定价 {#competitive-pricing}

我们为每个模型独立定价，确保价格具有竞争力。所有模型的定价在 [模型列表](https://tokendance.space/models) 页面公开透明，你可以在调用前查看具体费用。

### 统一计费 {#unified-billing}

无论你使用多少供应商的多少模型，所有费用统一从词元跳动的额度余额扣除。无需在每个供应商处分别充值和管理账单。

### 高可用性 {#high-availability}

每个模型可以配置多个供应商端点。当某个供应商出现故障时，系统自动切换到其他可用供应商，确保你的请求不受影响。

::: note
了解更多关于供应商路由和降级策略，请参阅 [供应商路由文档](../%E8%B7%AF%E7%94%B1%E4%B8%8E%E5%8F%AF%E7%94%A8%E6%80%A7/%E4%BE%9B%E5%BA%94%E5%95%86%E8%B7%AF%E7%94%B1.md)。
:::

### 智能负载均衡 {#load-balancing}

基于价格、延迟、吞吐量等指标，在多个供应商之间智能分配请求，自动选择当前最优的供应商。

### 实时用量追踪 {#usage-tracking}

提供完整的 API 调用日志和用量统计，按模型、供应商、API Key 等维度查看使用详情。

## 与直接使用供应商 API 的对比 {#comparison}

| 能力 | 直接使用供应商 | 使用词元跳动 |
|---|---|---|
| 切换模型/供应商 | 需要修改代码和 API Key | 只需修改 model 参数 |
| 供应商故障 | 服务中断 | 自动降级到备用供应商 |
| 计费管理 | 每个供应商单独管理 | 统一余额，一处管理 |
| 用量追踪 | 各平台分散查看 | 集中式日志和报表 |
| 多协议支持 | 每个协议独立配置 | 一个 Key 调用所有协议 |

## 适用场景 {#use-cases}

- **个人开发者**：一个 API Key 即可调用市面上所有主流模型，无需逐一注册各家平台
- **创业团队**：统一管理 API 用量和成本，快速测试不同模型找到最佳方案
- **企业用户**：高可用保障、自动降级、集中式审计日志
