# 快速开始

::: tip
想让 AI 直接完成接入？把[这份完整 Markdown](%E7%94%A8%20AI%20%E6%8E%A5%E5%85%A5.md)交给
Codex、Claude Code、Cursor 或其他 coding agent。它会自行读取文档索引、选择协议、获取 API Key 并修改项目。
:::

::: tip
词元跳动兼容 OpenAI、Anthropic、Google GenAI 等主流 SDK。本页以最通用的 OpenAI SDK 为例，其他协议请参考 [多协议支持](../../%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E9%80%89%E6%8B%A9%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E5%8D%8F%E8%AE%AE%E6%80%BB%E8%A7%88.md)。
:::

## 创建 API Key {#create-api-key}

登录后，前往 [API 密钥](https://tokendance.space/keys) 页面，点击「创建密钥」生成一个新的 API Key。

::: warning
密钥创建后请立即复制保存，它只会显示一次。
:::

## 浏览可用模型 {#browse-models}

访问 [模型列表](https://tokendance.space/models) 浏览所有可用模型。每个模型会标注其支持的协议（OpenAI、Anthropic、GenAI 等），据此选择对应 SDK 即可调用。

也可以通过 API 获取模型列表（无需鉴权）：

```bash
curl https://tokendance.space/gateway/v1/models
```

响应示例：


## 发起请求 {#make-request}

将代码中的 `YOUR_KEY` 替换为你的密钥，`MODEL_ID` 替换为模型 ID（如 `minimax-m2.5`），即可开始调用。本节示例自动从协议目录派生：
