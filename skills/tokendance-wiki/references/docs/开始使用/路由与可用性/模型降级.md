# 模型降级

`models` 参数允许你指定备选模型列表。当主模型（`model` 字段）的所有供应商都无法响应时，系统会按顺序尝试备选模型，直到某个模型成功返回。

::: note
模型降级支持 OpenAI 协议（`/v1/chat/completions`）和 Anthropic 协议（`/v1/messages`）。
:::

## 工作原理 {#how-it-works}

在请求体中使用 `model` 指定主模型，同时通过 `models` 数组按优先级排列备选模型。系统会先尝试主模型，失败后依次尝试 `models` 中的备选模型。

:::group

```bash title="OpenAI cURL"
curl https://tokendance.space/gateway/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_KEY" \
  -d '{
    "model": "glm-5.1",
    "models": ["minimax-m2.7", "kimi-k2.5"],
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

```bash title="Anthropic cURL"
curl https://tokendance.space/gateway/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "glm-5.1",
    "models": ["minimax-m2.7", "kimi-k2.5"],
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

```python title="Python (OpenAI)"
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_KEY",
    base_url="https://tokendance.space/gateway/v1"
)

response = client.chat.completions.create(
    model="glm-5.1",
    extra_body={
        "models": ["minimax-m2.7", "kimi-k2.5"]
    },
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
```

```python title="Python (Anthropic)"
import anthropic

client = anthropic.Anthropic(
    api_key="YOUR_KEY",
    base_url="https://tokendance.space/gateway"
)

response = client.messages.create(
    model="glm-5.1",
    max_tokens=1024,
    extra_body={
        "models": ["minimax-m2.7", "kimi-k2.5"]
    },
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.content[0].text)
```

```javascript title="Node.js"
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'YOUR_KEY',
  baseURL: 'https://tokendance.space/gateway/v1',
});

const response = await client.chat.completions.create({
  model: 'glm-5.1',
  // @ts-expect-error models is a TokenDance extension
  models: ['minimax-m2.7', 'kimi-k2.5'],
  messages: [{ role: 'user', content: 'Hello!' }],
});
console.log(response.choices[0].message.content);
```

:::

## 降级行为 {#fallback-behavior}

当主模型返回错误时，系统会自动尝试 `models` 列表中的下一个模型。

| 场景 | 行为 |
|---|---|
| 主模型可用 | 正常使用主模型（model 字段） |
| 主模型所有供应商失败 | 按顺序尝试 models 中的备选模型 |
| 所有模型都失败 | 返回最后一个错误 |

## 定价 {#pricing}

请求按实际使用的模型计费。你可以在 [调用日志](https://tokendance.space/activity) 中查看每次请求实际使用的模型和对应费用。

## 使用建议 {#best-practices}

- **按能力排序**：将能力最强的模型作为主模型，能力稍弱但稳定性更高的模型作为备选
- **合理设置数量**：1-2 个备选模型通常足够

::: tip
模型降级适合对可用性要求极高的生产环境。对于开发和测试，使用单个模型即可。
:::
