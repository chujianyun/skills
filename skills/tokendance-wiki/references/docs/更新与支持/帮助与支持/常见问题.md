# 常见问题

## 入门 {#getting-started}

::: accordion title="词元跳动是什么？"
词元跳动（TokenDance）是一个 LLM API 中转平台，提供统一的 API 入口调用所有主流大模型。你只需要一个 API Key，就可以通过词元跳动调用 DeepSeek、通义千问、智谱 GLM、MiniMax、豆包等模型。我们负责负载均衡、自动降级和统一计费。[了解更多](../../%E5%BC%80%E5%A7%8B%E4%BD%BF%E7%94%A8/%E5%BF%AB%E9%80%9F%E5%85%A5%E9%97%A8/%E5%B9%B3%E5%8F%B0%E4%BB%8B%E7%BB%8D.md)。
:::

::: accordion title="如何开始使用？"
三步即可开始：

1. 注册账号并充值额度
2. 在 [API 密钥](https://tokendance.space/keys) 页面创建 API Key
3. 将你使用的 SDK 的 base URL 指向词元跳动，即可开始调用

详细指引请参考 [快速开始](../../%E5%BC%80%E5%A7%8B%E4%BD%BF%E7%94%A8/%E5%BF%AB%E9%80%9F%E5%85%A5%E9%97%A8/%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B.md) 文档。
:::

::: accordion title="支持哪些大模型？"
我们持续接入市面上的主流大模型，包括但不限于 DeepSeek、通义千问（Qwen）、智谱 GLM、MiniMax、豆包等。完整列表请访问 [模型列表](https://tokendance.space/models) 页面。
:::

::: accordion title="与直接使用供应商 API 有什么区别？"
使用词元跳动的主要优势：

- 一个 Key 调用所有模型，无需在每个供应商处注册
- 自动降级和负载均衡，提高可用性
- 统一计费，一处管理所有费用
- 多协议原生支持（OpenAI、Anthropic、Gemini 等），无需协议转换
:::

## 定价与计费 {#pricing}

::: accordion title="如何收费？"
词元跳动采用额度制。你需要先充值额度，每次 API 调用会根据使用的模型和 token 数量扣除相应额度。每个模型的定价在模型列表页面公开展示。
:::

::: accordion title="如何查看用量和费用？"
登录后访问 [调用日志](https://tokendance.space/activity) 页面，可以按模型、供应商、API Key 等维度查看详细的使用记录和费用。
:::

::: accordion title="如何充值？"
前往 [额度](https://tokendance.space/credits) 页面自助充值。
:::

## 技术问题 {#technical}

::: accordion title="支持流式输出吗？"
支持。所有文本生成协议（OpenAI、Anthropic、Gemini）都支持流式输出（Streaming）。在请求中设置 `stream: true` 即可启用。
:::

::: accordion title="支持工具调用（Function Calling）吗？"
支持。词元跳动原生转发请求，完整支持各协议的工具调用功能。只要上游模型支持工具调用，通过词元跳动调用时功能完全一致。
:::

::: accordion title="支持图像输入（Vision）吗？"
支持。支持视觉输入的模型可以通过词元跳动正常接收图像。图像以 URL 或 Base64 格式传入，与直接调用供应商 API 的方式一致。
:::

::: accordion title="支持图像生成吗？"
支持。我们支持 OpenAI Image Generations 和火山引擎 Ark Image Generations 两种图像生成协议。详情请参考 [多协议支持](../../%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E9%80%89%E6%8B%A9%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E5%8D%8F%E8%AE%AE%E6%80%BB%E8%A7%88.md) 文档。
:::

::: accordion title="支持文本转语音吗？"
支持。我们接入了 MiniMax 同步语音合成（T2A v2），支持 mp3 / wav / flac 多种音频格式，提供同步返回与 SSE 流式分帧两种模式。详情请参考 [MiniMax 语音合成协议](../../%E6%A8%A1%E5%9E%8B%E4%B8%8E%E5%8D%8F%E8%AE%AE/%E5%A4%9A%E6%A8%A1%E6%80%81%E5%8D%8F%E8%AE%AE/%E8%AF%AD%E9%9F%B3/MiniMax%20T2A%20v2.md)。
:::

::: accordion title="有请求频率限制吗？"
有。详细说明请参考 [请求限流](../../%E5%BC%80%E5%A7%8B%E4%BD%BF%E7%94%A8/%E8%B7%AF%E7%94%B1%E4%B8%8E%E5%8F%AF%E7%94%A8%E6%80%A7/%E8%AF%B7%E6%B1%82%E9%99%90%E6%B5%81.md) 文档。
:::

## 账户与安全 {#account}

::: accordion title="API Key 泄露了怎么办？"
请立即登录 [API 密钥](https://tokendance.space/keys) 页面删除泄露的密钥，并创建新密钥。旧密钥删除后立即失效，不会再产生费用。
:::
