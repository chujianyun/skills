::: changelog id="20261014-session-affinity" date="2026-10-14" service="api_gateway" type="added" title="新增会话粘滞"
对话类请求新增会话粘滞：同一会话的多轮请求会优先回到上一轮命中提示词缓存的供应商端点，减少缓存重建带来的输入成本。缓存失效后自动回到默认路由，`provider` 显式偏好仍然优先。

- 默认开启，系统根据对话开头的内容自动识别会话
- 可通过请求头 `X-Session-ID` 或 `prompt_cache_key` 字段显式声明会话，识别更稳定

[查看会话粘滞文档](../../%E5%BC%80%E5%A7%8B%E4%BD%BF%E7%94%A8/%E8%B7%AF%E7%94%B1%E4%B8%8E%E5%8F%AF%E7%94%A8%E6%80%A7/%E4%BC%9A%E8%AF%9D%E7%B2%98%E6%BB%9E.md)
