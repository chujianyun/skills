# Client SDKs

> Install a TypeSafe client SDK and use typed questions and answers in your application.

Our client SDKs provide typed questions and answers for the TypeSafe API and handle retries automatically with their default retry policy.

Choose a client SDK for installation instructions, examples, and API details.

- **[Python](Python/TypeSafe Python SDK.md)**: Install the Python client SDK and make your first request.

- **[JavaScript / TypeScript](JavaScript/JavaScript SDK.md)**: Install the JavaScript client SDK and make your first typed request.

You can also call the [HTTP API](../API reference.md) directly from any language.
