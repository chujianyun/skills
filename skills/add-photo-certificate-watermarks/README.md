# 照片与证件水印

这个 Skill 用于在本地给照片、身份证、护照、学位证、毕业证、资格证、营业执照等证件或证书扫描件及 PDF 添加文字水印。照片默认采用右下角版权标记，证件默认采用斜向平铺的用途限制水印。

它的核心原则是：先生成预览、确认清晰度和避让区域，再批量输出；原件永不覆盖，图片元数据默认移除。

## 适合的场景

- 给摄影作品或产品图添加作者、品牌或版权标记
- 给身份证、护照等身份证明添加实名认证、入职或业务办理用途水印
- 给学位证、毕业证、成绩单、职业资格证、获奖证明等添加限定用途水印
- 给营业执照和其他资质证明添加审核用途水印
- 批量处理 JPEG、PNG、WebP 或 PDF
- 通过坐标避让二维码、头像、印章、签名和证书编号

## 边界

- 不支持去除水印、伪造或修改身份证、学历证书等证件内容
- 不自动识别敏感区域，必须通过预览人工复核
- 水印不能提供绝对防盗用能力
- 默认不保留图片 EXIF；如需保留，应先确认其中没有敏感位置或设备信息
