# 经典知识库 API

> 用于管理经典知识库、文档、分段、元数据、标签和知识流水线的 API

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/api-reference/guides/knowledge.md)。

不经过 Dify 控制台，直接在自己的代码中构建和维护 [经典知识库](../../../../../%E4%BD%BF%E7%94%A8/%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93.md)：创建知识库、导入文档和分段、用元数据和标签组织内容，并可直接调用检索接口用于搜索或 RAG。

## 查找知识库 ID

API 密钥及其访问范围、服务 API 端点，详见 [知识库 API](%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md)。

请求路径中的 `dataset_id` 就是知识库的 ID。可以在 Dify 中打开该知识库，从页面 URL 里复制 `/datasets/` 之后的部分；如果密钥能访问所有知识库，也可以通过 [获取知识库列表](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%9F%A5%E8%AF%86%E5%BA%93/%E8%8E%B7%E5%8F%96%E7%9F%A5%E8%AF%86%E5%BA%93%E5%88%97%E8%A1%A8.md) 获取。

## 管理知识库的 API 访问权限

默认情况下，每个知识库都开放 API 访问。如需让某个知识库对所有密钥关闭 API 访问，打开该知识库，关闭左下角的 **访问 API** 开关。

## 添加和更新文档

文档创建是异步的，需要先创建文档，再轮询等待索引完成：

**1. 创建知识库**

调用 [创建空知识库](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%88%9B%E5%BB%BA%E7%A9%BA%E7%9F%A5%E8%AF%86%E5%BA%93.md)，也可直接使用已有的知识库。

**2. 添加文档**

调用 [从文本创建文档](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E4%BB%8E%E6%96%87%E6%9C%AC%E5%88%9B%E5%BB%BA%E6%96%87%E6%A1%A3.md) 或 [从文件创建文档](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E4%BB%8E%E6%96%87%E4%BB%B6%E5%88%9B%E5%BB%BA%E6%96%87%E6%A1%A3.md)，两者都会返回一个 `batch` ID。

如果创建知识库时未设置 `indexing_technique`（内容用于检索的索引方式），在第一个文档上设置即可，后续文档会自动继承。

**3. 轮询索引状态**

使用 `batch` ID 轮询 [获取文档嵌入状态（进度）](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E8%8E%B7%E5%8F%96%E6%96%87%E6%A1%A3%E5%B5%8C%E5%85%A5%E7%8A%B6%E6%80%81%EF%BC%88%E8%BF%9B%E5%BA%A6%EF%BC%89.md)，直到 `indexing_status` 变为 `completed` 或 `error`，期间会依次经过 `waiting`、`parsing`、`cleaning`、`splitting`、`indexing` 几个阶段。

* **[获取知识库的文档列表](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E8%8E%B7%E5%8F%96%E7%9F%A5%E8%AF%86%E5%BA%93%E7%9A%84%E6%96%87%E6%A1%A3%E5%88%97%E8%A1%A8.md)**：返回分页列表，支持按关键词或索引状态筛选。
* **[获取文档详情](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E8%8E%B7%E5%8F%96%E6%96%87%E6%A1%A3%E8%AF%A6%E6%83%85.md)**：返回文档的索引状态、元数据和处理统计信息，`metadata` 查询参数控制响应包含、省略还是仅返回元数据字段。
* **[下载文档](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E4%B8%8B%E8%BD%BD%E6%96%87%E6%A1%A3.md)**：返回文档原始上传文件的签名下载 URL。
* **[批量下载文档（ZIP）](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E6%89%B9%E9%87%8F%E4%B8%8B%E8%BD%BD%E6%96%87%E6%A1%A3%EF%BC%88ZIP%EF%BC%89.md)**：最多可将 100 个通过文件上传的文档打包为一个压缩包。
* **[更新文档](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E6%9B%B4%E6%96%B0%E6%96%87%E6%A1%A3.md)**：上传新文件替换文档内容并重新触发索引，是基于文件更新文档的标准方式。
* **[用文本更新文档](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E7%94%A8%E6%96%87%E6%9C%AC%E6%9B%B4%E6%96%B0%E6%96%87%E6%A1%A3.md)**：直接更新文档的文本内容、名称或处理配置，内容变更时将重新触发索引。
* **[用文件更新文档](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E7%94%A8%E6%96%87%E4%BB%B6%E6%9B%B4%E6%96%B0%E6%96%87%E6%A1%A3.md)**：已废弃的别名接口，用于上传替换文件，改用「更新文档」。
* **[批量更新文档状态](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E6%89%B9%E9%87%8F%E6%9B%B4%E6%96%B0%E6%96%87%E6%A1%A3%E7%8A%B6%E6%80%81.md)**：一次性启用、禁用、归档或取消归档多个文档。
* **[删除文档](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%96%87%E6%A1%A3/%E5%88%A0%E9%99%A4%E6%96%87%E6%A1%A3.md)**：永久删除文档及其中的所有分段。

## 管理分段与子分段

* **[向文档添加分段](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%88%86%E6%AE%B5/%E5%90%91%E6%96%87%E6%A1%A3%E6%B7%BB%E5%8A%A0%E5%88%86%E6%AE%B5.md)**：手动为文档添加分段（上传的内容在索引时已自动分段）。每个分段都需要 `content`，问答模式的文档还需要 `answer`。

## 管理元数据字段

元数据字段为文档附加结构化信息，检索时可据此过滤：

* **[创建元数据字段](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%85%83%E6%95%B0%E6%8D%AE/%E5%88%9B%E5%BB%BA%E5%85%83%E6%95%B0%E6%8D%AE%E5%AD%97%E6%AE%B5.md)**：为知识库添加自定义字段，类型可为 `string`、`number` 或 `time`。
* **[获取元数据字段列表](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%85%83%E6%95%B0%E6%8D%AE/%E8%8E%B7%E5%8F%96%E5%85%83%E6%95%B0%E6%8D%AE%E5%AD%97%E6%AE%B5%E5%88%97%E8%A1%A8.md)**：返回全部字段（包括自定义和内置字段），并给出每个字段的使用文档数。
* **[更新元数据字段](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%85%83%E6%95%B0%E6%8D%AE/%E6%9B%B4%E6%96%B0%E5%85%83%E6%95%B0%E6%8D%AE%E5%AD%97%E6%AE%B5.md)**：重命名自定义字段。
* **[删除元数据字段](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%85%83%E6%95%B0%E6%8D%AE/%E5%88%A0%E9%99%A4%E5%85%83%E6%95%B0%E6%8D%AE%E5%AD%97%E6%AE%B5.md)**：删除自定义字段，文档会随之丢失该字段的取值。
* **[获取内置元数据字段](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%85%83%E6%95%B0%E6%8D%AE/%E8%8E%B7%E5%8F%96%E5%86%85%E7%BD%AE%E5%85%83%E6%95%B0%E6%8D%AE%E5%AD%97%E6%AE%B5.md)**：返回系统内置字段，如 `document_name`、`uploader`、`upload_date`。
* **[更新内置元数据字段](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%85%83%E6%95%B0%E6%8D%AE/%E6%9B%B4%E6%96%B0%E5%86%85%E7%BD%AE%E5%85%83%E6%95%B0%E6%8D%AE%E5%AD%97%E6%AE%B5.md)**：为知识库启用或禁用内置字段。
* **[批量更新文档元数据](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%85%83%E6%95%B0%E6%8D%AE/%E6%89%B9%E9%87%8F%E6%9B%B4%E6%96%B0%E6%96%87%E6%A1%A3%E5%85%83%E6%95%B0%E6%8D%AE.md)**：在一次调用中为多个文档设置元数据键值对。

元数据还可充当稳定的外部键：在每个文档上存入源系统的 ID，后续同步时按该 ID 过滤，即可找到并更新同一批文档。

标签在工作空间层面管理，不依附于某个具体知识库：

* **[创建知识库标签](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A0%87%E7%AD%BE/%E5%88%9B%E5%BB%BA%E7%9F%A5%E8%AF%86%E5%BA%93%E6%A0%87%E7%AD%BE.md)**：创建用于组织知识库的标签。
* **[获取知识库标签列表](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A0%87%E7%AD%BE/%E8%8E%B7%E5%8F%96%E7%9F%A5%E8%AF%86%E5%BA%93%E6%A0%87%E7%AD%BE%E5%88%97%E8%A1%A8.md)**：返回工作空间内的全部标签。
* **[修改知识库标签](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A0%87%E7%AD%BE/%E4%BF%AE%E6%94%B9%E7%9F%A5%E8%AF%86%E5%BA%93%E6%A0%87%E7%AD%BE.md)**：重命名标签。
* **[删除知识库标签](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A0%87%E7%AD%BE/%E5%88%A0%E9%99%A4%E7%9F%A5%E8%AF%86%E5%BA%93%E6%A0%87%E7%AD%BE.md)**：将标签从所有绑定的知识库上移除，但不会删除这些知识库。
* **[绑定标签到知识库](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A0%87%E7%AD%BE/%E7%BB%91%E5%AE%9A%E6%A0%87%E7%AD%BE%E5%88%B0%E7%9F%A5%E8%AF%86%E5%BA%93.md)**：为知识库绑定一个或多个标签，一个知识库可同时绑定多个标签。
* **[解除标签与知识库的绑定](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A0%87%E7%AD%BE/%E8%A7%A3%E9%99%A4%E6%A0%87%E7%AD%BE%E4%B8%8E%E7%9F%A5%E8%AF%86%E5%BA%93%E7%9A%84%E7%BB%91%E5%AE%9A.md)**：从知识库上移除标签。
* **[获取知识库绑定的标签](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A0%87%E7%AD%BE/%E8%8E%B7%E5%8F%96%E7%9F%A5%E8%AF%86%E5%BA%93%E7%BB%91%E5%AE%9A%E7%9A%84%E6%A0%87%E7%AD%BE.md)**：返回某个知识库当前绑定的标签。

## 查询可用模型

* **[获取可用模型](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A8%A1%E5%9E%8B/%E8%8E%B7%E5%8F%96%E5%8F%AF%E7%94%A8%E6%A8%A1%E5%9E%8B.md)**：返回指定 `model_type` 下的可用模型。配置知识库时，可查询 `text-embedding` 获取嵌入模型，或查询 `rerank` 获取重排序模型。

## 运行知识流水线

知识流水线是一种工作流，从数据源摄取数据并将其转换为文档：

* **[上传流水线文件](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%9F%A5%E8%AF%86%E6%B5%81%E6%B0%B4%E7%BA%BF/%E4%B8%8A%E4%BC%A0%E6%B5%81%E6%B0%B4%E7%BA%BF%E6%96%87%E4%BB%B6.md)**：上传供流水线处理的文件。
* **[获取数据源插件列表](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%9F%A5%E8%AF%86%E6%B5%81%E6%B0%B4%E7%BA%BF/%E8%8E%B7%E5%8F%96%E6%95%B0%E6%8D%AE%E6%BA%90%E6%8F%92%E4%BB%B6%E5%88%97%E8%A1%A8.md)**：返回流水线中配置的数据源节点，默认返回已发布版本，传入 `is_published=false` 则返回草稿版本。
* **[执行数据源节点](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%9F%A5%E8%AF%86%E6%B5%81%E6%B0%B4%E7%BA%BF/%E6%89%A7%E8%A1%8C%E6%95%B0%E6%8D%AE%E6%BA%90%E8%8A%82%E7%82%B9.md)**：执行单个数据源节点并以流式返回结果，适合单独测试某个步骤。
* **[运行流水线](../../../%E7%9F%A5%E8%AF%86%E5%BA%93%20API/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%9F%A5%E8%AF%86%E6%B5%81%E6%B0%B4%E7%BA%BF/%E8%BF%90%E8%A1%8C%E6%B5%81%E6%B0%B4%E7%BA%BF.md)**：以 `streaming` 或 `blocking` 模式执行完整流水线，通过 `is_published` 指定运行已发布版本还是当前草稿。
