# 对话型应用 API

> 面向聊天助手和旧版 Agent 应用的 API，涵盖对话消息、会话管理、文件上传、语音转换及标注管理

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/api-reference/guides/chat.md)。

[聊天助手应用](../../../../%E4%BD%BF%E7%94%A8/%E7%BC%96%E6%8E%92/%E5%9F%BA%E7%A1%80%E5%BA%94%E7%94%A8/%E8%81%8A%E5%A4%A9%E5%8A%A9%E6%89%8B.md)（`chat` 模式）和 [旧版 Agent 应用](../../../../%E4%BD%BF%E7%94%A8/%E7%BC%96%E6%8E%92/%E5%9F%BA%E7%A1%80%E5%BA%94%E7%94%A8/Agent.md)（`agent-chat` 模式）共用这套 API：同一组接口用于发送消息、管理会话、处理文件和获取应用设置。两者仅在回复的流式事件上有所不同：聊天助手应用以 `message` 事件流式返回回复，旧版 Agent 应用则返回 `agent_thought` 和 `agent_message` 事件。

> [!NOTE]
>
> 认证方式、基础 URL，以及按终端用户区分数据的 `user` 字段，详见 [快速开始](../Dify%20API%20%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B.md) 和 [终端用户身份](../%E7%BB%88%E7%AB%AF%E7%94%A8%E6%88%B7%E8%BA%AB%E4%BB%BD.md)。

## 发送消息并接收流式回复

* **[发送对话消息](../../%E5%BA%94%E7%94%A8%20API/%E5%AF%B9%E8%AF%9D%E6%B6%88%E6%81%AF/%E5%8F%91%E9%80%81%E5%AF%B9%E8%AF%9D%E6%B6%88%E6%81%AF.md)**：向聊天助手或旧版 Agent 应用发送用户提问。阻塞式返回在回复完成后一次性返回全部内容；旧版 Agent 应用仅支持流式返回。
* **[停止响应](../../%E5%BA%94%E7%94%A8%20API/%E5%AF%B9%E8%AF%9D%E6%B6%88%E6%81%AF/%E5%81%9C%E6%AD%A2%E5%93%8D%E5%BA%94.md)**：在回复完成前中断流式输出。
* **[获取下一轮建议问题列表](../../%E5%BA%94%E7%94%A8%20API/%E5%AF%B9%E8%AF%9D%E6%B6%88%E6%81%AF/%E8%8E%B7%E5%8F%96%E4%B8%8B%E4%B8%80%E8%BD%AE%E5%BB%BA%E8%AE%AE%E9%97%AE%E9%A2%98%E5%88%97%E8%A1%A8.md)**：回复完成后，基于当前对话内容推荐后续问题。

## 管理会话

通过 API 创建的会话，与该应用 Web 应用中发起的会话相互隔离。

* **[获取会话列表](../../%E5%BA%94%E7%94%A8%20API/%E4%BC%9A%E8%AF%9D%E7%AE%A1%E7%90%86/%E8%8E%B7%E5%8F%96%E4%BC%9A%E8%AF%9D%E5%88%97%E8%A1%A8.md)**：按最近活跃时间排序，返回当前用户的会话。
* **[获取会话历史消息](../../%E5%BA%94%E7%94%A8%20API/%E4%BC%9A%E8%AF%9D%E7%AE%A1%E7%90%86/%E8%8E%B7%E5%8F%96%E4%BC%9A%E8%AF%9D%E5%8E%86%E5%8F%B2%E6%B6%88%E6%81%AF.md)**：返回某个会话的历史消息，适合滚动加载的聊天界面。
* **[重命名会话](../../%E5%BA%94%E7%94%A8%20API/%E4%BC%9A%E8%AF%9D%E7%AE%A1%E7%90%86/%E9%87%8D%E5%91%BD%E5%90%8D%E4%BC%9A%E8%AF%9D.md)**：设置或自动生成会话名称。
* **[删除会话](../../%E5%BA%94%E7%94%A8%20API/%E4%BC%9A%E8%AF%9D%E7%AE%A1%E7%90%86/%E5%88%A0%E9%99%A4%E4%BC%9A%E8%AF%9D.md)**：删除指定会话。
* **[获取会话变量](../../%E5%BA%94%E7%94%A8%20API/%E4%BC%9A%E8%AF%9D%E7%AE%A1%E7%90%86/%E8%8E%B7%E5%8F%96%E4%BC%9A%E8%AF%9D%E5%8F%98%E9%87%8F.md)**：读取会话在多轮对话间保留的变量值。
* **[更新会话变量](../../%E5%BA%94%E7%94%A8%20API/%E4%BC%9A%E8%AF%9D%E7%AE%A1%E7%90%86/%E6%9B%B4%E6%96%B0%E4%BC%9A%E8%AF%9D%E5%8F%98%E9%87%8F.md)**：直接修改其中某个变量的值。

## 处理文件

* **[上传文件](../../%E5%BA%94%E7%94%A8%20API/%E6%96%87%E4%BB%B6%E6%93%8D%E4%BD%9C/%E4%B8%8A%E4%BC%A0%E6%96%87%E4%BB%B6.md)**：上传图片、文档、音频或视频文件，供 [发送对话消息](../../%E5%BA%94%E7%94%A8%20API/%E5%AF%B9%E8%AF%9D%E6%B6%88%E6%81%AF/%E5%8F%91%E9%80%81%E5%AF%B9%E8%AF%9D%E6%B6%88%E6%81%AF.md) 引用。文件仅限上传的终端用户使用。
* **[下载文件](../../%E5%BA%94%E7%94%A8%20API/%E6%96%87%E4%BB%B6%E6%93%8D%E4%BD%9C/%E4%B8%8B%E8%BD%BD%E6%96%87%E4%BB%B6.md)**：预览或下载已上传的文件，前提是该文件属于当前应用内的某条消息。
* **[获取终端用户信息](../../%E5%BA%94%E7%94%A8%20API/%E7%BB%88%E7%AB%AF%E7%94%A8%E6%88%B7/%E8%8E%B7%E5%8F%96%E7%BB%88%E7%AB%AF%E7%94%A8%E6%88%B7%E4%BF%A1%E6%81%AF.md)**：根据终端用户 ID（例如上传文件响应中的 `created_by`）查询该用户的详细信息。

## 语音转写与合成

* **[语音转文字](../../%E5%BA%94%E7%94%A8%20API/%E8%AF%AD%E9%9F%B3%E4%B8%8E%E6%96%87%E5%AD%97%E8%BD%AC%E6%8D%A2/%E8%AF%AD%E9%9F%B3%E8%BD%AC%E6%96%87%E5%AD%97.md)**：将上传的音频文件（MP3、M4A、WAV、AMR 或 MPGA，最大 30 MB）转写为文字，让终端用户用语音代替打字输入。
* **[文字转语音](../../%E5%BA%94%E7%94%A8%20API/%E8%AF%AD%E9%9F%B3%E4%B8%8E%E6%96%87%E5%AD%97%E8%BD%AC%E6%8D%A2/%E6%96%87%E5%AD%97%E8%BD%AC%E8%AF%AD%E9%9F%B3.md)**：将回复合成为语音。
