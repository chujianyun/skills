## 生成文本

* **[发送消息](../../%E5%BA%94%E7%94%A8%20API/%E6%96%87%E6%9C%AC%E7%94%9F%E6%88%90%E6%B6%88%E6%81%AF/%E5%8F%91%E9%80%81%E6%B6%88%E6%81%AF.md)**：将 `inputs` 中的取值填入应用的提示词模板并生成回复。阻塞式返回在生成完成后一次性返回全部内容；流式返回持续输出 `message` 事件，直至 `message_end`（应用开启文字转语音自动播放时还会收到 `tts_message` 事件）。

## 语音转写与合成
