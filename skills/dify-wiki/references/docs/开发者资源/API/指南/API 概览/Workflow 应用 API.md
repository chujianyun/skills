## 运行工作流

* **[执行工作流](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E6%89%A7%E8%A1%8C%E5%B7%A5%E4%BD%9C%E6%B5%81.md)**：使用提供的输入变量，执行应用当前已发布的工作流。

  流式返回时，节点执行过程中会实时推送事件；阻塞式返回时，运行结束后才返回结果。
* **[按 ID 执行工作流](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E6%8C%89%20ID%20%E6%89%A7%E8%A1%8C%E5%B7%A5%E4%BD%9C%E6%B5%81.md)**：执行指定的已发布版本，其 `workflow_id` 来自此前的运行响应或运行详情查询结果。

## 跟踪与控制运行

无论选择哪种模式，响应都会携带两个 ID：`task_id` 用于控制运行中的任务，`workflow_run_id` 用于标识运行结束后持久保存的记录。

* **[停止工作流任务](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E5%81%9C%E6%AD%A2%E5%B7%A5%E4%BD%9C%E6%B5%81%E4%BB%BB%E5%8A%A1.md)**：通过 `task_id` 取消运行中的任务。适用于流式返回；阻塞式返回只能在运行暂停、调用返回后取消。
* **[流式获取工作流事件](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E6%B5%81%E5%BC%8F%E8%8E%B7%E5%8F%96%E5%B7%A5%E4%BD%9C%E6%B5%81%E4%BA%8B%E4%BB%B6.md)**：连接中断或运行暂停后，从 `workflow_run_id` 恢复事件流。

  传入 `include_state_snapshot=true` 可先重放已执行节点的状态，传入 `continue_on_pause=true` 可在多次人工介入暂停间保持流连接。

## 人工介入暂停

当运行到达提交方式为 Web 应用的 [人工介入](../../../../%E4%BD%BF%E7%94%A8/%E7%BC%96%E6%8E%92/Workflow%20%E4%B8%8E%20Chatflow/%E4%BA%BA%E5%B7%A5%E4%BB%8B%E5%85%A5/%E4%BA%BA%E5%B7%A5%E4%BB%8B%E5%85%A5.md) 节点时，可通过 API 完成这次暂停的处理：

**1. 监听暂停事件**

运行的事件流会推送 `human_input_required` 事件，其中携带 `form_token` 和本次运行的 `workflow_run_id`，随后以 `workflow_paused` 事件结束。

**2. 获取表单**

使用 `form_token` 调用 [获取人工介入表单](../../%E5%BA%94%E7%94%A8%20API/%E4%BA%BA%E5%B7%A5%E4%BB%8B%E5%85%A5/%E8%8E%B7%E5%8F%96%E4%BA%BA%E5%B7%A5%E4%BB%8B%E5%85%A5%E8%A1%A8%E5%8D%95.md)，加载表单内容。

**3. 提交填写结果**

通过 [提交人工介入表单](../../%E5%BA%94%E7%94%A8%20API/%E4%BA%BA%E5%B7%A5%E4%BB%8B%E5%85%A5/%E6%8F%90%E4%BA%A4%E4%BA%BA%E5%B7%A5%E4%BB%8B%E5%85%A5%E8%A1%A8%E5%8D%95.md) 发送接收者的填写内容。提交后运行恢复执行。

**4. 继续跟踪事件流**

使用暂停时事件流中的 `workflow_run_id`，调用 [流式获取工作流事件](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E6%B5%81%E5%BC%8F%E8%8E%B7%E5%8F%96%E5%B7%A5%E4%BD%9C%E6%B5%81%E4%BA%8B%E4%BB%B6.md) 打开新的事件流，跟踪剩余事件，直到运行结束。

带文件的表单提交与完整事件序列，详见 [人工介入流程](../%E4%BA%BA%E5%B7%A5%E4%BB%8B%E5%85%A5%20API%20%E9%9B%86%E6%88%90%E6%B5%81%E7%A8%8B.md) 指南。

## 查看历史运行

* **[获取工作流执行情况](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E8%8E%B7%E5%8F%96%E5%B7%A5%E4%BD%9C%E6%B5%81%E6%89%A7%E8%A1%8C%E6%83%85%E5%86%B5.md)**：根据 `workflow_run_id` 查询某次运行的状态与输出。
* **[获取工作流日志](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E8%8E%B7%E5%8F%96%E5%B7%A5%E4%BD%9C%E6%B5%81%E6%97%A5%E5%BF%97.md)**：返回运行级别的汇总信息（状态、token 用量、步骤数、耗时），而非逐节点的执行日志；可按关键词、状态、时间范围或触发运行的用户筛选。

如需逐节点的事件，应流式跟踪运行本身，而非查看日志：新发起的运行以流式返回调用 [执行工作流](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E6%89%A7%E8%A1%8C%E5%B7%A5%E4%BD%9C%E6%B5%81.md)，已在执行中的运行使用 [流式获取工作流事件](../../%E5%BA%94%E7%94%A8%20API/%E5%B7%A5%E4%BD%9C%E6%B5%81%E8%BF%90%E8%A1%8C/%E6%B5%81%E5%BC%8F%E8%8E%B7%E5%8F%96%E5%B7%A5%E4%BD%9C%E6%B5%81%E4%BA%8B%E4%BB%B6.md)。

## 处理文件

* **[上传文件](../../%E5%BA%94%E7%94%A8%20API/%E6%96%87%E4%BB%B6%E6%93%8D%E4%BD%9C/%E4%B8%8A%E4%BC%A0%E6%96%87%E4%BB%B6.md)**：上传图片、文档、音频或视频文件，运行工作流时在文件类型的输入变量中以返回的 `id` 作为 `upload_file_id` 传入。文件仅限上传的终端用户使用。
* **[获取终端用户信息](../../%E5%BA%94%E7%94%A8%20API/%E7%BB%88%E7%AB%AF%E7%94%A8%E6%88%B7/%E8%8E%B7%E5%8F%96%E7%BB%88%E7%AB%AF%E7%94%A8%E6%88%B7%E4%BF%A1%E6%81%AF.md)**：根据终端用户 ID（例如上传文件响应中的 `created_by`）查询该用户的详细信息。

## 语音转写与合成

* **[语音转文字](../../%E5%BA%94%E7%94%A8%20API/%E8%AF%AD%E9%9F%B3%E4%B8%8E%E6%96%87%E5%AD%97%E8%BD%AC%E6%8D%A2/%E8%AF%AD%E9%9F%B3%E8%BD%AC%E6%96%87%E5%AD%97.md)**：将上传的音频文件（MP3、M4A、WAV、AMR 或 MPGA，最大 30 MB）转写为文字，让终端用户用语音代替打字提供输入值。
