# 获取应用参数

> **适用于**：Chatflow、Workflow、Agent、聊天助手、旧版 Agent、文本生成应用。

返回应用的前端配置：开场白和建议问题、功能开关、用户输入表单，以及文件上传限制。用它来渲染应用的输入项并应用正确的上传限制。
