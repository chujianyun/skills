# 获取人工介入表单

> **适用于**：Chatflow、Workflow。

返回暂停中的人工介入表单内容。需要 Web 应用提交方式。

人工介入调用的完整流程，参见 [人工介入流程](../../%E6%8C%87%E5%8D%97/%E4%BA%BA%E5%B7%A5%E4%BB%8B%E5%85%A5%20API%20%E9%9B%86%E6%88%90%E6%B5%81%E7%A8%8B.md)。
