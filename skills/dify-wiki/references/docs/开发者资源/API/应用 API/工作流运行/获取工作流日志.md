# 获取工作流日志

> **适用于**：Chatflow、Workflow。

列出过往的工作流运行，支持可选筛选。每条记录是运行级摘要（状态、Token 用量、步数和耗时），而非逐节点的执行日志。

如需跟踪某次运行的节点级事件，请改用流式方式：

- **自行发起的运行**：以流式返回方式调用 [执行工作流](%E6%89%A7%E8%A1%8C%E5%B7%A5%E4%BD%9C%E6%B5%81.md)，运行执行时会发送 `node_started` 和 `node_finished` 事件。
- **已在进行中的运行**：调用 [流式获取工作流事件](%E6%B5%81%E5%BC%8F%E8%8E%B7%E5%8F%96%E5%B7%A5%E4%BD%9C%E6%B5%81%E4%BA%8B%E4%BB%B6.md) 并附带 `include_state_snapshot=true`，先重放各已执行节点的状态，再流式发送其余事件。

已结束运行的节点级日志无法通过服务 API 获取。
