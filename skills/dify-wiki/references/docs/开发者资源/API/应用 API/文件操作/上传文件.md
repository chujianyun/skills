# 上传文件

> **适用于**：Chatflow、Workflow、Agent、聊天助手、旧版 Agent、文本生成应用。

上传文件并返回其 `id`，供后续请求引用。文件归上传它的终端用户所有：只有携带相同 `user` 的请求才能引用该文件。

应用实际能使用哪些文件类型，取决于它的文件上传设置；可通过 [获取应用参数](../%E5%BA%94%E7%94%A8%E9%85%8D%E7%BD%AE/%E8%8E%B7%E5%8F%96%E5%BA%94%E7%94%A8%E5%8F%82%E6%95%B0.md) 读取。
