# 文字转语音

> **适用于**：Chatflow、Workflow、Agent、聊天助手、旧版 Agent、文本生成应用。

将文本转换为语音音频。传入 `text` 可合成任意文本，或传入 `message_id` 为已有消息的答案配音。
