# 获取下一轮建议问题列表

> **适用于**：Chatflow、Agent、聊天助手、旧版 Agent。

返回为某条消息推荐的追问问题。

如果应用没有可用的模型，或生成问题失败，接口仍返回 `200`，`data` 为空数组。
