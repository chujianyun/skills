# 从知识库检索分段 / 测试检索

> 搜索知识库，返回与查询最相关的分段，可用于生产环境检索和测试检索。

知识库的索引方式为 `economy` 时，始终按关键词检索，并忽略 `retrieval_model.search_method`。
