# 从文件创建文档

> 在知识库中通过上传文件创建文档。支持 PDF、TXT、DOCX 等常见格式。索引异步进行；使用返回的 `batch` ID 通过 [获取文档嵌入状态（进度）](%E8%8E%B7%E5%8F%96%E6%96%87%E6%A1%A3%E5%B5%8C%E5%85%A5%E7%8A%B6%E6%80%81%EF%BC%88%E8%BF%9B%E5%BA%A6%EF%BC%89.md) 跟踪。
