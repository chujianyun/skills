# 取消研究任务

> 取消尚未结束的研究任务，返回的任务 `stage` 为 `canceled`。

任务记录会保留，已写入的结果仍可通过 [获取研究任务结果列表](%E8%8E%B7%E5%8F%96%E7%A0%94%E7%A9%B6%E4%BB%BB%E5%8A%A1%E7%BB%93%E6%9E%9C%E5%88%97%E8%A1%A8.md) 读取。
