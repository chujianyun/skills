# 更新同步策略

> 设置数据源的定时同步，替换原有设置，并返回新设置。

保存不会启动同步。第一次定时同步在更新后满一个间隔时到期，之后每次在上一次进入队列后满一个间隔时到期。要立即同步，调用 [同步数据源](../%E6%95%B0%E6%8D%AE%E6%BA%90%E5%90%8C%E6%AD%A5%E4%B8%8E%E5%AF%BC%E5%85%A5/%E5%90%8C%E6%AD%A5%E6%95%B0%E6%8D%AE%E6%BA%90.md)。

每次向该数据源导入完成后，都要用数据源新的 `version` 重新保存定时同步。导入会改变 `version`，仍绑定在旧值上的定时同步会在下一次到期时自行关闭。

要暂停定时同步而不改动其设置，用 [更新数据源](%E6%9B%B4%E6%96%B0%E6%95%B0%E6%8D%AE%E6%BA%90.md) 将数据源的 `status` 设为 `disabled`。暂停期间到期的同步，会在数据源恢复为 `active` 时运行。

先读取再保存的流程，详见 [同步数据源与定时同步](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#sync-and-schedule-sources)。
