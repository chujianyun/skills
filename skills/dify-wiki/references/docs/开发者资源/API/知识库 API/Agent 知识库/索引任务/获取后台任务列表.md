# 获取后台任务列表

> 在同一个列表中汇总知识库的后台工作，或按 ID 查找指定任务：

- 不传 `task_ids` 时：返回最新的索引任务、批量任务和数据源运行，合并后最新的在前。属于批量任务的索引任务，会合并显示为该批量任务。沿 `next_cursor` 可获取更早的任务。
- 传入 `task_ids` 时：最多查找 100 个索引任务或批量任务 ID。未知 ID、该密钥无法查看的任务以及数据源运行 ID 会被排除。该列表不分页。

如需在此跟踪 [重新索引文档](../%E6%96%87%E6%A1%A3%E4%B8%8E%E5%88%86%E6%AE%B5/%E9%87%8D%E6%96%B0%E7%B4%A2%E5%BC%95%E6%96%87%E6%A1%A3.md) 请求，查找其 `bulk_job_id`。

各任务操作的适用场景，详见 [跟踪索引进度](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#track-indexing)。
