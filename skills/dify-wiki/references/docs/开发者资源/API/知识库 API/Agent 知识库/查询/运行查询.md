# 运行查询

> 运行已通过 [创建查询令牌](%E5%88%9B%E5%BB%BA%E6%9F%A5%E8%AF%A2%E4%BB%A4%E7%89%8C.md) 获取令牌的查询，并以 Server-Sent Events 流式返回回答。此接口以查询令牌作为凭据，不使用知识库 API 密钥。服务端在受理请求时校验令牌。

两步调用流程及流的读取方式，详见 [查询知识库](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#query-the-knowledge-base)。

哪些错误应当重试、错误详情各字段的含义，详见 [处理错误](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#handle-errors)。

查询成功时，会先保存查询记录，再发送 `answer.done`。重复调用会再次运行查询。

                  - `nodeId`：分段 ID。

                  - `label`：`node:<nodeId>`。

                  - `documentAssetId`：分段所属的文档文件。

                  - `sectionPath`：大纲路径。

                  - `pageNumber`：页码，从 1 开始，源文件提供页码信息时返回，否则省略。

                  - `projectionIds`：参与本次匹配的检索索引 ID。识别源文件请使用 `documentAssetId`。

                  - 客户端断开连接：本次运行被取消，流结束。


                  **回答内容**：在 `fast` 和 `deep` 深度下，由一个 `answer.delta`

                  find evidence for that query in the indexed retrieval
                  projections.`，且 `finishReason` 为 `no-retrieval-evidence`。


                  在所有深度下，回答最长 2,000 个字符。回答达到这个长度，并不能说明它是否被截断。
