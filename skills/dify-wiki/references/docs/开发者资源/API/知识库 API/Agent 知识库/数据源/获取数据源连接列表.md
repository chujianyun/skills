# 获取数据源连接列表

> 列出该知识库的连接，最早的在前。将某个连接的 `id` 作为 `connectionId` 传给 [创建数据源](%E5%88%9B%E5%BB%BA%E6%95%B0%E6%8D%AE%E6%BA%90.md)，即可添加通过该连接读取内容的数据源。

只有在 Dify 中为该知识库添加过某个提供商的数据源后，列表中才会出现该提供商的连接。要使用新的提供商，先在 Dify 中添加它的第一个数据源。每个知识库的连接相互独立。选择 `status` 为 `active`，且 `provider_id` 和 `configuration` 与目标提供商及凭据一致的连接。

具体步骤详见 [添加数据源](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#add-a-source)。
