# 重试数据源运行

> 以相同的运行 ID，从头重新执行状态为 `failed` 或 `canceled` 的数据源运行，并返回已排队的运行。进度会重置，导入会重新获取每个条目，同步会从头开始。已选定页面的抓取预览会直接重新导入这些页面，不再抓取。

要重做已取消的抓取预览或失败的 [导入网站页面](%E5%AF%BC%E5%85%A5%E7%BD%91%E7%AB%99%E9%A1%B5%E9%9D%A2.md) 运行，不要重试：用新的 `Idempotency-Key` 启动新的预览或导入。

无请求体。

如何跟踪、重试和取消运行，详见 [跟踪数据源运行](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#follow-source-runs)。
