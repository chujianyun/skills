# 获取知识库设置

> 返回知识库的嵌入模型、检索设置、就绪状态，以及调用 [更新知识库设置](%E6%9B%B4%E6%96%B0%E7%9F%A5%E8%AF%86%E5%BA%93%E8%AE%BE%E7%BD%AE.md) 时需要发送的 `revision`。

何时可以通过 API 设置模型，详见 [更换模型或检索设置](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#change-models-or-retrieval-settings)。
