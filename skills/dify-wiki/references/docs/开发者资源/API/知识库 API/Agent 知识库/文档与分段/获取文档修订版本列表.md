# 获取文档修订版本列表

> 列出文档的修订版本，最新的在前。接收的是 [获取文档列表](%E8%8E%B7%E5%8F%96%E6%96%87%E6%A1%A3%E5%88%97%E8%A1%A8.md) 返回的文档 ID，而不是文档文件 ID。

每个修订版本都会注明其对应的文档文件。文档 ID 与文档文件 ID 的关系，详见 [浏览文档和分段](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#browse-documents-and-chunks)。

填充分页前，会先排除该密钥无法读取其文档文件的修订版本。即使某页的修订版本少于 `limit` 个，也要继续沿 `next_cursor` 翻页。
