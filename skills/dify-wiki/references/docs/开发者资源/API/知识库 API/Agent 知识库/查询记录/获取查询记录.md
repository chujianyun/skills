# 获取查询记录

> 返回一条完整的查询记录：查询内容、检索深度、调用方，以及按执行顺序排列的流水线步骤及其元数据。`query.generate` 步骤的元数据内嵌了所有检索分段，因此响应可能较大（最大 2 MiB）。

运行之后所属文档被删除的分段会显示为不可用。如需分页查看这些分段，使用 [获取查询分段列表](%E8%8E%B7%E5%8F%96%E6%9F%A5%E8%AF%A2%E5%88%86%E6%AE%B5%E5%88%97%E8%A1%A8.md)、[获取查询冲突列表](%E8%8E%B7%E5%8F%96%E6%9F%A5%E8%AF%A2%E5%86%B2%E7%AA%81%E5%88%97%E8%A1%A8.md) 和 [获取缺失分段列表](%E8%8E%B7%E5%8F%96%E7%BC%BA%E5%A4%B1%E5%88%86%E6%AE%B5%E5%88%97%E8%A1%A8.md)。

本次运行所用的模型和索引版本，见 [获取查询记录列表](%E8%8E%B7%E5%8F%96%E6%9F%A5%E8%AF%A2%E8%AE%B0%E5%BD%95%E5%88%97%E8%A1%A8.md) 中的 `profile`。

如何结合查看一次运行的分段、冲突和缺失分段，详见 [排查回答](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#investigate-an-answer)。
