# 获取查询记录列表

> 列出知识库的查询记录，最新的在前。每次调用 [运行查询](../%E6%9F%A5%E8%AF%A2/%E8%BF%90%E8%A1%8C%E6%9F%A5%E8%AF%A2.md)，流一建立就会保存一条记录，之后失败的运行也不例外；但客户端断开连接，或运行以 `RETRIEVAL_EXECUTION_LEASE_LOST` 失败时，不保存记录。

列表除了包含当前密钥产生的记录，还包含工作流、Agent、MCP 客户端和其他 API 密钥产生的记录。即使为每个租户分别使用一个密钥，列表也不会只显示该租户的运行。在 Dify 中进行的检索测试从不列出。

`source` 是唯一的筛选条件。如需日后再次定位某次运行，在查询时记下 [运行查询](../%E6%9F%A5%E8%AF%A2/%E8%BF%90%E8%A1%8C%E6%9F%A5%E8%AF%A2.md) 返回的 `x-query-run-id` 响应头。

如何结合查看一次运行的分段、冲突和缺失分段，详见 [排查回答](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#investigate-an-answer)。
