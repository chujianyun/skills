# 获取研究任务结果列表

> 列出研究任务目前已写入的结果，按 `sequence` 升序排列。

一个任务最多写入两个结果：先是检索检查点（如有），然后是最终结果。在最后一个结果中查看 `answer`。提前停止的任务可能没有任何结果。

规划、创建、轮询和读取结果的完整流程，详见 [运行研究任务](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#run-a-research-task)。
