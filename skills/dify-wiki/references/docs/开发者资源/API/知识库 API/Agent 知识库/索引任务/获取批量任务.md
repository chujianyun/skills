# 获取批量任务

> 返回批量任务中各索引任务的进度。在此 API 中，批量任务来自 [重新索引文档](../%E6%96%87%E6%A1%A3%E4%B8%8E%E5%88%86%E6%AE%B5/%E9%87%8D%E6%96%B0%E7%B4%A2%E5%BC%95%E6%96%87%E6%A1%A3.md)，并且只有启动它的 API 密钥才能读取。

[重新索引文档](../%E6%96%87%E6%A1%A3%E4%B8%8E%E5%88%86%E6%AE%B5/%E9%87%8D%E6%96%B0%E7%B4%A2%E5%BC%95%E6%96%87%E6%A1%A3.md) 报告为 `not_found` 的条目会计为已完成，因此即使没有任何文档被重新索引，`completed_items` 也可能等于 `total_items`。要发现这种情况，可比较 `total_items` 与该响应中 `queued` 条目的数量。重新索引流程详见 [重新索引并跟踪索引进度](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#track-indexing)。
