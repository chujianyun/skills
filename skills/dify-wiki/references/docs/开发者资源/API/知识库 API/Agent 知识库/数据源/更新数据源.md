# 更新数据源

> 更新数据源的名称、状态、URI、元数据或提供商参数；配置有变化时，可同时启动一次同步。

至少传入 `name`、`status`、`uri`、`metadata`、`providerParameters` 中的一项。只传 `expectedVersion` 和 `syncAfterUpdate` 的请求会被拒绝。

如何启动和跟踪同步，详见 [同步数据源与定时同步](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#sync-and-schedule-sources)。
