# 获取数据源文件列表

> 列出在线云盘数据源在其提供商处可见的存储桶和文件。

数据源必须是 `connector` 类型，且 `metadata.providerKind` 为 `online-drive`。

要打开返回的某个文件夹，将其 `id` 作为 `prefix` 传入。某个存储桶的 `is_truncated` 为 `true` 时，将其 `continuation_token` 作为 `continuationToken` 传入，即可读取下一页。
