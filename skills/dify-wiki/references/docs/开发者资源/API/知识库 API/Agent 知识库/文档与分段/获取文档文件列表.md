# 获取文档文件列表

> 列出知识库中存储的文档文件。返回的是文档文件 ID，而非文档 ID。如需列出文档，使用 [获取文档列表](%E8%8E%B7%E5%8F%96%E6%96%87%E6%A1%A3%E5%88%97%E8%A1%A8.md)。

文档文件上没有任何字段表明知识库是否仍在使用它。这要看修订版本的 `state`，可在 [获取文档修订版本列表](%E8%8E%B7%E5%8F%96%E6%96%87%E6%A1%A3%E4%BF%AE%E8%AE%A2%E7%89%88%E6%9C%AC%E5%88%97%E8%A1%A8.md) 中查看，该操作接收文档 ID。

文档 ID 与文档文件 ID 的关系，详见 [浏览文档和分段](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#browse-documents-and-chunks)。
