# 获取设置迁移

> 返回迁移的进度。该迁移由 [更新知识库设置](%E6%9B%B4%E6%96%B0%E7%9F%A5%E8%AF%86%E5%BA%93%E8%AE%BE%E7%BD%AE.md) 在返回 `202` 时启动。轮询直到 `run_state` 为 `succeeded`、`failed` 或 `canceled`。

迁移 `succeeded` 后，通过 [获取知识库设置](%E8%8E%B7%E5%8F%96%E7%9F%A5%E8%AF%86%E5%BA%93%E8%AE%BE%E7%BD%AE.md) 读取新设置及其 `revision`。

更新并轮询的流程，详见 [更换模型或检索设置](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#change-models-or-retrieval-settings)。
