# 获取分段列表

> 列出文档某个修订版本的分段，按分段 ID 排序，而非按在文档中的位置排序。接收 [获取文档列表](%E8%8E%B7%E5%8F%96%E6%96%87%E6%A1%A3%E5%88%97%E8%A1%A8.md) 返回的文档 ID（而不是文档文件 ID），以及修订版本号。

如需按文档顺序读取分段，获取所有页后按 `ordinal` 排序。

只要修订版本对应的文档文件版本仍然存在，任何修订版本都可以列出，包括已被取代的修订版本。

文档 ID 与文档文件 ID 的关系，详见 [浏览文档和分段](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#browse-documents-and-chunks)。
