# 获取删除批次

> 返回一次 [批量删除文档文件](../%E6%96%87%E6%A1%A3%E4%B8%8E%E5%88%86%E6%AE%B5/%E6%89%B9%E9%87%8F%E5%88%A0%E9%99%A4%E6%96%87%E6%A1%A3%E6%96%87%E4%BB%B6.md) 请求，包括每个文件的处理结果，以及每个已受理文件的删除作业当前状态。只有发送该批次的 API 密钥能读取它。

当 `results` 中的每个条目都为 `rejected`，或其 `job.run_state` 为 `completed` 或 `failed` 时，该批次即告完成。读取批次不会推进处于 `pending` 的文件。仍处于 `pending` 的文件，是批次中途停止时尚未受理的文件。如需重试这些文件，使用同一个 `Idempotency-Key` 再次发送原请求。

删除流程详见 [删除文档和数据源](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#delete-documents-and-sources)。
