# 获取文档大纲

> 返回为文档文件当前版本构建的标题树。

大纲要等索引构建出来才会存在；如果文件在这一步之前就索引失败，则不会有大纲。重新索引后，要等新的索引任务发布，此操作才会返回该任务构建的大纲。

响应不分页。
