# 重新索引文档

> 为每个选中的文档排入一个索引任务，根据其当前文件重建索引。返回一个批量任务 ID，用于统一跟踪这些任务。

`all: true` 和 `documentIds` 必须且只能提供其中一个。

不会重新上传任何文件。用 `compilation_job.id` 通过 [获取索引任务](../%E7%B4%A2%E5%BC%95%E4%BB%BB%E5%8A%A1/%E8%8E%B7%E5%8F%96%E7%B4%A2%E5%BC%95%E4%BB%BB%E5%8A%A1.md) 跟踪单个任务，通过 [获取批量任务](../%E7%B4%A2%E5%BC%95%E4%BB%BB%E5%8A%A1/%E8%8E%B7%E5%8F%96%E6%89%B9%E9%87%8F%E4%BB%BB%E5%8A%A1.md) 跟踪整个请求。

重新索引流程详见 [重新索引并跟踪索引进度](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#track-indexing)。
