# 获取数据源

> 返回一个数据源的存储内容。

此接口返回的 `last_synced_at`、`sync_policy` 和 `sync_workflow` 始终为 `null`。定时同步设置用 [获取同步策略](%E8%8E%B7%E5%8F%96%E5%90%8C%E6%AD%A5%E7%AD%96%E7%95%A5.md) 读取，运行情况用 [获取数据源运行](../%E6%95%B0%E6%8D%AE%E6%BA%90%E5%90%8C%E6%AD%A5%E4%B8%8E%E5%AF%BC%E5%85%A5/%E8%8E%B7%E5%8F%96%E6%95%B0%E6%8D%AE%E6%BA%90%E8%BF%90%E8%A1%8C.md) 或 [获取数据源运行列表](../%E6%95%B0%E6%8D%AE%E6%BA%90%E5%90%8C%E6%AD%A5%E4%B8%8E%E5%AF%BC%E5%85%A5/%E8%8E%B7%E5%8F%96%E6%95%B0%E6%8D%AE%E6%BA%90%E8%BF%90%E8%A1%8C%E5%88%97%E8%A1%A8.md) 跟踪，`last_synced_at` 从 [获取数据源列表](%E8%8E%B7%E5%8F%96%E6%95%B0%E6%8D%AE%E6%BA%90%E5%88%97%E8%A1%A8.md) 读取。不要用此响应覆盖「获取数据源列表」的结果。
