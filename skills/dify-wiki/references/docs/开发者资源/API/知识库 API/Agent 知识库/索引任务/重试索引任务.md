# 重试索引任务

> 以同一个任务 ID 重新启动 `run_state` 为 `failed` 或 `canceled` 的索引任务，并返回更新后的任务。之后用同一个 ID 轮询 [获取索引任务](%E8%8E%B7%E5%8F%96%E7%B4%A2%E5%BC%95%E4%BB%BB%E5%8A%A1.md)。

任务进入 `published` 后，如需再次索引该文档，使用 [重新索引文档](../%E6%96%87%E6%A1%A3%E4%B8%8E%E5%88%86%E6%AE%B5/%E9%87%8D%E6%96%B0%E7%B4%A2%E5%BC%95%E6%96%87%E6%A1%A3.md)。重新索引流程详见 [重新索引并跟踪索引进度](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#track-indexing)。

处于 `run_state: superseded` 的尝试无法重试，即使其 `stage` 为 `canceled`。如果你从某次重新索引的响应中保存了更新的任务 ID，轮询该任务。
