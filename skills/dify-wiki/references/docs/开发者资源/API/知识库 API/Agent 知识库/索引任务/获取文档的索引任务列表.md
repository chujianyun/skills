# 获取文档的索引任务列表

> 列出文档因上传和同步产生的索引任务，最早的在前，每个任务都带有其结果。失败和已取消的任务也包括在内。

最新的任务在最后一页。如需查看当前正在运行的任务，改为读取 [获取文档](../%E6%96%87%E6%A1%A3%E4%B8%8E%E5%88%86%E6%AE%B5/%E8%8E%B7%E5%8F%96%E6%96%87%E6%A1%A3.md) 中的 `latest_task`。

未知的文档 ID（包括文档文件 ID）会返回 `200`，`data` 为空。一页中的任务可能少于 `limit` 个，因此要沿 `next_cursor` 一直翻页，直到它为 `null`。

各任务操作的适用场景，详见 [跟踪索引进度](../../../%E6%8C%87%E5%8D%97/API%20%E6%A6%82%E8%A7%88/%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93%20API.md#track-indexing)。
