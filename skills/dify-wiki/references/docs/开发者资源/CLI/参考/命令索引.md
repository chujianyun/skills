# 命令索引

> 按用途分组列出 difyctl 命令，说明每条命令的作用和使用条件

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cli/reference/command-index.md)。

要查看某条命令的标志，运行 `difyctl help <command>`。

命令中的 `<mode>` 表示应用类型，例如 `workflow` 或 `advanced_chat`。每条命令支持哪些类型，可用 `help` 查看。每个类型对应哪种应用，参见 [查找应用](../%E5%BA%94%E7%94%A8%E6%93%8D%E4%BD%9C/%E8%BF%90%E8%A1%8C%E5%BA%94%E7%94%A8.md#查找应用)。

## 工作空间 Skill 自部署

这些命令用于管理工作空间中的 Skill。如需将 `difyctl` Skill 安装到编码 Agent，改用 `install skills`。

| 命令 | 作用 | 使用条件 |
| :- | :- | :- |
| `get skill` | 列出工作空间中的 Skill，可按关键词或标签筛选，也可两者同时使用 | |
| `describe skill` | 显示 Skill 的详细信息，包括最新版本和 `draft_hash` | |
| `get skill version` | 列出 Skill 已发布的版本 | |
| `export skill` | 将 Skill 的草稿下载为 zip 文件。要下载已发布的版本，用 `--version-id` 指定 `get skill version` 列出的版本 ID | |
| `import skill` | 从文件夹创建 Skill；或传入 `--skill-id`，用文件夹替换现有 Skill 的草稿。导入会删除文件夹中没有的草稿文件。 加上 `--draft-hash`（值取自 `describe skill`），可以防止导入覆盖你读取之后 Skill 发生的改动 | 编辑及以上角色 |
| `publish skill` | 将 Skill 的草稿发布为新版本 | 编辑及以上角色 |
