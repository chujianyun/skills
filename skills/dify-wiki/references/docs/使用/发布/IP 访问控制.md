# IP 访问控制

> 使用可复用的 IP 策略，将应用访问范围限制为可信网络

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/publish/ip-access-control.md)。

IP 访问控制根据每个请求的来源公网 IP 地址限制对应用的访问。通过 IP 访问控制，你可以将应用访问范围限制为办公网络、指定服务器等可信网络。

在 **IP 策略** 中定义允许的地址，并在各应用的 **访问控制** 中选择该策略保护的访问入口。

> [!NOTE]
>
> IP 访问控制适用于 Professional 和 Team 套餐。
>
> 只有工作空间所有者和管理员可创建、编辑或删除 IP 策略。有权管理应用访问入口的编辑成员可使用现有策略配置该应用的访问控制。

## 管理 IP 策略

你可以在工作空间的 **设置** > **IP 策略** 中管理 IP 策略。同一策略可应用到该工作空间内的多个应用。

### 创建 IP 策略

点击 **创建 IP 策略**；如果工作空间已有策略，则点击 **添加**。输入 **名称**，将要允许的地址添加到 **允许列表**：

* 要允许当前使用的网络，点击当前 IP 地址旁的 **添加**。
* 向网络或系统管理员确认需要访问应用的网络或服务器的公网 IP 地址。

可输入单个 IPv4 或 IPv6 地址，也可用 CIDR 表示法输入地址范围。添加地址范围后，策略会允许来自该范围内所有 IP 地址的请求。

点击 **创建**。然后可前往应用的 **访问控制** 设置，[应用这份策略](IP%20%E8%AE%BF%E9%97%AE%E6%8E%A7%E5%88%B6.md#配置应用访问控制)。

### 编辑 IP 策略

在 **IP 策略** 中选择策略，更新 **允许列表**，然后点击 **保存**。

更改会影响所有使用这份策略的应用，无需重新发布即可生效。

### 删除 IP 策略

删除后无法恢复，所有使用这份策略的应用都将失去 IP 访问保护。

在 **IP 策略** 中，打开策略的 **…** 菜单，选择 **删除** 并确认。

## 配置应用访问控制

从 **工作室** 打开应用，或从 **Agents** 打开 Agent，然后进入其 **访问入口** 标签页。你会在右上角找到 **访问控制**。

### 设置访问控制

1. 在 **IP 策略** 下选择要使用的策略。
2. 在 **应用于** 下，开启要通过这份 IP 策略保护的访问入口，然后点击 **保存**。未选中的入口不受这份策略限制。

要检查设置，请分别从允许的网络和允许范围之外的网络测试选中的访问入口。

### 更换策略或受保护的访问入口

在 **访问控制** 中，点击 **编辑**，调整 **IP 策略** 或 **应用于** 下的选择，然后点击 **保存**。

保存也会重新启用已暂停的访问控制。

### 暂停或恢复访问控制

在 **访问控制** 中，关闭 **按 IP 地址限制访问** 并确认。重新开启开关即可恢复。

暂停期间，IP 限制停止生效，但设置会保留。

> [!WARNING]
>
> Professional 或 Team 订阅失效时，IP 访问保护也会停止生效，但设置会保留。续订或升级到其中任一套餐，即可重新使用 IP 访问保护。
