# 分享你的 AI 应用

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/publish/README.md)。

你已经在 Dify 中构建了出色的应用。现在让我们将它交付给你的用户。每个 Dify 应用都会自动以多种方式提供服务，选择最适合你情况的方式。

## 从 Web 应用开始

通过 Web 应用分享是你最快的路径。这些应用在你创建任何应用时会自动生成，无需设置即可立即工作。

**1. 点击发布**

在你的应用中点击 **发布** 以激活最新版本。

**2. 复制 URL**

在应用的 **访问入口** 标签页找到你的 Web 应用链接。

**3. 立即分享**

将链接发送给用户，或在分享前 [将访问范围限制为获准的网络](IP%20%E8%AE%BF%E9%97%AE%E6%8E%A7%E5%88%B6.md)。

> [!TIP]
>
> Web 应用在任何设备上都能工作，并自动适应屏幕尺寸。无需应用商店审批或安装。

## 发布工作原理

当你发布应用时，Dify 会在所有渠道激活你的最新配置。以下是幕后发生的情况：

* **Web 应用** 立即更新新功能和响应
* **API 端点** 提供最新的模型和工作流配置
* **嵌入式组件** 反映更新的样式和行为
* **MCP 服务器** 提供对当前应用功能的访问

> [!WARNING]
>
> 发布会用当前配置替换你的实时应用。用户将在下次交互中立即看到更改。

## 选择你的方法

> [accordion] 我想直接发布
>
> 分享一个链接并在几分钟内开始收集反馈。非常适合验证想法或为非技术用户提供服务。

> [accordion] 我正在构建一个产品
>
> 使用 **API 集成**。你可以控制界面、用户身份验证和数据处理。你的应用成为产品生态系统的一部分。

> [accordion] 我有一个现有网站
>
> 使用 **网站嵌入**。将 AI 功能添加到你当前的网站，无需重建任何内容。适用于任何网站技术。

> [accordion] 我想要扩展 AI 工具
>
> 使用 **MCP 服务器**。让你的应用作为原生工具在 Claude Desktop、Cursor 和其他 AI 开发环境中可用。

## 只允许可信网络访问 Professional Team

使用 [IP 访问控制](IP%20%E8%AE%BF%E9%97%AE%E6%8E%A7%E5%88%B6.md)，即使应用链接被转发，也可只允许可信网络访问。

## 发布最佳实践

在分享你的应用之前，请确保你已配置这些设置：

* **应用描述** - 帮助用户了解你的应用功能
* **图标和品牌** - 使你的应用易于识别且专业
* **访问控制** - 决定是否只允许获准的网络访问
* **速率限制** - 保护你的应用免受过度使用（对于 API 访问尤其重要）

> [!TIP]
>
> 所有发布方法都使用相同的应用配置。设置一次，随处发布。
