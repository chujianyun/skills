# 维护 Agent 知识库

> 知识库上线后，处理概览页面提示的问题，保持数据源同步，并及时更新文档

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/knowledge-base/maintain-knowledge-base.md)。

应用开始依赖某个知识库后，记得不时查看它的 **概览** 页面，处理页面上提示的问题。

## 关注概览页面

### 需要关注

* **数据源内容已过期**：该数据源从未成功同步过，或者距最近一次成功同步已超过 7 天。

  在 **数据源** 页面点击 **立即同步**。如果数据源显示 **错误**，先解决错误信息中指出的问题，再点击 **重试**。

* **文档处理失败**：某个文档的最新版本未能完成索引。如果之前的版本已经索引过，在更新成功之前，检索会继续使用旧版本。

  在 **文档** 页面将鼠标悬停在状态上查看原因，然后点击 **重试**。如果问题出在内容本身，先在源头修正，再重新同步。上传的文件该如何处理，详见 [更新文档](%E7%BB%B4%E6%8A%A4%20Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93.md#更新文档)。

* **查询质量需要检查**：在检索测试中或通过服务 API 提出的某个问题，返回的依据很弱，甚至没有依据。

  在 **检索测试** 页面重新运行这个问题。如果仍未命中，就 [将其保存为问题案例](%E6%B5%8B%E8%AF%95%E5%B9%B6%E8%B0%83%E4%BC%98%E6%A3%80%E7%B4%A2.md#问题案例)，再逐步解决。

* **模型配置未完成**：缺少某个必需的模型，或者还没有文档完成索引，模型因此尚未经过验证。

  在 **设置** > **检索** 中补上缺少的模型。如果知识库还是空的，添加一个文档即可。

### 查询结果

想知道检索有多少次没能满足用户，可查看 **查询结果** 图表。它会统计所选时间段内的每个问题，无论来自检索测试、应用还是 API 调用方，并按检索到的内容分类：

* **无依据**：没有返回任何内容。

* **低置信度**：返回了分段，但每个分段的得分都低于设定的阈值。仅在开启 **Score 阈值** 时出现。

* **已回答**：其余所有情况。

当 **低置信度** 或 **无依据** 的比例上升时，拿用户实际提出的问题来 [测试并调优检索](%E6%B5%8B%E8%AF%95%E5%B9%B6%E8%B0%83%E4%BC%98%E6%A3%80%E7%B4%A2.md)。

## 保持数据源最新

如果等不及下一次定时同步，可在 **数据源** 页面打开该数据源的菜单，点击 **立即同步**。

如需为数据源添加页面或文件，编辑该数据源并更新所选内容。

移除数据源不会删除它导入的文档。这些文档会留在知识库中，但不再更新。如果不再需要这些内容，需另行删除。

## 更新文档

要更新上传的文件，先删除旧文档，再上传新版本。上传同名文件只会新增一个文档，不会替换原来的那个。

如果内容只是暂时过时，可以禁用文档，不必删除。禁用期间它不会参与检索，重新启用后即可恢复。
