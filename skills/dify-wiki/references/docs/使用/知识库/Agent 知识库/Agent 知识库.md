# Agent 知识库

> 由知识库替你阅读、整理和索引内容，你只需决定放入哪些内容，并检查检索结果

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/knowledge-base/overview.md)。

> [!NOTE]
>
> Agent 知识库目前处于 Beta 阶段。

Agent 知识库会替你处理内容，由推理模型逐篇阅读并整理文档，再由嵌入模型让文档可供检索。你要做的不多：决定放入哪些内容，设定检索深度，再检查返回的结果。

在默认深度下，检索会按语义和关键词匹配内容。把 [检索深度](%E6%A3%80%E7%B4%A2%E8%AE%BE%E7%BD%AE.md#retrieval-depth) 调深后，知识库会像 Agent 一样探究问题：跨文档追踪相关主题，或者把问题拆成几部分，再阅读完整的章节。

除了应用，你本机上的编码 Agent 也能通过 [Dify CLI](%E6%8E%A5%E5%85%A5%E5%BA%94%E7%94%A8%E3%80%81Agent%20%E5%92%8C%E4%BB%A3%E7%A0%81.md#from-your-coding-agent) 读取其中的文档，像浏览文件夹里的文件一样。

> [!TIP]
>
> * 如需与经典知识库比较，参见 [该创建哪一类知识库](../%E7%9F%A5%E8%AF%86%E5%BA%93.md#choose)。
>
> * 如需把经典知识库迁移过来，参见 [如何升级](%E4%BB%8E%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93%E5%8D%87%E7%BA%A7%E5%88%B0%20Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93.md)。
