# 创建 Agent 知识库

> 创建 Agent 知识库，从数据源导入或上传文件来添加内容，为测试做好准备

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/knowledge-base/create-knowledge-base.md)。

前往 **知识库**，切换到 **Agent**，然后点击 **创建**。

## 设置基本信息

为知识库填写名称和描述，并设定哪些成员能查看它、把它接入自己的应用。以上各项之后都可在知识库的设置中修改。

知识库使用工作空间的默认模型。要让文档中的图片也能被检索到，需要使用 [支持视觉的嵌入模型](%E5%A4%9A%E6%A8%A1%E6%80%81%E6%A3%80%E7%B4%A2.md)。

## 添加内容

内容存放在别处且会持续变化时，连接数据源；手头是独立的文档时，直接上传文件。一个知识库可同时包含这两类内容。

> [!TIP]
>
> 先导入少量有代表性的文档，等检索调优到位后再导入其余内容。之后更换嵌入模型会重新索引所有文档，趁知识库还小时更换，消耗的 token 也更少。

### 连接数据源

数据源借助 Firecrawl、Notion、Google Drive 等数据源集成，从网站、文档平台或云盘导入内容。

**1. 选择提供商**

从工作空间已安装的数据源集成中选择一个，或点击 **更多提供商** 浏览并安装新的集成。

> [!TIP]
>
> 如果现有集成都满足不了需求，可以 [自行开发](../../../%E5%BC%80%E5%8F%91%E8%80%85%E8%B5%84%E6%BA%90/%E6%8F%92%E4%BB%B6%E5%BC%80%E5%8F%91/%E5%BC%80%E5%8F%91%E6%8C%87%E5%8D%97%E4%B8%8E%E7%A4%BA%E4%BE%8B/%E6%8C%89%E6%8F%92%E4%BB%B6%E7%B1%BB%E5%9E%8B/%E6%95%B0%E6%8D%AE%E6%BA%90%E6%8F%92%E4%BB%B6.md)，或向社区 [提出需求](https://github.com/langgenius/dify-plugins/issues/new?template=plugin_request.yaml)。

然后在 **集成** > **数据来源** 中输入对应的 API 密钥或授权账号，完成连接。

**2. 选择要同步的内容**

> [tab] 网站抓取
>
> 1. 为数据源命名并粘贴 URL，然后检查 **抓取选项** 中的默认设置，按需调整。
>
> 2. 点击 **抓取并预览**，从结果中选择要导入的页面。

> [tab] 在线文档
>
> 从已连接的账号中选择要导入的页面。

> [tab] 在线云盘
>
> 从已连接的云盘或存储桶中选择要导入的文件。

**3. 设置同步策略**

选择预设的同步周期，设置自定义间隔（1 小时至 30 天），或改为手动同步。

同步频率按内容的更新频率来定。同步时发现变化，就会重新索引有变化的内容，这会消耗 token。

### 上传文件

单个文件最大 15 MB。

> [!TIP]
>
> 批量上传适用于 Professional 和 Team 套餐。[了解更多](https://dify.ai/pricing)。

## 后续步骤

在 **文档** 页面看到文档显示为 **就绪** 后，还要完成三步，知识库才适合面向真实用户：

1. [检查已索引的文档](%E6%A3%80%E6%9F%A5%E5%B7%B2%E7%B4%A2%E5%BC%95%E7%9A%84%E6%96%87%E6%A1%A3.md)：打开文档，确认章节、摘要和分段都处理得当。

2. [测试检索并调优设置](%E6%B5%8B%E8%AF%95%E5%B9%B6%E8%B0%83%E4%BC%98%E6%A3%80%E7%B4%A2.md)：提出应用实际会遇到的问题，反复调优，直到结果稳定可靠。

3. [接入应用、Agent 和代码](%E6%8E%A5%E5%85%A5%E5%BA%94%E7%94%A8%E3%80%81Agent%20%E5%92%8C%E4%BB%A3%E7%A0%81.md)：把它添加到需要依据它作答的应用中。
