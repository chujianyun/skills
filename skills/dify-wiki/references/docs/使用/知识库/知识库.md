# 知识库

> 让应用依据你自己的内容作答，并选定要使用哪一类知识库

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/knowledge/overview.md)。

有了知识库，应用就能用你自己的内容回答问题。每收到一个问题，系统都会找出最相关的段落，连同问题一起交给模型。这样，回答依据的就是你的内容，而不只是模型在训练中学到的知识。

凡是应用需要知道、模型本身却不了解的内容，都适合放进知识库，例如帮助中心、内部制度、产品目录或研究资料。可按领域或团队各建一个知识库，再接入需要它的应用。

## 两类知识库

选哪一类，主要看你在构建什么应用，以及想对内容处理过程掌控到什么程度。

> [tab] Agent 知识库
>
> [Agent 知识库](Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93/Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93.md) 配置起来很简单：添加内容后，它会自行整理并索引全部内容。
>
> 希望获得以下能力时，适合选择它：
>
> * **难题也能深入检索**：可将 [检索深度](Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%A3%80%E7%B4%A2%E8%AE%BE%E7%BD%AE.md#retrieval-depth) 设为「快速」「深度」或「研究」。
> * **内容始终保持最新**：已连接的网站、在线文档和在线云盘会按你设定的同步策略自动更新。
> * **内置质量检查**：每次改动后重新测试关键问题，并跟踪检索未命中的情况。
> * **编码 Agent 也能访问**：可通过 Dify CLI 读取其中的内容。
>
> Workflow 应用、Chatflow 应用和新 Agent 都可使用它。新项目建议从这里开始。

> [tab] 经典知识库
>
> 在 [经典知识库](%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93.md) 中，内容如何分段、索引和检索，都由你自己决定。
>
> 有以下需求时，适合选择它：
>
> * **聊天助手、文本生成应用或旧版 Agent 应用** 需要基于它作答。Workflow 和 Chatflow 应用则两类知识库都能使用。
> * **需要更细致地控制内容处理**，甚至用 [知识流水线](%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%9E%84%E5%BB%BA%E8%87%AA%E5%AE%9A%E4%B9%89%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%9E%84%E5%BB%BA%E8%87%AA%E5%AE%9A%E4%B9%89%E7%9F%A5%E8%AF%86%E5%BA%93.md) 搭建完整的处理链路。
> * **内容要留在自有系统中**，以 [外部知识库](%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93/%E8%BF%9E%E6%8E%A5%E5%A4%96%E9%83%A8%E7%9F%A5%E8%AF%86%E5%BA%93/%E8%BF%9E%E6%8E%A5%E5%A4%96%E9%83%A8%E7%9F%A5%E8%AF%86%E5%BA%93.md) 的形式接入。
> * **需要上传超过 15 MB 的文件**：在 Professional 和 Team 套餐中，单个文件最大可达 50 MB。

> [!NOTE]
>
> 大多数经典知识库日后都可 [升级](Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93/%E4%BB%8E%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93%E5%8D%87%E7%BA%A7%E5%88%B0%20Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93.md) 为 Agent 知识库，但 Agent 知识库无法转换为经典知识库。

## 两类知识库对比

| | Agent 知识库 | 经典知识库 |
| :- | :- | :- |
| 适用应用 | Workflow 和 Chatflow 应用、新 Agent | 聊天助手、文本生成应用、旧版 Agent 应用、Workflow 和 Chatflow 应用 |
| 内容来源 | 上传文件、抓取网站、在线文档、在线云盘 | 上传文件、抓取网站、Notion；还可通过知识流水线接入其他数据源，或接入外部知识库 |
| 文件大小 | 所有套餐均为单个文件最大 15 MB | Sandbox 套餐单个文件最大 15 MB，Professional 和 Team 套餐最大 50 MB |
| 可配置项 | 模型和检索深度，以及 Top K 和可选的分数阈值 | 模型、分段模式与分段长度、索引方式和检索方式，以及 Top K 和可选的分数阈值；也可用知识流水线配置整条处理链路 |
| 检索 | 按语义和关键词匹配；调深检索深度后，还会追踪相关主题，或把问题拆成几部分 | 按语义、按关键词，或两者结合 |
| 索引所用模型 | 推理模型和嵌入模型 | 嵌入模型（高质量索引），或不使用模型（经济索引） |
| 内容更新 | 每个数据源可单独设置同步策略 | Notion 和网站文档需手动同步 |
| 质量测试 | 检索测试、参考问题、评测和问题案例 | 检索测试 |
| 监控 | 「概览」页面，显示需要关注的事项以及各问题的作答情况 | 无 |
| 在 Dify 之外访问 | 服务 API 和 [Dify CLI](Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%8E%A5%E5%85%A5%E5%BA%94%E7%94%A8%E3%80%81Agent%20%E5%92%8C%E4%BB%A3%E7%A0%81.md#from-your-coding-agent) | 服务 API |

两类知识库的权限选项相同，并共用文档配额、请求频率限制和知识库 API 密钥。使用支持视觉的嵌入模型时，两类知识库也都能检索图片。
