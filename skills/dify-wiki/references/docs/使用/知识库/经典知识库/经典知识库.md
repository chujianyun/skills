# 经典知识库

> 自己设置分段、索引和检索方式，设计专属的处理流程，或接入你已在运行的外部知识库

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/knowledge/readme.md)。

在经典知识库中，内容如何分段、索引和检索，都由你自己决定。它还能接入你已在运行的知识库，由 Dify 直接在其中检索，无需把内容复制过来。

聊天助手、文本生成应用和旧版 Agent 应用都可基于它作答，Workflow 和 Chatflow 应用也可通过知识检索节点使用它。

> [!TIP]
>
> * 如需与 Agent 知识库比较，参见 [该创建哪一类知识库](../%E7%9F%A5%E8%AF%86%E5%BA%93.md#choose)。
>
> * 即用型经典知识库可 [升级](../Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93/%E4%BB%8E%E7%BB%8F%E5%85%B8%E7%9F%A5%E8%AF%86%E5%BA%93%E5%8D%87%E7%BA%A7%E5%88%B0%20Agent%20%E7%9F%A5%E8%AF%86%E5%BA%93.md) 为 Agent 知识库，外部知识库和用知识流水线构建的知识库则不行。

## 创建知识库

* **[创建即用型知识库](%E5%88%9B%E5%BB%BA%E5%8D%B3%E7%94%A8%E5%9E%8B%E7%9F%A5%E8%AF%86%E5%BA%93/%E5%88%9B%E5%BB%BA%E5%8D%B3%E7%94%A8%E5%9E%8B%E7%9F%A5%E8%AF%86%E5%BA%93.md)**：导入数据，再设定内容如何分段、索引和检索。

* **[构建自定义知识库](%E6%9E%84%E5%BB%BA%E8%87%AA%E5%AE%9A%E4%B9%89%E7%9F%A5%E8%AF%86%E5%BA%93/%E6%9E%84%E5%BB%BA%E8%87%AA%E5%AE%9A%E4%B9%89%E7%9F%A5%E8%AF%86%E5%BA%93.md)**：标准设置不适合你的内容时，可用知识流水线设计专属的处理流程，自行选择数据源，以及提取、分段和索引内容的每个步骤。

* **[连接外部知识库](%E8%BF%9E%E6%8E%A5%E5%A4%96%E9%83%A8%E7%9F%A5%E8%AF%86%E5%BA%93/%E8%BF%9E%E6%8E%A5%E5%A4%96%E9%83%A8%E7%9F%A5%E8%AF%86%E5%BA%93.md)**：通过 API 检索你已在运行的知识库，无需把内容迁入 Dify。

## 测试与改进

* **[测试召回效果](%E6%B5%8B%E8%AF%95%E6%A3%80%E7%B4%A2.md)**：拿用户可能会问的问题试一试，看看会返回哪些分段。

* **[调整知识库设置](%E7%AE%A1%E7%90%86/%E8%B0%83%E6%95%B4%E7%9F%A5%E8%AF%86%E5%BA%93%E8%AE%BE%E7%BD%AE.md)**：更换嵌入模型、修改检索设置，或将索引方式从「经济」切换为「高质量」。

* **[利用元数据增强检索](%E7%AE%A1%E7%90%86/%E7%AE%A1%E7%90%86%E6%96%87%E6%A1%A3%E5%85%83%E6%95%B0%E6%8D%AE.md)**：为文档标注元数据，让检索只在符合条件的文档中进行。
