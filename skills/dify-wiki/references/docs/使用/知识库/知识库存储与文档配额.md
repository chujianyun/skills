# 知识库存储与文档配额

> 工作空间的知识库最多能容纳多少文档、存储多少索引数据，哪些内容计入各项配额，以及达到上限后如何处理

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/knowledge/knowledge-storage-limit.md)。

每个工作空间都有两项知识库配额：一项限制文档数量，另一项限制知识库可存储的索引数据量。经典知识库和 Agent 知识库共用这两项配额。

工作空间所有者和管理员可在 **设置** > **账单** 的 **文档上传配额** 和 **知识库数据存储空间** 中查看用量。各套餐的配额详见 [Dify 定价页面](https://dify.ai/pricing)。

## 文档配额

文档配额限制的是工作空间内所有知识库的文档总数，无论文档是上传的还是从数据源导入的。每个文档都计入，已禁用、已归档和处理失败的文档也不例外。

达到配额后，凡是会新增文档的上传和导入都会失败。如需继续添加，可删除不再需要的文档，或升级套餐。

## 知识库数据存储空间

每个文档都会切分成分段，也就是检索时返回的段落。知识库数据存储空间以可检索的形式保存这些分段，包括分段的文本和向量。向量是分段的数值表示，语义检索靠它按含义匹配内容。

原始文件不占用这部分空间，因此用量取决于文档索引后产生的数据量，与文件大小无关。

### 哪些内容占用存储空间

在经典知识库中，以 **高质量** 索引方式索引的文档会为每个分段存储一个向量，父子模式下则为每个子分段存储一个向量。以 **经济** 方式索引的文档改用关键词索引，不计入知识库数据存储空间。

在 Agent 知识库中，每个分段都会同时存为向量和文本，前者用于按含义匹配，后者用于按关键词匹配。知识图谱还会为它提取的主题以及主题之间的关联另外存储向量。

无论哪类知识库，使用多模态嵌入模型时，每张图片也会额外存储一个向量。嵌入模型还决定每个向量的大小，例如在默认设置下，OpenAI 的 `text-embedding-3-large` 生成的向量是 `text-embedding-3-small` 的两倍大。

用量数据不是实时的，上传或删除后可能要过几分钟才会更新。

### 上传到经典知识库会超出上限时

在建立索引之前，Dify 可能会根据预估的存储用量拒绝某次上传。被拒绝的文档会以 **错误** 状态留在文档列表中。

要索引该文档，可升级套餐或释放存储空间，然后点击文档列表上方的 **重试**。释放出的空间未必能马上在重试时生效，工作空间里还有其他文档正在索引时尤其如此。

也可删除该文档，调大分段长度后重新上传。这样可能减少分段数量，但分段越大，每次检索返回的段落也可能越长、越不精确。

### 存储空间已满时

用量达到套餐上限后，两类知识库都无法再添加内容：

* **经典知识库** 不能再上传文档，也不能添加或编辑分段。修改分段设置等操作需要重新索引，这时也无法进行。在 Dify 中，启用、禁用、归档和撤销归档文档同样会被拦下，不过仍可通过服务 API 修改文档状态。即使知识库使用 **经济** 索引方式也一样，因为这项限制针对的是整个工作空间。
* **Agent 知识库** 无法处理新增或修改过的内容。新的上传和导入可能直接被拒绝，正在处理、同步或重新索引的文档则会处理失败。嵌入模型也无法更换。

  检索和删除仍可正常使用。有了空间之后，重新添加被拒绝的内容，并重试处理失败的文档。

要解除限制，可释放存储空间或升级套餐。

如果套餐降级或订阅到期导致数据量超出新套餐的上限，数据会全部保留，应用也仍可检索这些知识库。但在用量降到上限以内或重新升级之前，都无法添加内容。

### 释放存储空间

删除不再需要的文档或知识库即可。Agent 知识库在后台删除内容，因此空间可能还要再过几分钟才会释放出来。

重新添加内容或重试失败的文档前，先确认 **知识库数据存储空间** 显示的用量已低于上限，否则可能再次失败。
