# Dify 文档

Dify 是一个用于构建 AI 应用的开源平台。你可以创建 Agent、Agentic 工作流和聊天机器人，让它们利用你自己的数据，并发布为 Web 应用或通过 API 集成。

> [card] [构建你的第一个应用](../%E5%AD%A6%E4%B9%A0/%E6%95%99%E7%A8%8B/30%20%E5%88%86%E9%92%9F%E5%BF%AB%E9%80%9F%E5%85%A5%E9%97%A8.md)
>
> 刚接触 Dify？从这里开始：构建一个可运行的 AI 应用，并在过程中掌握核心概念。

## 选择 Dify 的运行方式

> [card] [Dify Cloud](%E4%BD%BF%E7%94%A8%20Dify.md)
>
> 在托管平台上立即开始构建。无需安装，并包含免费的 Sandbox 套餐。

> [card] [自部署](https://docs.dify.ai/zh/self-host/deploy/overview.md)
>
> 在你自己的基础设施上运行开源的 Community Edition。使用 Docker Compose 几分钟即可完成部署。
