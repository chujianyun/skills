# 工作空间

> 工作空间是 Dify 中的基础组织单位，你的团队所构建、配置和管理的一切都存在于工作空间中

> 本文档由 AI 自动翻译。如有任何不准确之处，请参考 [英文原版](https://docs.dify.ai/en/cloud/use-dify/workspace/readme.md)。

工作空间是你团队在 Dify 中的完整 AI 环境。它包含并隔离你的组织所需的一切：应用、知识库、团队成员、模型配置、集成和账单。

## 工作空间概念模型

Dify 中的每个资源都属于一个工作空间。当你创建应用时，它会继承工作空间的模型配置。当你添加团队成员时，他们会根据其角色获得对工作空间资源的访问权限。当你配置模型或安装集成时，它们对整个工作空间都可用。

```
🏢 你的组织
└── 📁 工作空间
    ├── 🤖 应用（聊天机器人、工作流、Agent）
    ├── 📊 知识库（文档、嵌入向量）
    ├── 👥 团队成员（角色和权限）
    ├── 🔧 集成（模型供应商、工具、自定义代码）
    └── 💳 账单（订阅、限制、使用情况）
```

这种以工作空间为核心的设计意味着你的资源与其他组织完全隔离，团队成员只能访问他们被允许查看的内容，你只需为整个工作空间配置一次模型和账单。

## 工作空间创建

首次登录时会自动创建工作空间，你将成为拥有完全权限的所有者。每个账户只能创建一个工作空间。

> [!NOTE]
>
> 你的个人账户可以同时归属于多个工作空间。通过左上角的工作空间选择器在它们之间切换。

## 资源如何连接

你构建的应用可以使用工作空间中配置的任何模型供应商，访问所有工作空间知识库，并使用已安装的集成。团队成员根据其工作空间权限查看应用。

工作空间角色决定对所有资源的访问权限：

* **所有者** 控制账单、模型供应商和工作空间设置
* **管理员** 管理团队成员并配置模型和集成
* **编辑者** 构建应用并管理知识库
* **成员** 使用已发布的应用
