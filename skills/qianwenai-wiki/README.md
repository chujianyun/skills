# qianwenai-wiki

千问AI平台官方文档的离线检索 Skill，覆盖开发者指南、API / SDK / CLI 参考、Token Plan、资源、更新日志和 OpenAPI Schema。

它适合回答模型接入、接口参数、SDK 示例、计费与排障问题。Skill 默认以打包快照为依据，并通过全文检索只加载相关页面；价格、额度、模型上下线等易变化信息应再核对官网。

## 使用

安装后可以直接说：

- “用 qianwenai-wiki 给我一个 OpenAI SDK 调用千问的 Python 示例”
- “Qwen Realtime API 的鉴权和连接方式是什么？”
- “万相文生视频接口有哪些必填参数？”
- “DASHSCOPE_API_KEY 报鉴权失败怎么排查？”

离线资料仅供检索与引用，版权归原权利人所有。重新同步会访问官方站点；覆盖已有快照需要显式确认，实际调用模型 API 可能产生费用。
