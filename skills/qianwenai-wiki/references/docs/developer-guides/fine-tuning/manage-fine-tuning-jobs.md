# 管理微调任务

> 在千问AI平台控制台中监控、管理和部署微调任务。

创建微调任务后，使用 [千问AI平台控制台](https://platform.qianwenai.com/home/model-production/fine-tuning)监控进度、查看结果并部署训练好的模型。

## 任务列表

微调列表页面展示您的所有任务。支持按任务名称搜索，以及使用筛选器缩小范围：

- **全部类型**：按训练类型筛选（SFT / DPO / CPT）。
- **全部状态**：按任务状态筛选。

在此您可以：

- 点击任务名称查看详情页。
- 对已完成的任务点击**去部署**创建部署。
- 点击**删除**移除任务及其关联数据。

## 任务详情页

点击任务名称打开详情页，包含四个标签页：

### 详情标签页

查看完整的训练配置——基础模型、超参数、数据集引用和 Token 消耗。使用此标签页核实提交的信息。

### 指标标签页

通过图表监控训练质量：

- **训练 loss**：应随模型改进逐步下降。
- **验证 loss**：如果与训练 loss 发生偏离，说明模型出现过拟合。
- **准确率**：训练集和验证集的 Token 级别准确率。

### 日志标签页

查看原始训练日志，用于调试失败或跟踪详细进度。

### 输出标签页

在此管理已保存的检查点。每个检查点显示保存时的 epoch、发布状态和剩余 TTL。点击**发布**将检查点作为自定义模型发布，以便部署。

## 发布检查点

要使用检查点，必须先发布：

1. 前往任务详情页的**输出**标签页。
2. 点击目标检查点旁边的**发布**。
3. 指定模型名称。发布的模型将出现在[自定义模型](/developer-guides/custom-models/overview)列表中。

## 部署训练好的模型

自定义模型在创建部署之前无法通过 API 调用。发布检查点后：

1. 前往[部署页面](https://platform.qianwenai.com/home/model-production/deployments)。
2. 点击**创建部署**并选择您的自定义模型。
3. 部署达到**运行中**状态后，使用其模型代码调用 API。

完整指南请参见[部署概览](/developer-guides/deployment/overview)。

## 停止和删除任务

- **停止**：取消正在运行的任务。已完成的检查点会保留。
- **删除**：移除任务及其关联数据。此操作不可撤销。

## 任务状态

| 状态   | 说明                 |
| ---- | ------------------ |
| 初始化中 | 任务已提交，正在分配资源并排队调度。 |
| 运行中  | 训练正在进行中。           |
| 已完成  | 训练成功完成。            |
| 失败   | 训练遇到错误。请查看日志了解详情。  |
| 取消中  | 任务正在取消，等待进行中的操作结束。 |
| 已取消  | 任务已被手动取消。          |
