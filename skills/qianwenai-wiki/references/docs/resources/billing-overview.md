# 充值及查看余额

> 为账户充值并查看可用额度

## 可用额度

**可用额度**是您当前可用于消费的余额，当账户存在退款、调账等操作时可能为负值，计算公式如下：

```
可用额度 = 现金余额 + 信控额度 + 信控退款 - 当月欠费 - 历史欠费
```

| 组成部分 | 说明                           |
| ---- | ---------------------------- |
| 现金余额 | 账户内剩余的资金（含充值和退款到账）           |
| 信控额度 | 合同约定的信用额度（信控用户专属）            |
| 信控退款 | 使用信控额度支付的消费，发生退订、降配等情况时产生的退款 |
| 当月欠费 | 本月已产生但尚未结算的费用                |
| 历史欠费 | 已出账但尚未还款的历史账单                |

可用额度降至零后，API 调用将受到限制。

在[账单概览](https://platform.qianwenai.com/home/billing/overview)页面可查看当前可用额度及各组成部分的明细。

## 充值

### 支持的充值方式

| 充值方式 | 到账时间     | 限制               | 适用场景                    |
| ---- | -------- | ---------------- | ----------------------- |
| 支付宝  | 实时       | 不支持花呗和信用卡        | 操作便捷，适合小额快速充值           |
| 银联在线 | —        | 不支持信用卡           | 无需开通网银，使用银行借记卡直接支付      |
| 个人网银 | —        | 支持 21 家银行，不支持信用卡 | 已开通个人网银、需要较高单笔支付额度的个人用户 |
| 企业网银 | —        | 支持 32 家银行，不支持信用卡 | 使用银行 U 盾等企业安全措施的对公支付场景  |
| 对公汇款 | 1–5 个工作日 | 汇款人须与实名认证信息一致    | 企业大额充值，或需要财务对公转账的场景     |

完成充值后，可在记录页面查看充值历史。

### 充值步骤

1. 登录[千问AI平台](https://platform.qianwenai.com/)，进入**账单**页面。
2. 点击**充值**。
3. 选择充值方式，输入充值金额。
4. 按页面提示完成支付。

<Note>
  充值前须完成实名认证，且充值账户名称须与实名认证信息一致。
</Note>

### 对公汇款

对公转账指通过银行渠道向千问AI平台账户充值，余额可用于消费。

**操作步骤**：

1. 核对实名信息：确认汇款账户与千问AI平台账号实名信息一致。
2. 获取专属账号：获取您的专属汇款账号。
3. 执行汇款：通过网银或线下银行柜台向专属账号汇款，1\~5 个工作日到账（以银行实际为准），到账后千问AI平台会发送短信通知。
4. 查询记录：进入账单概览界面，点击**可用余额**下方的**记录**按钮，查看汇款记录。

## 余额告警

当可用额度降至设定阈值时，系统会发送告警通知，帮助您及时充值，避免服务中断。

**设置方法**：

1. 进入**账单** → **可用额度**页面。
2. 设置告警阈值金额。
3. 系统将在可用额度低于该金额时通过邮件、短信等方式发送通知。
