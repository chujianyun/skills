# 免费额度

> 新用户免费额度

<div className="for-agent-only" style={{display: "none"}}>
  首次注册千问AI平台后，大部分模型会自动获得独立的免费额度。其中文本类模型的免费额度累计超过7000万 Token。该总量会随新模型上线而变化。具体哪些模型有免费额度，以权益页面显示为准。
</div>

## 规则

### 有效期

免费额度的有效期通常为 90 天，但两类额度的起算时间不同：

- **新用户免费额度**：开通账号时，已发布的模型会自动获得免费额度，有效期从**账号开通之日**起计算。
- **新发布模型免费额度**：开通账号后新上线的模型，有效期从**模型发布之日**起计算。

免费额度过期后自动失效，不支持补发、延期或重置：

- 额度有效期内是否使用均不会暂停计时；
- 额度过期后，剩余部分自动作废，不会重新发放或延长；
- 同一认证主体下重新注册账号，无法再次领取新人免费额度。

额度到期或用完后，继续调用模型将产生[费用](/developer-guides/getting-started/pricing)。

### 适用范围

不同模型（含同一模型的不同快照版本）的免费额度相互独立，不互通、不共享。

- 每个模型均有独立的免费额度（通常为 100 万 Token），不能跨模型合并或转移使用。
- 带日期后缀的快照版本（如`qwen-max-2026-05-17`）与不带日期的最新版本（如`qwen-max`）视为两个独立模型，各自拥有独立额度。
- 当某个模型额度用完后，系统不会自动切换到其他有额度的模型。如需使用其他模型的免费额度，需在代码或工具配置中手动修改`model`参数。

免费额度仅抵扣模型实时推理（调用）产生的费用，不可抵扣以下场景：

- [批量调用](/developer-guides/text-generation/batch)
- [内置工具调用费用](/developer-guides/getting-started/pricing#built-in-tools)（联网搜索、图片搜索等）
- 模型微调
- 模型部署
- 自定义模型（微调后模型、已部署模型）

## 获取免费额度

[注册](https://platform.qianwenai.com/)千问AI平台即可激活免费额度。

<Note>
  如果注册后未收到免费额度，页面会提示"为保障账号安全与资源合理使用，请完成认证后领取免费额度"。请前往[权益](https://platform.qianwenai.com/home/benefits)页面，点击**去认证**完成账号认证。认证成功后，免费额度将自动发放。
</Note>

## 查看剩余额度

前往[权益](https://platform.qianwenai.com/home/benefits)页面查看和管理所有模型的免费额度。您也可以从[控制台首页](https://platform.qianwenai.com/home)，依次点击**我的权益** > **查看免费额度**进入该页面。
该页面提供：

- **可用模型**：当前有免费额度的模型数量
- **即将过期的模型**：免费额度将在 7 天内过期的模型
- **余额偏低模型**：免费额度已消耗 80% 以上的模型
- **不可用模型**：近 180 天免费额度已过期或已用尽的模型

可切换模型类型（向量模型、大语言模型、多模态模型、语音模型、视觉模型）并查看详细信息：

- 模型、免费额度、已消耗、剩余比例、到期时间、状态
- 在**操作**列开启**免费额度用尽即停**开关，在额度用尽时自动停止

<Note>
  控制台显示的免费额度数据存在分钟级延迟，非实时数据。
</Note>

## 使用免费额度

调用模型进行实时推理时，免费额度会自动扣减。详情请参见[首次 API 调用](/developer-guides/getting-started/first-api-call)。

<Warning>
  未认证用户，免费额度耗尽后将停止响应并返回错误码 `AllocationQuota.FreeTierOnly`。完成认证并充值后可继续按量付费。

  已认证用户，免费额度耗尽后继续调用会按量计费，费用从账户余额中扣除。可提前开启[免费额度用尽即停](#免费额度用尽即停)功能，防止产生意外费用。
</Warning>

## 免费额度用尽即停

开启免费额度用尽即停后，免费额度用尽时将无法调用模型，且不会产生计费。

- **未认证用户**：该功能默认开启，无法关闭。
- **已认证用户**：该功能默认关闭。可前往[权益](https://platform.qianwenai.com/home/benefits)页面开启或关闭。

<Note>
  未认证用户在控制台上看不到**免费额度用尽即停**开关，该功能已自动为其启用。
</Note>

#### 如何启用

前往[权益](https://platform.qianwenai.com/home/benefits)页面：

- **单个模型**：打开目标模型的**免费额度用尽即停**开关
- **批量操作**：
  1. 点击右上角的**免费额度用尽时自动停止**下拉菜单
  2. 选择**启用已选模型**进入批量模式（表格中出现复选框）
  3. 勾选要启用的模型，然后点击**启用已选模型**；或直接点击**启用所有模型**
  4. 完成后点击**退出批量模式**

如果某个模型未显示该开关，说明该模型的免费额度已用完或已过期，或该模型不提供免费额度。

#### 如何关闭

- **未认证用户**：该功能无法关闭。完成认证后可管理此功能。
- **已认证用户**：若已启用，可前往[权益](https://platform.qianwenai.com/home/benefits)页面关闭。

## 常见问题

### 免费额度用完后会发生什么？

**未认证用户**：免费额度用完后无法继续调用。完成认证并充值后可继续按量付费。

**已认证用户**：

- 若已开启[免费额度用尽即停](#免费额度用尽即停)，免费额度用完后无法继续调用，需要关闭该功能方可继续按量付费。
- 若未开启[免费额度用尽即停](#免费额度用尽即停)，正在进行的模型调用不会中断。超出免费额度的 token 将按[模型调用计费](/developer-guides/getting-started/pricing)中的输入/输出费用计费，费用按量自动扣除，可能导致欠费。

账户欠费时，即使其他模型仍有免费额度也无法调用。

调用模型前，请检查免费额度并使用[预算管理](/resources/bill-query)。

### 为什么产生了费用？

**可能的原因**：

- 使用了没有免费额度的模型。例如：qwen3.7-max、qwen3.7-max-2026-06-08 和 qwen3.7-max-2026-05-20 的免费额度是分开的。
- 免费额度不可抵扣[批量调用](/developer-guides/text-generation/batch)的费用。
- 免费额度数据存在分钟级延迟。页面可能显示有剩余额度，但实际已用完，从而产生费用。稍后再次查看以获取最新数据。

可在[按量付费](/resources/bill-query)页面确认费用明细。

### 如何避免产生费用？

免费额度用完后，费用会自动从账户余额中扣除。管理费用风险的方法：

- **删除 API Key**：前往千问AI平台 [API Key](https://platform.qianwenai.com/home/api-keys) 页面删除已创建的 API Key。删除后将无法通过 API 调用模型，从而避免继续产生费用。
- **设置余额预警**：配置[余额预警](https://platform.qianwenai.com/home/billing/overview)。当余额低于预警值时，您将收到短信或邮件通知。

### 有剩余额度，为什么调用失败？

账户可能存在欠费。欠费后所有模型调用都会被拒绝——即使仍有免费额度。

### 为什么看不到免费额度和有效期？

如果**免费额度**列显示**无免费额度**或该区域未显示，可能是以下原因之一：

- **免费额度已到期或耗尽**：免费额度有效期为 90 天，从开通千问AI平台账号、模型发布或模型申请通过之日起计算（以较晚者为准），到期或耗尽后将不再显示，继续调用模型将产生费用。
- **该模型不提供免费额度**：部分模型不参与新人免费额度发放，具体以[权益](https://platform.qianwenai.com/home/benefits)页面显示为准。

### 使用哪种 API Key 才能消耗免费额度？

API Key 本身不绑定特定模型，同一个 API Key 可调用所有模型，无需为使用免费额度单独创建新的 API Key。

实时调用时，系统将自动优先使用免费额度抵扣，无需手动设置。按消耗优先级依次为：免费额度 > 资源包 > 按量付费。

<Note>
  Token Plan 专属 API Key 不消耗免费额度，使用专属 API Key 调用模型将直接按量付费。如需使用免费额度，请改用通用 API Key。
</Note>
