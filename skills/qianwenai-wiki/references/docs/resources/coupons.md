# 使用和管理优惠券

> 查看、使用和管理您的优惠券

优惠券是千问AI平台在营销活动中为用户提供的优惠权益，按照发放类型可分为代金券、满减券和折扣券。

## 优惠券类型

按发放类型，优惠券分为以下三种：

| 类型      | 说明                                      |
| ------- | --------------------------------------- |
| **代金券** | 具有固定面额，在额度范围内可多次抵扣，直至余额用尽               |
| **满减券** | 具有使用门槛（如"满 100 元减 10 元"），订单金额满足条件后一次性抵扣 |
| **折扣券** | 无使用门槛，在最高可抵扣金额范围内对订单金额一次性打折             |

按使用对象，优惠券分为**通用优惠券**和**指定商品优惠券**。

每个账号最多可同时持有 50 张有效优惠券（包含被未支付订单占用的冻结券）。

## 查看优惠券

登录[千问AI平台](https://platform.qianwenai.com/)，进入**权益** > [优惠券](https://platform.qianwenai.com/home/benefits/voucher)页面，查看您持有的所有优惠券。

该页面提供以下筛选条件，帮助您快速定位优惠券：

- **券类型**：筛选代金券、满减券或折扣券
- **状态**：筛选可用、已用完、已过期、已作废的优惠券

在优惠券列表中，可以查看每张券的：

| 字段          | 说明                                   |
| ----------- | ------------------------------------ |
| 优惠券 ID      | 优惠券的唯一编号                             |
| 券类型         | 代金券、满减券或折扣券                          |
| 面值          | 优惠券的面额                               |
| 余额          | 优惠券的剩余可抵扣金额                          |
| 订单金额限制      | 使用该券时订单需满足的金额条件                      |
| 适用订单类型      | 该券适用的交易场景，如新购、续费、试用、转换、扩容、升级、按量付费账单等 |
| 生效时间 / 失效时间 | 优惠券的有效使用期限                           |
| 状态          | 可用、已用完、已过期、已作废                       |

<Note>
  千问AI平台优惠券页面仅展示适用于百炼的优惠券。如果您同时在使用阿里云，优惠券有可能会被阿里云侧的消费使用掉。
</Note>

## 如何使用优惠券

每张优惠券都有其适用产品、消费类型和使用条件。使用前，请在优惠券详情中确认。

### 按量付费账单自动抵扣

千问AI平台的模型调用为按量付费（后付费）模式。系统会在计费出账时自动使用生效中的优惠券进行抵扣，无需手动操作。

- **自动匹配**：系统优先使用即将过期的优惠券。到期时间相同时，优先使用余额较多的优惠券。
- **多券抵扣**：如果单张优惠券余额不足以抵扣整个账单，系统会自动使用下一张可用的代金券继续抵扣，直至账单金额完全抵扣或可用优惠券用尽。
- **余额支付**：若优惠券抵扣完毕后账单仍有剩余金额，该部分需另行支付。

<Note>
  按量付费账单明细按整点小时区间生成，存在一定延迟。若刚产生 API 调用或 Token 消费，暂未查到抵扣记录，请等待一段时间后再查看。
</Note>

抵扣顺序不可调整：系统自动优先使用即将过期的优惠券，不支持手动调整抵扣顺序或设置优先扣除账户余额。

按量计费无固定扣费日期，只要优惠券在有效期内且适用该产品，系统会随用随抵、实时结算。

<Warning>
  优惠券无法用于抵扣欠费，需自行充值还清。欠费补齐后，再次产生的按量付费费用可继续使用优惠券抵扣。
</Warning>

### 订单支付时使用

购买预付费资源时，系统会根据订单产品、支付类型、订单金额等属性进行匹配，在支付页面自动筛选并展示可用的优惠券。您可手动选择一张优惠券进行抵扣。

- 满减券和折扣券仅适用于预付费订单。
- 单笔订单一次只能使用一张优惠券。一张优惠券在有效期内可抵扣多个订单，直至余额用完。
- 未支付订单中的优惠券将被冻结，需先取消该订单才能继续使用优惠券。

## 查看抵扣明细

在[优惠券](https://platform.qianwenai.com/home/benefits/voucher)页面，点击目标优惠券**操作**列的**查看明细**，可查看该优惠券的抵扣记录，包括：

交易时间、抵扣账期、抵扣金额。

## 优惠券退回规则

在订单取消、资源退订等场景下，已使用的优惠券是否退回取决于具体情况：

- 支付前取消订单：优惠券退回。
- 资源下单后开通失败、账单回滚修正：支持退回代金券和满减券，折扣券无法退回。
- 资源退订、账单调账：已消耗的优惠券根据系统规则评估是否退回。

## 常见问题

### 为什么优惠券无法使用？

优惠券有具体的使用规则和可抵扣范围，具体信息请在[优惠券](https://platform.qianwenai.com/home/benefits/voucher)管理页面查看。常见原因：

- **适用产品限制**：优惠券不适用于当前购买或使用的产品。
- **使用期限**：优惠券已过期失效。
- **消费场景**：订单类型不在优惠券适用范围内。
- **订单金额**：满减券的订单金额未达到使用门槛。
- **优惠互斥**：已享受其他折扣或优惠活动。
- **优惠券冻结**：优惠券被未支付订单占用，需先取消关联订单。

### 优惠券是否支持账户充值？

优惠券不支持账户余额充值，仅可用于订单支付时抵扣和按量付费账单自动抵扣。

### 优惠券是否可以提现、转余额、延期或补发？

- **不可转余额/提现**：优惠券不支持转换为现金或充值到账户余额，仅可用于订单支付时抵扣或按量付费账单自动抵扣。
- **不可延期/补发**：优惠券过期后无法恢复、补发或延期。请在有效期内及时使用。
- **未使用不计费**：领取优惠券本身不产生任何费用，仅在购买产品或调用资源时才会触发抵扣。
