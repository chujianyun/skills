# 插件系统

WorkBuddy 提供了丰富的插件系统，您可以通过安装插件来扩展 WorkBuddy 的能力。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/plugins-overview.D9JHvvzp.png)

## 一、插件类型

WorkBuddy 支持以下几种插件类型：

| 类型 | 说明 |
| --- | --- |
| **Skill** | 技能插件，为 WorkBuddy 添加特定领域的能力 |
| **MCP** | Model Context Protocol 插件，连接外部服务和数据源 |
| **Hook** | 钩子插件，在特定时机自动执行操作 |
| **Agent** | 智能体插件，提供专门的任务处理能力 |
| **Rule** | 规则插件，定义 WorkBuddy 的行为规范 |

## 二、查看和安装插件

1. 点击左侧的 **插件** 按钮，进入插件管理页面
2. 浏览内置的插件列表，可以看到每个插件的名称、作者和分类
3. 选择需要的插件，点击 **安装** 即可

## 三、管理已安装的插件

在插件页面的中间栏，可以查看已经安装的插件：

1. 点击已安装的插件
2. 选择 **管理** ，可以查看插件的详细说明
3. 如需卸载，可以在管理页面进行操作

## 四、添加插件市场

如果内置插件不能满足需求，您可以添加第三方插件市场：

1. 在插件页面点击 **+** 按钮
2. 输入插件市场的地址
3. 确认后即可浏览和安装该市场中的插件

## 五、常用插件推荐

以下是一些常用的插件类型：

- **文档处理** ：支持更多文档格式的读取和生成
- **数据分析** ：增强数据处理和可视化能力
- **网络搜索** ：让 WorkBuddy 能够搜索互联网信息
- **文件管理** ：批量处理和整理文件
