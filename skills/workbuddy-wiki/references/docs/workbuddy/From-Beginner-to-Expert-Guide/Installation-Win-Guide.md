# Windows 系统安装指南

## 环境要求

- Windows 10 及以上，支持 Windows x64；ARM64 设备的支持情况以当前版本说明为准。
- 不支持 Windows 7/8/8.1。

> **Tip: TIP**
>
> 不满足上述要求的系统将无法启动 WorkBuddy。

## 下载

访问 [WorkBuddy 官网](https://www.workbuddy.cn/)，点击**立即下载**，选择 Windows，下载对应安装包。

![WorkBuddy 官网下载页](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/download-page.DZ4QT3Pt.png)

## 安装

1. 等待安装包下载完成后，双击已下载的安装包，启动安装程序。

![下载文件夹中的安装包](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/downloaded-installer.C0rVfq07.png)

1. 勾选 **"我同意此协议"**，点击**下一步**。 ![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-2.nX8V0i5W.png)
2. 选择安装路径（默认路径可直接点击下一步），点击**下一步**。 ![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-3.C1dI3tJz.png)
3. 确认开始菜单文件夹，点击**下一步**。 ![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-4.B1FHUmlf.png)
4. 建议勾选 **"创建桌面快捷方式"**，点击**下一步**。 ![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-5.BlN7t4Co.png)
5. 确认配置无误，点击**安装**。 ![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-6.BqsUqnLs.png)
6. 安装完成后，点击**完成**退出安装向导。 ![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-7.O4VQi_-H.png)

## 登录

1. 启动 WorkBuddy，点击**登录**按钮。 ![WorkBuddy 登录界面](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/login-screen.Dxuj6Li0.png)
2. 浏览器自动打开登录页面（WorkBuddy 官网 **workbuddy.cn**），在当前页面的登录弹窗中勾选《用户服务协议》与《隐私政策》，使用**微信扫码**完成登录；也支持**手机号、邮箱、SSO** 等登录方式，登录全程在当前页面完成，无需跳转。 ![微信扫码登录](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/login-wechat-qr.Ci-o675k.png)
3. 页面显示登录成功后，返回客户端即可开始使用。首次使用可参考[开启你的第一个任务](../../workbuddy/FirstTask.md)。 ![登录成功进入 WorkBuddy](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/login-success-home.Cy4H-gxN.png)
  > **Tip: 语言设置**
  >
  > - 如需切换界面语言，点击左下角 **头像** > **设置** > **通用** > **语言** ，进行切换。
  > - 如果点击登录后无法打开浏览器、登录失败或客户端无响应，可参见 [常见问题](../../workbuddy/From-Beginner-to-Expert-Guide/FAQ.md) 。

## 版本更新

点击左下角**头像** > **检查更新**，系统将自动检测版本。

> **Tip: 提示**
>
> 若已是最新版本则无需操作；若存在新版本，系统将自动下载并完成升级。 ![已是最新版本提示](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/update-latest.BP_i_XeX.png)
