# 错误码处理说明

## 常见错误码

### 1001

- **常见判断** ：多与模型侧状态有关。
- **处理方案** ：优先切换模型重试。

### 3002

- **常见判断** ：多与网络环境有关。
- **建议处理** ：
  1. 先确认当前使用的是公司网络还是家庭网络。
  2. 若为公司网络，建议联系企业 `IT` 协助排查。
  3. 若为家庭网络，可按官网网络排查流程逐项处理。
  4. 也可以参照 [网络代理](#网络代理) 关闭网络代理

### 3003

- **常见判断** ：多与网络环境有关。
- **建议处理** ：
  1. 先确认当前使用的是公司网络还是家庭网络。
  2. 若为公司网络，建议联系企业 `IT` 协助排查。
  3. 若为家庭网络，可按官网网络排查流程逐项处理。
  4. 也可以参照 [网络代理](#网络代理) 关闭网络代理

### 6003

- **常见判断** ：表示请求频率受限，专业版也可能出现。
- **建议处理** ：优先切换模型重试。

### 6004

- **常见判断** ：表示请求频率受限，专业版也可能出现。

### 11115

- **常见判断** ：输入内容过长。
- **处理方案** ：精简输入内容或切换为其他支持更大上下文的模型。

### 11133

- **常见判断** ：多与模型侧状态有关。
- **处理方案** ：新开会话或切换模型重试。
