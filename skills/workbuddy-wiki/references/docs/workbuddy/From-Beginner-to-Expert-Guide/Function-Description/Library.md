# 资料库

>
> 从超级个体到超级团队，让产物沉淀、管理、流转协同。

资料库是人和 Agent 共同的产物存放地。它让 AI 生成的文件从"用完即散落"，推进到"沉淀、管理、流转协同"的完整工作链路：Agent 产出的文档自动归位，团队资料集中在同一棵目录树，任务可以随时把资料库中的内容读进来继续加工，做好的页面还能变成别人也能打开的链接。

资料库与普通网盘的区别在于：它不是把文件堆在一起，而是让 MD、CSV、HTML 三种载体互相引用、彼此联动——文档被页面引用、表格被页面渲染，改一处、处处生效。

在 WorkBuddy 左侧边栏点击**资料库**即可进入。

![在左侧边栏进入资料库](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/library-directory-tree.CBN8wKhp.png)

## 能力总览

资料库由三块能力组成：

| # | 能力 | 解决的问题 | 包含 |
| --- | --- | --- | --- |
| 01 | [内容管理](./Library/Content-Management) | 团队中人和 Agent 的产物一起管理，共享上下文 | 个人文档与团队资料分开整理；零散资料进入同一棵目录树；任务中直接读取与修改资料库 |
| 02 | [多人多 Agent 协作](./Library/Collaboration) | 多人多 Agent 一起在资料库协作 | 团队空间与权限；MD 审阅与 AI 修订；多人协同编辑 HTML；MD、CSV 与 HTML 分工 |
| 03 | [轻量发布](./Library/Lightweight-Publish) | 轻松将你 vibe coding 的作品发布上线 | 本地 HTML 发布为在线链接；HTML + CSV 搭建轻应用 |

## 核心特性

- **人与 Agent 同权限** — 资料库是 WorkBuddy 原生能力，Agent 在任务中读取、修改资料库内容时，权限与当前用户完全一致，不会越权访问。
- **一棵目录树装下所有资料** — AI 三件套（MD / CSV / HTML）、办公与本地文件（PDF / Word / PPT / Excel）、图片音视频（PNG / JPG / MP3 / MOV）统一归拢。
- **个人与团队分区** — 「我的文档」放个人产出与收藏，「团队空间」放项目共享资料，每一种资料都有明确归属。
- **改动闭环** — 从资料库添加到任务 → 基于资料提问让 Agent 执行 → 成果保存回资料库，资料不是一次性上传，而是进入持续工作的循环。
- **AI 修改可审阅可回退** — Agent 对 MD 文档的修改不覆盖原文，以待确认状态呈现，接受后才写入正文。

## MD、CSV 与 HTML 的分工

资料库中的三类 AI 产物各有明确职责，数据与视觉分离，可按场景灵活调整：

| 形态 | 职责 | 定位 | 典型用途 |
| --- | --- | --- | --- |
| **MD** | 决定内容 | 叙事 | 方案、周报、说明等以文字与结构为主的产物 |
| **CSV** | 存储数据 | 数据源（唯一数据源） | 清单、排期、库存、业绩等需要持续维护的数据 |
| **HTML** | 负责表达 | 呈现 | 读取 CSV 渲染成图表与列表，把静态页面升级为数据驱动页面 |

CSV 作为唯一数据源，由 WorkBuddy 在线表格承载，多人可同时维护；HTML 页面通过表格 ID 读取数据并实时渲染。改内容改 MD，改数据改 CSV，改样子改 HTML，互不干扰。详见[多人多 Agent 协作](./Library/Collaboration)。

## 快速开始

1. 打开WorkBuddy 左侧边栏的 **资料库** ，可以看到「我的文档」和「团队空间」两个区域。
2. 把和 Agent 一起完成的产物存进资料库：既可以在会话中让 Agent 直接保存，也可以对产物点击 **分享** 并开启 **发布为网站** ，发布与存入一步完成。
3. 本地文件、办公文档和多媒体文件可以直接上传到目录树，也支持剪藏网页链接。
4. 需要让 Agent 基于已有资料工作时，在资料库中选择空间或文档，点击 **添加到任务** 。
5. 任务产出的新成果保存回资料库，供后续查找和调用。

## 注意事项与重点提示

### 信息收集与使用

| 收集项 | 类型 | 用途 |
| --- | --- | --- |
| 资料库文档内容 | 必要 | 沉淀产物、供检索复用，以及作为任务上下文供 Agent 读取 |
| 文件目录结构 | 必要 | 呈现目录树并提供组织、归类功能 |
| 团队空间成员信息 | 必要 | 团队空间的权限管理和协作标识 |
| 评论与修订记录 | 非必要 | 仅在用户使用划词评论、AI 修订审阅时产生，用于协作讨论和修改留痕 |

>
> 类型判定标准：
>
>
> - 「必要」：使用产品功能时必须提供的信息
> - 「非必要」：仅在用户主动触发特定操作时才需要的数据

### 权限边界

- 「我的文档」中的内容仅自己可见
- 团队空间内容对空间成员可见，可见范围由空间权限档位决定
- Agent 只读取当前用户有权访问的内容，不会越权访问其他成员或空间的资料
- 「发布为网站」默认关闭，开启后任何获得链接的人都可访问，需要时由用户主动开启，也可随时关闭

### 内容安全与合规

- 发布链接使用 `workbuddy.link` 域名，页面内容由发布者负责
- 不得发布违反法律法规或平台规则的内容，相关内容一经核实将被处置

### 安全提示

- 把空间或文档添加到任务前，确认其中不含不宜进入对话上下文的敏感信息
- 通过邀请链接添加成员时，确认链接只发送给应当加入的人
- 开启「发布为网站」前，检查内容及其引用数据是否适合对外访问，不再需要时及时关闭

### 存储与容量

资料库的内容按类型分别存储：上传的办公与本地文件（PDF / Word / PPT / Excel、图片、音视频），以及在 WorkBuddy 中创建的 MD、CSV、HTML 文档，都统一存放在资料库中管理和检索。

容量说明：

- **查看容量** ：资料库侧边栏底部展示 **容量条** ，可随时查看存储空间的 **已用容量和总容量** ；

![侧边栏容量条](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/library-storage-bar.SsObZOFu.png)

- **容量不足提示** ：上传前会先校验剩余空间，容量已满时会弹窗提示当前版本上限，可清理文件释放空间，或点击 **去升级** 扩容；

![存储空间已满提示](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/library-storage-full.DzJCCEXR.png)

- **升级扩容** ：点击容量条旁的 **升级** 按钮，可直接唤起会员升级面板，选择版本与付费方式完成升级；

![会员升级面板](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/library-upgrade-panel.Cd2INfJM.png)

- **配额随会员版本关联** ：不同会员版本对应不同的存储配额（体验版 5GB、标准版 10GB、高级版 20GB、旗舰版 50GB），升级后配额实时生效；会员到期或降级时的存量数据处理策略，以产品内提示为准（会员权益详见 [定价](./../../Pricing) ）。

### 积分消耗提醒

资料库的存储、目录组织、检索和手动编辑不消耗积分；通过 WorkBuddy 对资料库内容进行加工、分析、生成新产物，以及 AI 修订、按评论修订、HTML 划词修改等操作会消耗积分。

多人协作同一份文档时，积分按**实际发起 AI 操作的人**计算：

- 谁点击并发送了 AI 指令，就消耗谁的积分。以「按评论修订」为例，评论的内容只作为 AI 的参考上下文， **积分由点击「按评论修订」并发送指令的人承担，不会扣写评论的人**
- 接受或拒绝修订建议本身不消耗积分

### 第三方共享

上传的办公与本地文件由腾讯网盘提供存储服务；在 WorkBuddy 中创建的内容存储在 WorkBuddy 云端。除此之外不会主动共享给第三方。通过团队空间、分享链接或发布为网站主动分享时，接收方可访问你指定的内容。

### 免责声明

Agent 生成产物的准确性和适用性由用户自行判断，建议在正式使用和对外分享前进行审核。

### 使用建议

- 重要产物及时保存回资料库，避免会话过期后无法找回
- 团队空间按项目划分，避免信息混杂
- 用 MD 写内容、CSV 存数据、HTML 做呈现，长期维护成本最低
- 修改团队共享文档前，善用划词评论与审阅确认，避免覆盖他人工作
