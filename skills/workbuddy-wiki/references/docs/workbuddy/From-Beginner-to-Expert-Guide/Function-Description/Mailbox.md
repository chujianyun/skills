# 我的邮箱

>
> WorkBuddy 为每个用户创建专属邮箱地址。在界面查看和管理往来邮件，在对话中让 AI 帮您写信、回复、转发，邮件到达即可驱动 AI 处理。

## 概述

**我的邮箱**是 WorkBuddy 为每个用户创建的一个专属邮箱地址（如 `xxx.agent@agent.qq.com`），由 Agent Mail 提供底层邮件服务。它让您的 WorkBuddy 拥有独立的收发邮件身份。既能在「我的邮箱」里查看和管理往来邮件，也能在对话中直接让 AI 帮您写信、回复、转发。

> **Tip: 核心心智**
>
> 邮件是给 Agent 的「工作信箱」——**收件在界面看，干活在对话里。**

### 和其他邮箱MCP/工具相比，有什么不一样

现有的邮箱 MCP 或第三方邮件工具主要提供邮件 API 调用能力。Agent 邮箱作为 WorkBuddy 端内原生功能，具备以下优势：

- **跨端稳定使用：** 一次开通后多端可用，身份不随设备切换而丢失，收发稳定可靠。
- **端内查看邮件不消耗 Token：** 邮件的查看与管理通过端内可视化界面完成，包括列表浏览、详情查看和附件下载，无需将邮件正文传入对话上下文，避免额外的 Token 消耗。
- **端内新邮件提醒：** 新邮件直接在 WorkBuddy 端内通知中心提醒，无需依赖外部邮箱客户端，提醒后可一键将邮件添加到对话进行处理。

与其他工具相比，Agent 邮箱将邮件能力集成至 WorkBuddy 内部，提供可视化界面、跨端支持和原生通知。查看邮件不消耗 Token，仅在对话中处理邮件时才产生积分消耗。

## 核心特性

- **独立身份** ：我的邮箱是独立的助手身份，不借用您的个人邮箱代发
- **界面与对话分工** ：界面用于查看和管理邮件，对话用于由 WorkBuddy 起草并发送邮件
- **邮件驱动 AI** ：邮件到达即可触发 AI 处理，结果回到对话和邮箱
- **用户可控** ：回复、转发等对外动作不自动发送，必须经您确认
- **数据隔离** ：邮箱绑定到账号实例，个人版/企业版相互隔离，满足企业审计

## 入口与开通

### 进入入口

在 WorkBuddy 左侧边栏的**更多**中，「我的邮箱」位于「我的文件」下方，点击即可进入。

### 开通规则

我的邮箱需要手动开通，开通时同意补充协议（手机号注册再加一步短信验证码）即可。您可以在两个地方完成开通：

**开通入口**

- 在「我的邮箱」界面开通：进入「我的邮箱」，按界面提示同意补充协议即可开通。
- 在对话里开通：当您第一次让 AI 发邮件、而邮箱还没开通时，会直接在对话内弹出开通卡片，同意后在后台开通，并继续把这封邮件发出去。不打断当前任务，不再弹外层设置窗口。

## 「我的邮箱」界面能做什么

在「我的邮箱」界面中可以查看和管理邮件，包括以下功能：

- **收信/发信记录** ：通过收信、发信两个标签页切换查看，邮件按今天、昨天、上周、更早分组显示
- **邮件详情** ：查看发件人、收件人、正文及附件，附件显示文件大小并支持下载
- **邮件管理** ：支持标记已读、删除邮件、按关键词搜索
- **发邮件** ：列表页右上角入口，点击后跳转到新对话并预填示例指令，补充收件人和内容后由 WorkBuddy 发送
- **管理邮箱** ：列表页右上角入口，点击后跳转到邮箱管理页面进行更多设置
- **添加到对话** ：在邮件列表和详情页均可使用，将整封邮件（标题、正文、发件人、时间、附件）作为上下文传入对话，让 WorkBuddy 进行总结、提取信息、起草回复等处理

![邮件详情页](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/mailbox-3.Cd55uKeb.png)

> **Note: 说明**
>
> **空内容保护：** 如果未补充任何内容直接发送，WorkBuddy 会询问「你想怎么回/发给谁」，不会自动生成全文发送。

## 通知中心

邮箱相关通知集中在左侧栏顶部的「通知中心」，包括新邮件提醒、开通成功、冻结、封禁、授权吊销等。

新邮件通知展开后，可直接「添加邮件到对话」或「前往邮箱」。

## 邮箱状态

邮箱页面顶部显示当前状态。状态异常时会展示错误码和原因，并提供「前往邮箱处理」入口。

| 状态 | 说明 |
| --- | --- |
| 运行中 | 正常收发邮件，界面与对话均可使用 |
| 已停用 | 用户主动停用，支持一键打开设置 |
| 已封禁/冻结 | 显示错误码和原因，请前往邮箱管理页面处理 |

## 在对话里收发邮件

写信类操作（发邮件、回复、转发）统一在对话中完成，由 WorkBuddy 帮您起草，您确认后再发出。点击「回复/转发」跳到对话时，输入框展示以下内容：

- **结构化邮件引用：** 一个携带原邮件的卡片，WorkBuddy 据此拿到完整正文和附件，提示词本身保持干净。
- **固定指令前缀：** WorkBuddy 写好「要干什么」，例如「帮我回复这封邮件」。
- **用户填充槽：** 展示灰色占位提示，光标自动落在这里，等您补完意图后手动发送。

> **Note: 关键原则：预填充后不自动发送**
>
> 回复/转发属于「对外行动」，必须留一道用户确认，避免误发。如果您什么都没补就发送，WorkBuddy 会询问「你想怎么回/发给谁」，而不是擅自拟全文发出。

### 典型场景

| 场景 | 操作方式 |

| 会议纪要发送 | 让 WorkBuddy 整理会议纪要并发送到指定邮箱 |
| 发票/合同处理 | 将发票、合同邮件添加到对话，WorkBuddy 提取关键字段并生成摘要 |

| 资讯简报 | 将订阅的新邮件汇总，由 WorkBuddy 生成行业简报 |

## 注意事项与重点提示

### 信息收集与使用

| 收集项 | 类型 | 用途 |
| --- | --- | --- |
| 我的邮箱地址（如 `xxx.agent@agent.qq.com`） | 必要 | 作为独立收发邮件身份，构成邮件往来基础 |
| 手机号 | 必要 | 首次开通时用于短信验证码校验，完成补充协议同意 |
| 邮件正文与附件 | 非必要 | 在您主动添加到对话或让 WorkBuddy 处理邮件时作为输入提供给 WorkBuddy |
| 收件人地址（发邮件/回复/转发时） | 非必要 | 在您主动发起写信操作时用于投递邮件 |
| 邮箱别名 | 非必要 | 用于显示邮箱名称，修改后几分钟内自动同步，不影响收发 |

### 权限边界

- **身份清晰：** Agent 邮箱是独立的助手身份，不借用您的个人邮箱代发。
- **用户可控：** 回复、转发等对外动作不自动发送，必须经您确认。
- **数据隔离：** 邮箱绑定到账号实例（个人版/企业版相互隔离），满足企业审计要求。
- **内容防护：** 邮件内容仅作为参考信息提供给 WorkBuddy 处理，不会覆盖 WorkBuddy 的安全规则（防止通过邮件内容操控 AI 行为）；附件会经过安全扫描。

### 安全提示

- 使用独立身份收发邮件，避免个人邮箱暴露
- 回复、转发操作保留确认环节，防止误发
- 附件经过安全扫描，邮件内容仅作为输入数据处理
- 授权失效时可重新授权恢复使用

### 积分消耗提醒

查看和管理邮件不消耗积分。在对话中让 WorkBuddy 处理邮件、起草回复、总结内容等操作会按正常任务消耗积分。

### 技术支持

我的邮箱通过 Agent Mail 提供邮件收发服务。邮件数据由 WorkBuddy 维护，用于代您处理。发送的邮件使用独立助手身份投递，不借用您的个人邮箱身份。

### 免责声明

发邮件、回复、转发等操作以独立助手身份执行，内容由您确认后发出。邮件内容的真实性与适当性由发送者负责，WorkBuddy 不代为判断邮件内容是否适合发送。请确认后再发出邮件。

### 使用建议

- 回复和转发操作需手动确认后发送，发送前请核对收件人和内容
- 涉及敏感信息（如合同金额、个人隐私）时建议先审阅再交由 WorkBuddy 处理
- 定期查看通知中心的邮箱动态，及时处理封禁、冻结等异常状态

## 常见问题

### 产品认知类

**Q：Agent 邮箱和我自己的 QQ 邮箱 / 企业邮箱有什么区别？**

普通邮箱是「给人用的邮箱客户端」，Agent 邮箱是「给 AI 用的工作信箱」。它的重点不是再造一个邮箱客户端，而是把邮件变成 WorkBuddy 的新入口。邮件到达即可驱动 AI 处理，结果回到对话和邮箱里。它不替代你的个人邮箱，而是多了一个能自动干活的助手邮箱。

**Q：和其他邮箱 MCP / 邮件工具相比，优势在哪？**

它是 WorkBuddy 端内原生能力，而不是「给 AI 接一个邮箱 API」：一次开通可**跨端稳定使用**；看邮件走**端内可视化界面、不消耗 Token**（不用把正文塞进对话让 AI 读一遍）；新邮件**端内通知中心直接提醒**，提醒即可一键添加到对话处理。

**Q：为什么要做 Agent 邮箱？**

解决三个问题：

- **入口问题** ：不用装 App、不用学新界面，发封邮件就能触发 Agent 干活。
- **身份问题** ：Agent 有独立邮箱身份，不借用你的个人邮箱，边界清晰。
- **工作流问题** ：邮件天然带正文、附件、主题、发件人、时间，是办公自动化最稳定的触发器之一。

**Q：Agent 邮箱是免费的吗？**

开通和使用「我的邮箱」界面不收费。在对话里让 AI 处理邮件、写信等会按正常 AI 任务消耗 Credits，请合理使用。

### 开通与入口类

**Q：怎么开通 Agent 邮箱？在哪开通？**

Agent 邮箱需要手动开通，同意补充协议（手机号注册再加一步短信验证码）即可。支持两个开通入口：一是在「我的邮箱」界面按提示开通；二是在对话里第一次让 AI 发邮件时，会内联弹出开通卡片，同意后在后台完成开通，并继续把这封邮件发出去，不打断当前任务、不会再弹外层设置窗口。

### 界面使用类

**Q：「添加到对话」是干什么的？**

把整封邮件（标题、正文、发件人、时间、附件）作为上下文塞进当前对话，交给 AI 接着处理——比如总结、提取字段、起草回复。列表每条邮件和详情页都有这个入口。

**Q：附件能看到大小、能下载吗？**

能。邮件详情页的附件会显示文件大小，并提供下载入口。

**Q：删除邮件是彻底删除吗？**

删除前会有二次确认弹窗。删除是界面里的轻量整理动作，用于清掉无用邮件，保持收件箱干净。

### 对话收发类

**Q：为什么发邮件、回复、转发要在对话里做？**

写信是「内容创作 + 对外行动」，最适合交给 WorkBuddy 起草、由你把关。放在对话里，WorkBuddy 能结合上下文帮你拟好内容，你确认后再发，比在界面里手敲更高效，也更安全。

**Q：WorkBuddy 会自动把邮件发出去吗？**

不会。预填充后停在输入框，必须你确认并点发送才会发出。回复 / 转发属于对外行动，始终留一道用户确认，避免误发。

### 状态 / 安全 / 隐私类

**Q：Agent 邮箱安全吗？会用我的身份乱发邮件吗？**

不会。几个保障：身份清晰（不借用你的个人邮箱代发）、用户可控（对外动作必须你确认）、数据隔离（个人版 / 企业版相互隔离，满足企业审计）、内容防护（邮件内容只作为输入处理，附件经安全扫描）。

**Q：我改了邮箱别名，界面多久会更新？**

几分钟内自动同步，无需手动操作，也不会打扰你。因为是你自己改的，符合预期。底层身份不依赖会变的别名，所以同步期间收发不受影响。

**WorkBuddy Agent 邮箱 — 收件在界面看，干活在对话里。**
