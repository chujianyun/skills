# 系统设置

WorkBuddy 的设置面板集中管理账号、外观、模型、数据等全部配置项。点击左侧边栏底部的**头像**，在用户菜单中点击**设置**即可打开。

## 一、打开设置面板

点击左侧边栏底部的**头像**，弹出用户菜单，点击**设置**打开设置面板。

![用户菜单](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/user-menu.BeSSfC0s.png)

用户菜单浮层同时提供几个快捷入口，可直接进入对应功能：

| 入口 | 说明 |
| --- | --- |
| 企业版 | 进入企业智能体 |
| 查看积分余额 | 查看当前积分余额与明细 |
| 记忆与进化 | 查看与管理记忆，详见[记忆](./Memory) |
| 外观 | 快速切换浅色 / 深色主题 |
| 帮助与反馈 | 帮助文档与意见反馈入口 |
| 检查更新 | 检测当前版本并按提示完成更新 |
| 退出登录 | 退出当前账号，切换其他账号登录 |

## 二、设置面板

设置面板采用**左侧导航 + 右侧内容区**结构，左侧为设置项导航，右侧为对应配置内容，**修改即时生效、无需重启**。

![设置面板](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/setting-panel.CMBi956S.png)

### 设置项一览

左侧导航按分组展示：

| 分组 | 设置项 | 说明 |
| --- | --- | --- |
| **设置** | 通用 | 语言、字体大小、锁屏运行、开机自启、网络代理等基础选项 |
|  | 个人主页 | 账号资料与个人中心入口 |
|  | 快捷键 | 键盘快捷键查看与配置 |
| **功能** | 个性化 | AI 对话个性化：回复风格、加载欢迎语、自定义指令、称呼与身份 |
|  | 记忆与进化 | 记忆的管理与清除，详见[记忆](./Memory) |
|  | 智能体 | 智能体（Agent）相关配置 |
|  | 模型 | 内置模型与自定义模型接入，详见[模型配置](./Model) |
|  | 助理设置 | 助理相关配置，详见[助理](./Assistant) |
|  | Buddy 应用 | 查看已连接的 Buddy 应用、取消授权，详见[Buddy 应用](./Buddy-App) |
| **数据与安全** | 数据管理 | 数据管理与已归档任务查看，详见[数据管理](./Data) |
|  | 安全中心 | 安全策略与权限相关配置，详见[默认权限与安全沙箱](./Permission-Modes) |
| — | 关于 | 版本信息、检查更新与用户协议 |

> **Note: 说明**
>
> 功能型设置项（外观、记忆、模型、助理、数据管理等）的详细说明见其独立文档，可在上表点击跳转。

## 代码开发的用户级配置兼容

进行代码开发时，WorkBuddy 会自动识别并加载你在个人环境中定义的**用户级 `.codebuddy` 配置**，包括规则、技能（Skills）、命令（Commands）、MCP 等：

- 用户级配置与项目级配置按明确的优先级合并生效，互不冲突；
- 配置加载失败时会有清晰提示，且不影响代码开发主流程。

用户级与项目级配置的完整目录说明，见 CodeBuddy Code 的[`.codebuddy` 目录结构说明](https://www.workbuddy.cn/docs/cli/codebuddy-dir)。
