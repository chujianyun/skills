# 插件

> **Note: 简介**
>
> 插件用于打包分发一组相关能力。一个插件可同时包含技能、外部工具连接、快捷指令、自动化规则等组件，安装后即可统一使用。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-20.BLG33HU2.png)

## 一、插件组成

一个插件通常包含以下一种或多种组件：

| 组件 | 说明 | 示例 |
| --- | --- | --- |
| **技能（Skills）** | 教会 AI 完成某类任务的方法与流程 | — |
| **MCP 连接** | 对接外部服务 | 连接邮箱、网盘等 |
| **快捷指令（Slash Commands）** | 在对话框中输入简短命令触发功能 | 输入 `/周报` 一键生成周报 |
| **自动化规则（Hooks）** | 在特定时机自动执行操作 | 生成文件后自动检查格式 |
| **智能体（Agents）** | 针对特定任务的专属 AI 助手 | — |

不同插件包含的组件数量可能不同，但安装与使用方式保持一致。

## 二、插件市场

### 安装插件

浏览推荐插件，按需一键安装。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-22.Gn2jdprE.png)

### 管理插件

查看已安装插件，执行启用、停用、更新等操作。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-21.C7hFc6Af.png)

点击插件卡片可进行单独管理：

- **更新**：获取插件最新版本 ![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-21-1.C8CgPsZ2.png)
- **启用 / 禁用**：按需开关插件 ![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/image-21-2.Q_F9ZL-b.png)
