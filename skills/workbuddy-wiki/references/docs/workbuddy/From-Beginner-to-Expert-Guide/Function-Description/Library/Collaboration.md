# 多人多 Agent 协作

>
> 多人多 Agent 一起在资料库协作。

团队空间让人和 Agent 在同一份材料上工作：权限决定谁能看、也决定 Agent 能用什么；MD 文档支持划词评论与 AI 修订，改动以修订建议形式呈现、接受后才生效；HTML 支持划词直接改与多人同时编辑；MD、CSV 与 HTML 各司其职，数据与视觉分离。

## 灵活设置权限，轻松建立团队空间

权限不只决定谁能看，也决定 Agent 能用什么。

### 建立团队空间

在资料库左栏「团队空间」区可以找到你所在的团队，点击标题右侧的 **+** 新建空间，用于一个项目、一个小组或一条业务线。空间内可以像文件夹一样嵌套整理文档树。

往空间里放资料有四种方式：

- **新建文档或表格** — 直接在空间里写纪要、方案，或建一张 CSV 维护清单与排期
- **上传本地文件** — 把 PDF、图片等文件收进空间
- **剪藏网页链接** — 把文章或网页链接收录进来
- **让 Agent 直接生成到这里** — 在任务中指定生成到某个团队空间，产物即刻落进空间，无需二次搬运

### 邀请成员与设置权限

在空间菜单中选择**邀请和管理成员**，打开分享面板：可以查看当前协作成员，通过**复制链接**邀请他人加入，也可以分享到微信等渠道或生成二维码。

![分享空间面板：查看协作成员并复制邀请链接](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/team-space-permission.mRiGW7qR.png)

成员权限分为四档，按角色灵活授权：

| 权限档位 | 可做的事 |
| --- | --- |
| 查看 | 浏览空间内容，不能修改 |
| 编辑 | 在空间内新建、修改和整理内容 |
| 管理 | 管理空间成员与权限设置 |
| 无权限 | 不可访问该空间 |

获得链接的人可以单独设定访问方式（如需申请权限、可查看等）。空间默认不对外公开，确需发布给外部访问时再主动开启，公开范围始终由自己掌握。

> **Note: 企业版权限范围管控**
>
> 企业版下，协作范围由企业管理员统一配置：
>
>
> - 允许 **组织外协作** 时：任何人使用 WorkBuddy 账号登录后，均可通过链接加入文档或空间协作；
> - 仅允许 **组织内协作** 时：分享面板的分享范围默认为「组织内」，只有组织内账号登录后才能通过链接加入，无法邀请组织外账号。

### Agent 按同一权限读取

把空间或文档带入任务后，Agent 只读取当前用户有权访问的内容。

![Agent 在任务中按当前用户权限读取空间内容](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/task-run-with-space.DJ9ZA9AU.png)

>
> 这意味着不必为 Agent 单独维护一套权限：人看不到的内容，Agent 也读不到。

## 使用审阅模式和 AI 一起编辑 MD 文档

评论、讨论和 AI 修订都围绕同一份 MD 文档完成。改哪里由你划定，改完是否生效也由你决定。

### 随时划词评论，一起讨论

随时划词评论，并在原文旁继续讨论，评论与正文位置一一对应。每条评论都是一个讨论线程，支持多轮回复、@ 提及和状态流转。

![划词评论后在原文旁展开讨论线程](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/md-comment-discussion.DGPDgb76.png)

### 修订建议：每处改动都看得见、可审阅

划词选中文本、提出修改要求后，AI 不会直接覆盖原文。每一次修订都以独立的修订建议呈现在原文旁：

- **不覆盖原文** — 原文保持不动，改动标为「待确认」状态
- **对比查看** — 会话中会列出「原文 / 改后」对照表，说明本轮改了什么、为什么这么改
- **逐条处理** — 支持 **接受** 或 **拒绝** ，也可以一次性接受后落回正文

只有点击**接受**后，内容才会写入正文。

>
> 适用场景：对外提案、协作写作稿等大部分内容不希望被随意改动的文档——你需要的是一个可审阅的建议，而不是直接替你改。
>
>
> 关于划词选区编辑的操作细节，以及在 Word / Excel / PPT 等办公文件中与 AI 协作编辑，参见[人机双写](./../Knowledge-Base/Cowriting)。

### 按评论修订

收到一连串批注时，不必逐条手动改。使用**按评论修订**，AI 会读懂评论内容和正文上下文，自动产出修订建议，你只负责审阅；改动完成后可以通知评论者回来复核。

### 撤销与重做：AI 编辑可逐层回退

与 AI 协作编辑本地文档（如 PPT）时，AI 的每一次修改都会保留在撤回栈中，不再出现 AI 编辑后无法撤回的情况：

- **撤销** ：通过撤回键逐层撤销 AI 修改的内容，你的手动修改与 AI 修改可混合逐层回退
- **重做** ：通过重做键恢复刚刚撤销的内容

>
> 本地文档中与 AI 协作编辑的完整能力，参见[人机双写](./../Knowledge-Base/Cowriting)。

## 多人协同编辑 HTML

划词修改与多人编辑都在同一份 HTML 里发生，改动即时可见。

### 划词让 AI 修改

在 HTML 中划词调用 AI，直接修改当前选中的内容。

![在 HTML 页面中划词调用 AI 修改选中内容](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/html-ai-selection.B58ksPx4.png)

### 多人一起编辑 HTML

HTML 可直接编辑，多位协作者的光标和修改状态同时可见。

### MD 与 HTML 的协作差异

两种载体的 AI 协作方式不同，按载体使用对应方式：

| 载体 | AI 修改方式 | 生效时机 |
| --- | --- | --- |
| MD 文档 | 划词提出修改要求，生成修订建议 | 审阅并点击「接受」后才写入正文 |
| HTML 页面 | 划词调用 AI，直接修改选中内容 | 改动即时可见，无需审阅确认 |

## MD、CSV 与 HTML 分工

MD 决定内容，CSV 存储数据，HTML 负责表达；数据与视觉分离，按场景灵活调整。这也是资料库区别于普通网盘的核心——三种载体互相引用、彼此联动，而不是把文件堆在一起。

| 形态 | 职责 | 修改时机 |
| --- | --- | --- |
| **MD** | 决定内容，承载文字与结构 | 需要调整叙述、结构和结论时改 MD |
| **CSV** | 存储数据，作为唯一数据源 | 需要更新数值、新增记录时改 CSV |
| **HTML** | 提供视觉表达，读取 CSV 渲染 | 需要调整版式、配色和交互时改 HTML |

先在 MD 中把内容和结构写清楚：

![在 MD 编辑器中撰写内容](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/editor-md.Clks4dR2.png)

再由 MD 生成 HTML 页面用于对外呈现，同一份内容获得面向读者的版式：

![由 MD 生成的 HTML 页面](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/editor-md-to-html.BdKdBjE4.png)

CSV 由 WorkBuddy 在线表格承载，多人可以同时维护；HTML 页面通过表格 ID 读取数据并实时渲染，因此 CSV 更新后页面随之刷新，无需重新导出。内容、数据和呈现各自独立，改一处不影响其他部分。

## 使用建议

- 团队空间按项目划分，权限随项目阶段调整，避免信息混杂
- 团队共享的 MD 文档优先用划词评论沟通，再用按评论修订交给 AI，减少返工
- AI 修订后逐条审阅再接受，重要文档不要一次性全部接受
- 需要多人同时改版式的页面用 HTML，需要多人维护数据的用 CSV
