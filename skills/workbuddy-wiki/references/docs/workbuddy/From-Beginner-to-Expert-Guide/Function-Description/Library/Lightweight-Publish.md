# 轻量发布

>
> 轻松将你 vibe coding 的作品发布上线。

在本地做好的 HTML 页面，发给同事往往打不开——因为发出去的是本地文件路径或`localhost` 地址，只指向自己的电脑。轻量发布把本地 HTML 上传为在线链接；配合 CSV 作为数据底座，还能把页面直接做成可用的轻应用。

>
> 本地 HTML 产物支持**可视化编辑**：选中元素手动调整样式，或唤起 AI 编辑完成修改，详见[内容管理 → 本地 HTML 可视化编辑](./Content-Management#本地-html-可视化编辑)。

## 本地 HTML 一键上传为在线链接

### 问题：发出去的是本地地址

在 WorkBuddy 里打开刚生成的 HTML 页面时，地址栏是一个本地路径，例如：

```
file:///tmp/lib_demo/2026中国AI办公协作市场分析报告
```

把这个地址复制给同事是打不开的——本地路径只指向你自己的电脑。

### 操作：发布为网站

点击页面右上角的**分享**图标，在弹窗中切换到**发布**页签，打开**发布为网站**开关，页面即被发布为在线链接，任何获得链接的人都可以访问。

![在分享弹窗的「发布」页签中开启「发布为网站」](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/publish-as-website.wn29MtFZ.png)

开关下方会显示生成的链接，点击右侧按钮即可复制；弹窗底部还可以直接分享到微信等渠道，或生成二维码。发布后的链接使用 `workbuddy.link` 域名，形如 `https://workbuddy.link/p/{页面 ID}`。

弹窗中的另一个页签**邀请协作**用于邀请他人共同编辑，与"发布给别人看"是两件事：发布为网站是只读访问，邀请协作是参与编辑。

>
> 页面内容不变，变的只是访问方式：从"只有你的电脑能打开"变成"拿到链接的人都能打开"。这个动作同时也把内容存入了资料库，你可以随时找到并继续修改，详见[内容管理](./Content-Management)。

### 发布前请注意

- **发布为网站开关默认关闭** ，开启后任何获得链接的人都可访问，不再需要时可随时关闭
- 发布前确认页面及其引用的数据适合对外公开，避免敏感信息随页面一同发布
- 页面内容由发布者负责，不得发布违反法律法规或平台规则的内容

## HTML + CSV 搭建轻应用

普通 HTML 页面能看、能分享，但内容是写死的。资料库的 HTML 可以引入 CSV 作为数据源：数据在线存储、双向同步，改一次页面就自动更新。过去需要配数据库才能做的事，现在一个 HTML 页面加一张 CSV 表就够了。

### HTML：经营工作台

把经营指标、业务待办和操作流程做成直接可用的页面。HTML 负责呈现与操作，面向人——打开就是一个经营系统。

![用 HTML 搭建的经营工作台页面](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/app-html-dashboard.eeMbubAk.png)

### CSV：业务数据底座

用目录和多张 CSV 表持续管理商品、订单与库存数据。CSV 负责存储与更新，面向数据——结构清楚、持续可维护。

![用多张 CSV 表管理业务数据](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/app-csv-library.DXpZTSNj.png)

### 两者的配合方式

| 层 | 形态 | 职责 | 谁来维护 |
| --- | --- | --- | --- |
| 展示与操作层 | HTML | 指标看板、待办列表、表单操作 | 由 Agent 生成，需要改版式或交互时继续对话调整 |
| 数据层 | CSV | 商品、订单、库存等业务数据 | 由人或 Agent 持续更新，改数据不动页面 |

数据与页面分离带来两个好处：

- **数据在线存储** — 数据存在 CSV 表里，不写死在页面代码中，日常只需更新 CSV，页面无需重做
- **双向同步** — 页面上的修改会写回数据表，数据表里的修改页面也跟着变

后续想加字段、换配色、加筛选，继续在任务中对话调整即可。

### 两类场景怎么选

| 目标 | 适合的做法 | 典型例子 |
| --- | --- | --- |
| 把资料变好看 | 数据不常变，一个 HTML 页面就够 | 汇报、复盘、旅游攻略、作品集 |
| 把资料变能用 | 需要持续记录和更新，用 HTML + CSV | 个人工作台、客户跟进、任务看板、记账 |

常见的轻应用形态，例如：**项目管理看板**（集中查看任务、负责人与项目状态）、**电商管理系统**（管理商品、订单和经营数据）、**生活工作台**（把记账、习惯、健康、日程装进一个页面）。凡是还在用备忘录或表格凑合的事，都可以做成这样的轻应用。

>
> 更多关于 MD、CSV 与 HTML 各自职责的说明，参见[多人多 Agent 协作](./Collaboration)。

## 注意事项

- 发布为网站前，确认页面及其引用的数据适合对外访问，避免敏感信息随页面一同公开
- 页面依赖的 CSV 数据如有更新，需确认页面读取的是最新数据
- 不再需要对外访问时，关闭「发布为网站」开关即可停止访问
