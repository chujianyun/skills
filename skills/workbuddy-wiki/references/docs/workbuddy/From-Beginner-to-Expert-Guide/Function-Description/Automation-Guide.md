# 自动化

配置自动化，WorkBuddy 按设定时间自动执行周期性、重复性任务（如每日简报、周报汇总、定时数据整理），并将结果保存到指定目录。

## 概述

自动化在**本地客户端**保存定时任务配置（任务名称、prompt、调度规则、工作目录、执行状态等），在指定时间以您当前的登录身份自动发起 Agent 任务，按 prompt 执行查询、汇总、文件处理等工作；任务仅在配置的时间规则触发时执行，受任务频率、最大执行时长与系统并发控制限制。

## 如何使用自动化任务

### 1. 创建自动化任务

#### 打开自动化页面

可查看已安排的任务及历史执行记录。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/auto-1.CdwfDmc9.png)

#### 添加任务

点击 **添加自动化**，填写以下配置项：

| 配置项 | 说明 |
| --- | --- |
| **名称** | 用于区分不同自动化任务 |
| **提示词** | 描述任务目标和输出要求 |
| **工作空间** | 指定任务执行目录及文件保存位置，默认自动分配automation-xxxx工作空间；通过助理会话创建的自动化任务不绑定助理（Claw）工作空间，统一落在你的 automation 工作目录下 |
| **权限模式** | 提供默认权限和完全访问权限两种权限模式，兼顾效率和安全 |
| **选择模型和技能** | 指定执行任务的模型和技能、专家、连接器 |
| **定时规则** | 设置执行频率和生效日期区间，详见下方说明 |
| **推送到小程序/企业微信** | 开启后，推送会通过安全链路把文件同步到云端，以便在小程序或企业微信bot能接收到数据 |

**定时规则说明：**

- 支持 **每周多天** ：例如每周一、三、五 09:00 执行——一条规则即可表达，无需为每天单独创建任务；
- 支持 **每月多天** ：例如每月 1 日、15 日、28 日 09:00 执行；
- 同一任务的多个执行日期请 **合并在一条规则** 中配置，不要拆成多个自动化任务。

## 推送到企业微信bot

打开并选择已授权的企业微信 bot 后，WorkBuddy 可在任务执行完成后自动将结果发送至**企业微信**，便于第一时间查看。现支持两种机器人，配置成功将展示在开关下方：

- **企微助理集成：** 在企业微信群「@机器人」下发任务，全员共享执行结果，适合团队协作。
- **自动化通知 bot ：** 注册独立企微 bot，用于接收所有自动化任务结果通知。

## 推送到企业微信 bot

除小程序外，自动化任务执行完成后还可将结果推送到**企业微信**。在任务详情页开启「**推送到企业微信 bot**」开关（位于「推送到小程序」下方）。

**选择通知机器人**：开启时会弹出选择弹窗，两种来源二选一：

| 来源 | 说明 | 适用 |
| --- | --- | --- |
| **助理的企业微信 bot** | 复用「企微助理集成」的 bot 通道推送通知 | 已绑定企微助理的用户 |
| **独立的自动化通知 bot** | 为所有自动化任务单独注册的企微 bot，与助理消息通道互不影响 | 仅用于自动化通知的场景 |

- 开启后开关下方会显示当前来源，点击可展开切换；未绑定的来源会显示「去绑定」入口，按引导完成绑定后自动返回当前任务；
- 选择助理 bot 时，绑定方式建议使用 **WebSocket 长连接** ：URL 回调有时效性风险，长时间未触发可能失效（界面会以 ⚠ 预警标识提醒）；
- 当前使用的通道被解绑时，来源标识会显示红点与「该通道已断开 · 重新绑定」提示，推送开关 **不会** 被自动关闭；
- 凭据错误或企微不可用时，通知失败 **不阻塞** 任务本身执行。

> **Note: 单向通知说明**
>
> 使用助理的企业微信 bot 时，结果仅作为通知发送到企微，**不会写入助理上下文**，助理不会感知本次任务的执行内容。

![推送到企业微信 bot](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/auto-wecom.BNZlG9EB.png)

> **Tip: 通过企微 bot 创建的任务**
>
> 在企微 bot 通道中创建的自动化任务，推送开关**默认开启**并自动绑定当前企微 bot，创建即通即用；其他通道创建的任务保持默认关闭，按需手动开启。

## 注意事项与重点提示

### 信息收集与使用

- 账户身份信息：识别任务归属，触发时沿用当前登录身份调用模型/工具/MCP/连接器。
- 用户输入内容：保存任务名称、prompt、调度说明，触发时作为 Agent 执行指令。
- 使用行为日志：任务的创建/启停/触发/执行结果与耗时，用于状态展示与审计。
- 第三方平台凭证：仅当任务调用 MCP/连接器/OAuth 服务时使用您已授权的凭证；自动化本身不另存凭证。
- 本地文件读写：仅在您指定的工作目录范围内访问。

### 积分消耗提醒

积分消耗视任务复杂度而定：

- 简单提醒类较低
- 代码巡检、文档汇总、连接器分析等可能产生较多 token 消耗

### 第三方共享

自动化调用外部模型、MCP、连接器、OAuth 平台或通知通道时发生数据共享。

### 安全提醒

任务在无人值守下自动执行，**请审慎设置涉及文件写入/删除/资金操作的 prompt**。

### 使用建议

- 新建任务后建议 **先以低频率试运行** ，确认 Agent 的理解与执行结果符合预期，再放大调度频率。
- 大模型在执行过程中可能存在理解偏差或非预期行为，对 **结果中涉及文件改动、数据变更、对外发送的部分，请保留可追溯的日志** ，便于核查。
- 任务调用的第三方服务由其独立提供，相关稳定性、计费规则与处理结果 **请关注该第三方的服务状态与协议** 。
