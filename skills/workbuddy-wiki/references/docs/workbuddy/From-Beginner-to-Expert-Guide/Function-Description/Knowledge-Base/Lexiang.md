# 乐享知识库

腾讯乐享（乐享知识库）是腾讯旗下专为企业与团队打造的 AI 知识库产品，依托腾讯 18 年知识管理经验，围绕多源知识连接、动态智能治理、权限感知供给、Agentic 智能执行四大能力，推动组织知识从“可存、可找”走向被人与 AI 理解、信任、使用和增值，让企业知识资产真正转化为可持续的业务生产力，成为企业持续运转的知识中枢。

## 连接

1. 在左侧边栏点击 **资料库** ，选择 **乐享知识库** 。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/knowledge-base-18.BRERdI6D.png)

1. 点击 **立即前往授权** 后使用 微信扫码登录 / 手机号登录 乐享知识库。首次登录需要绑定手机号。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/knowledge-base-20.CGZ6dsX-.png)

1. 点击 **继续** 完成授权，WorkBuddy 将获得以下乐享知识库权限：

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/knowledge-base-19.CCCvb6-A.png)

- 读取知识库权限
- 搜索和查询知识内容
- 创建和编辑知识内容

> **Tip: TIP**
>
> WorkBuddy 连接资料库的乐享知识库后将获得**登录用户**的乐享知识库的权限，详细授权信息见上方内容。

## 使用

### 任务引用指定文件

在任务中引用乐享知识库内容的方式有两种：

1. **添加到任务：** 在资料库 - 乐享知识库中将当前知识库添加到任务，或选中对应文件，点击 **添加到任务** 。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/knowledge-base-21.Cjf0feQy.png)

1. **上传文件：** 在新建任务的输入框上方 **上传文件** 图标处打开乐享知识库，支持勾选整个团队空间、知识库或选择文件，点击 **确定** 添加到对话。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/knowledge-base-22.bLFMJsr-.png)

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/knowledge-base-23.CJ3cH4BO.png)

### 产物存回乐享知识库

在右侧产物中找到需要的文件，点击上传到云端，选择**乐享知识库**储存。保存到乐享知识库支持按照**团队空间**储存。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/knowledge-base-8.BniC-tuz.png)

### 版本信息

乐享知识库会展示当前企业使用的版本（免费版 / 标准版 / 高级版 / 商业版）：

- **超级管理员** ：点击版本信息后，可在下拉中查看乐享 code、许可总额度与已用量、有效期等详情；
- **其他成员** ：仅可见当前版本，不展示许可额度等详情。

## 解除绑定

如果需要换绑账号或关闭连接，可以点击**乐享知识库**，在右上角点击**解除绑定**。

![](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/base-lexiang-1.C63Zb9Bx.png)
