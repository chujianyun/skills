# 发票

用户可通过 [WorkBuddy 官网](https://www.workbuddy.cn/) **个人主页** 查看发票：

1. 登录 [WorkBuddy 官网](https://www.workbuddy.cn/) ，进入个人主页；
2. 在左侧导航栏中，选择 **账单与发票** ；
3. 点击 **查看发票** ，前往腾讯云控制台发票管理 **开发票** 。
