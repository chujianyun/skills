# 账号注销

WorkBuddy 支持注销个人账号。提交注销申请后，账号会进入 **15 天注销冷静期**，冷静期结束后账号正式注销，所有数据永久删除且**不可恢复**。请在操作前仔细阅读本文，并确认已备份重要数据。

## 注销前须知

### 注销后果

1. **数据删除：** 个人资料、账号名称、头像等基本信息，以及任务、文件、知识库、对话记忆、定时任务、AI 产出文件、记忆库等数据将永久删除，不可恢复。
2. **订阅服务终止：** 免费订阅服务终止；剩余积分（Credits）、额度、时长、AI 助手使用次数等资源不予折现。
3. **绑定关系解除：** 企业微信、API 密钥、第三方授权（GitHub / CNB / TAPD 等）在注销完成时由系统 **自动解除** ，无需提前处理，解除后无法找回；关联的 CodeBuddy 账号将 **同步注销** ，两端数据均不可恢复。
4. **重新注册限制：** 注销后 **15 天内** ，该手机号不支持重复注册；若需恢复使用，请在 15 天之后再试。

>
> 请注意：**自动续费签约、未到期的付费订阅与加量包、企业创建者身份**不属于自动解除范围，必须在提交注销**之前**自行处理（注销流程**不自动退款、不自动关闭自动续费**），否则无法提交注销申请，详见[注销受阻怎么办](#注销受阻怎么办)。

> **Warning: 说明**
>
> WorkBuddy **暂不支持换绑手机号**（无法将已有账号的绑定手机号更换为新号码）。若需使用其他手机号，只能使用该手机号**登录其对应的账号**（各端「切换登录账号」操作见[小程序设置](./../workbuddymini/features/Settings)），**无法通过换绑手机号绕过 15 天重新注册限制**。

### 注销规则

1. 提交注销后，账号进入 **注销冷静期** ，冷静期为 **15 天** ；此期间如需撤销注销，请联系腾讯云官方客服。
2. 冷静期内账号无法登录，尝试登录会提示「 **账号处于注销冷静期内，取消注销请联系腾讯云官方客服** 」，这属于注销流程中的正常现象，并非登录故障。
3. 冷静期结束后，账号正式注销，所有数据 **不可恢复** 。
4. 若账号存在 **阻断项** （例如未到期的付费资源、自动续费签约、企业创建者身份），将无法提交注销申请，需先自行处理；其中企业创建者需先转让 Owner 身份或解散企业，未结清的付费资源需先自行处理（注销流程 **不自动退款、不自动关闭续费** ）。
5. **企业成员身份不影响个人账号注销** ；如需退出企业，请在企业管理侧自行操作。
6. 注销流程中任意一步点击「取消」或关闭弹窗，都会立即终止流程，账号状态不变。
7. 提交注销即表示已知悉并接受注销后果。

## 注销操作

### 网页端 / PC 客户端

PC 客户端内不直接提供注销入口，需前往网页个人主页操作：

1. 在 PC 客户端点击左侧边栏底部的**头像**，选择**个人主页**，点击**前往管理中心**（或直接登录[官网](https://www.codebuddy.cn/work/)后点击右上角头像进入个人主页）；
2. 在左侧导航栏选择 **账号设置**，在页面底部的「注销账号」区域点击 **注销**，进入注销流程： ![注销账号入口](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/web-1-%E5%85%A5%E5%8F%A3.C58Pwwg5.png)
3. 注销流程共三步，前一步通过才能进入下一步： **Step 1 风险确认**：弹窗会列出注销后将被永久删除的数据（个人资料、账号名称、头像等基本信息；订阅套餐、订单记录、Credits 余额与充值凭证；Skill 配置、模型偏好、使用历史与生成内容；已授权的第三方集成 GitHub / CNB / TAPD 等），并提示本账号注销将**同步注销关联的 CodeBuddy 与 WorkBuddy 账号**、**15 天内不支持重复注册**。勾选「我已阅读并同意《账号注销服务协议》」后，点击 **下一步，验证手机号**： ![注销账号-风险确认](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/web-2-%E9%A3%8E%E9%99%A9%E7%A1%AE%E8%AE%A4.Hd0mWHhI.png) **Step 2 验证手机号**：系统会向账号绑定的手机号发送短信验证码，填写后点击 **下一步**。若收不到验证码，请检查手机号或稍后重试；手机号已停用可联系在线客服进行人工核验： ![注销账号-验证手机号](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/web-3-%E9%AA%8C%E8%AF%81%E6%89%8B%E6%9C%BA%E5%8F%B7.C1wEY5V6.png) **Step 3 最后一次确认**：在输入框中键入「**确认注销**」四个字激活注销按钮（需精确输入，多字、错字或多余空格均无法通过），点击 **永久注销账号** 提交注销申请： ![注销账号-最后一次确认](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/web-4-%E6%9C%80%E5%90%8E%E7%A1%AE%E8%AE%A4.Cg0UKT5S.png)

### 移动端 App

1. 点击左上角菜单（≡）打开侧边栏 → 点击用户名称旁的 **⚙ 齿轮图标**，进入**账号设置**，点击页面底部的**注销账号**： ![账号设置-注销账号](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/app-1-%E8%B4%A6%E5%8F%B7%E8%AE%BE%E7%BD%AE.C0-bhnQj.png)
2. 进入「申请注销 WorkBuddy 账号」页，页面会说明注销状态将保持 15 天、期间如需恢复账号请联系客服处理、付费资源未使用完将无法完成注销，并逐条列出注销后果。确认后点击**申请注销**： ![申请注销](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/app-2-%E7%94%B3%E8%AF%B7%E6%B3%A8%E9%94%80.WJ-JNHyg.png)
3. 阅读《WorkBuddy 账号注销协议》，阅读完成后点击**同意注销协议并确认注销**： ![阅读并同意注销协议](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/app-3-%E6%B3%A8%E9%94%80%E5%8D%8F%E8%AE%AE.BN6XzIuc.png)
4. 在「身份验证」页填写发送到绑定手机号的短信验证码（验证码 5 分钟内有效），点击**确认注销**提交注销申请： ![身份验证-验证绑定手机号](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/app-4-%E9%AA%8C%E8%AF%81%E6%89%8B%E6%9C%BA%E5%8F%B7.C3OXD8Dv.png)

>
> 提交注销后，该账号将无法继续登录 App，并进入 15 天注销冷静期，冷静期结束后完成注销。

## 冷静期内撤销注销

- 提交注销后如需撤销，请在 **15 天冷静期内** 联系腾讯云官方客服处理；撤销成功后账号恢复可用，数据完整。
- 冷静期内，该账号在 PC 客户端、网页端、移动端 App **所有设备** 上均无法登录，登录时会提示「账号处于注销冷静期内，取消注销请联系腾讯云官方客服」。
- 注销成功后，该账号在 **所有设备** 上的登录状态会立即失效，需重新注册后才能使用。

## 注销受阻怎么办

如果发起注销时提示**无法注销**、**暂不可注销**或**还有未解除的内容**，说明账号上仍有需要先行处理的**阻断项**。不同端（网页端 / PC 客户端 / 移动端 App）的提示措辞可能略有差异，请按下表对照自己的账号情况处理，处理完成后再重新发起注销：

| 受阻情形 | 如何判断 | 处理方法 |
| --- | --- | --- |
| 付费订阅尚未到期 | 提示中出现订阅名称与有效期，例如"个人标准版订阅，有效期至 XXXX" | 等待订阅到期或先完成退订，资源全部失效后再发起注销 |
| 仍有未用完的付费加量包 | 提示中出现付费加量包及数量 | 用完加量包或先完成退订后再发起注销 |
| 账号仍处于自动续费签约状态 | 提示中出现自动续费或连续包月/包年签约 | 先在**我的订阅**中关闭自动续费，解约后再发起注销 |
| 你是某个企业的创建者 | 提示不支持企业创建者注销，或提示需先处理企业 | 先转让该企业或注销该企业，再注销个人账号 |
| 你是某个企业的成员 | 企业成员身份本身不阻断注销；若账号下挂有企业统一购买的付费资源，会提示存在未结清的付费资源 | 联系企业管理员处理相关资源，或退出企业后再发起注销 |
| 此前已提交过注销申请 | 提示账号已在注销流程中 | 无需重复提交；如需撤销注销，请在冷静期内联系客服 |
| 账号未绑定手机号 | 提示需先绑定手机号，无法完成验证 | 先在**账号设置**中绑定手机号，再发起注销 |
