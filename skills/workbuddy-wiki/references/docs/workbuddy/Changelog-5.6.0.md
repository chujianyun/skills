# WorkBuddy 更新日志

## 5.6.0 版本发布 🚀（2026-09-19）

- 新增设置「应用管理」，可查看已授权的第三方应用与 Buddy 应用，并支持一键撤销授权
- 新增会话消息引用输入，选中他人消息即可作为上下文继续追问
- 新增巴西葡萄牙语与印尼语界面，切换后重启依旧保持
- 恢复自定义 MCP 直接编辑 `mcp.json` 的能力，可整份配置维护并即时生效
- 新增闲置能力提醒卡片，长期未使用的插件和技能可一键关闭
- Browser Use 兼容 Edge 加载项商店和 QQ 浏览器
- 完善微信 macOS 系统 Share Sheet 转发到 WorkBuddy 的流程，高频分享给出频控提示
- 新增语音输入实时反馈并延长最长录音时长，语音输入过程中不再打断手动编辑
- 提升对话历史首帧速度，长会话和复杂任务续聊更流畅
- 优化 Markdown 预览与编辑，切换 Tab 不再丢失编辑内容，Mermaid 等图表滚动更顺畅
- 优化连接器管理，卡片描述、图标、连接状态和市场目录更新更稳定
- 优化 MCP 服务管理、授权面板与探活重试，网络恢复后可自动重连
- 优化云端任务产物栏与消息顺序，产物随对话出现，多轮消息不再乱序
- 优化跨设备会话标题、模型、置顶顺序同步
- 优化电脑操作、浏览器操作、Bash 命令等工具在对话中的展示形态
- 优化购买积分体验，账户与订阅入口整合，支付到账变化更直观
- 优化专家中心分类展示、专家分享 / 导入与深链跳转
- 优化企业腾讯文档、乐享企业版面板首次打开速度
- 统一退出登录的二次确认弹窗、危险按钮和加载态，跨标签页登出实时同步
- 优化流式回复中「已处理 X 秒」耗时对齐真实整秒，减少无效刷新
- 优化窗口缩放边缘不再闪出异色底色，首页输入框悬停提示词模板时不再抖动
- 修复企业腾讯文档首次预览停在登录页、连接器授权完成后误跳系统浏览器的问题
- 修复冷启动短窗口内新建会话缺失插件工具的问题
- 修复企业下发含 `%USERPROFILE%` 环境变量的安全路径规则不生效的问题
- 修复切换账号后连接器目录不刷新，个人版切司内看不到内网连接器的问题
- 修复上一轮长命令仍在执行时，新消息误中断上一轮任务的问题
- 修复连接器已连接却调不到工具、已关闭却显示为开启导致会话无法发送的问题
- 修复插件套件启停后当前会话不生效、状态停留在「部分完成」的问题
- 修复流式 Markdown 标记异常、重复文本，以及慢历史加载被误判为空会话的问题
- 修复腾讯文档 skill 拿不到票据、PPT 编辑报错的问题
- 修复 WorkBuddy 频繁自动掉登录态的问题

- 修复内置插件 MCP（微信支付、表格助理等）在桌面会话里连不上的问题
- 修复 Windows 上表格助手、文档流水线等子代理从工具描述中随机消失的问题
- 修复弱网对话恢复失败、同一会话消息队列被新输入越过的问题
