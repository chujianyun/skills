# 套餐管理

## 套餐说明

- **自动续费：** 连续包月/连续包年的自动续费可在个人主页取消。
- **到期处理：** 到期后降级为体验版，已生成内容不受影响，高级功能受限。
- **最大购买期限：** 最长支持购买 **30个月** ，达上限时现有权益不受影响。

### 升级套餐

在订阅有效期内，您可以随时升级到更高档位的套餐，无需等当前套餐到期。升级时当前套餐的剩余价值会自动折算抵扣。

#### 升级入口

在 WorkBuddy 内从用户头像处打开下拉框，在当前套餐处**升级**或进入**设置 - 账户设置**操作升级套餐；也可以在**管理中心 - 套餐与用量**板块升级当前订阅计划。

![升级套餐入口](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/plan-1.BjNbeWF-.png)

#### 计费方式

升级时，系统会先按新套餐价格向您收取全额费用，随后自动将当前套餐的剩余价值退回原支付账户。您只需要补齐新旧套餐之间的差价。

- **剩余价值计算公式：**
  - 月付用户剩余价值：月价 X（1 - 已用积分／月总积分）
  - 年付用户剩余价值：未来未生效月份数 X 月均价 + 月均价 X（1 - 当月已用积分／月总积分）
  - 计算基准：仅拿基础积分计算价值，加赠积分不参与价值核算

#### 关键规则

- **支持升配，不支持降配**
  - 支持升配，不支持降配。用户实际支付金额必须大于退款金额
  - 支持套餐月升月、年升年、月升年、年转月的操作，其中，年转月需要购买比原套餐剩余更多的月付
  - 最小购买周期 = 当前版本剩余有效期按月/年向上取一个整周期
- **积分在新周期重新起算**
  - 升配后旧版基础积分剩余回收，按新版套餐全量下发新积分，有效期按新周期计算
  - 加赠积分一并退回，下发时按当前加赠方案重新发放
  - 新版积分先生效，旧版积分再失效，升配过程零断档
- **加量包不受影响**
  - 加量包积分不回收不计算，保留原有效期和余额
- **补差价机制**
  - 升配时先签约再解约，用户无需手动解旧约，旧版剩余价值自动退回原账户
- **包月 / 包年用户升级需先解约**
  - 包月 / 包年用户升级需要先解除旧约，解除后当前版本变为按月购买，再进行升配
- **订阅到期之后只能新购，不能升配**

#### 示例

**示例1：月付标准版升级到高级版**

>
> 标准版月付用户，月价99元，本月总积分4000(2000基础用量 + 2000赠送用量)，已用1000积分。升级到高级版月付199元。该用户的有效期还剩余20天，不足一月。

- **剩余价值金额** = 99 x (1 - 1000/2000) = 99 X 0.5 = 49.5元

用户实际支付 199 元，系统退回 49.5 元到原支付账户

- **新有效期：** 升配日 + 一个月
- **新积分用量：**
  - 全量发放9000积分
  - 旧剩余3000积分回收（基础用量和赠送用量都会回收）
- 加量包不受影响

**示例2：标准版包月升级高级版包月套餐**

>
> 标准版包月用户，月价70元，本月总积分4000(2000基础用量 + 2000赠送用量)，已用1000积分。升级到高级版连续包月140元。该用户的有效期还剩50天，大约1.5个月

- **剩余价值金额** = 70 X (1 - 1000/2000) + 70 = 70 X 0.5 + 70 = 105 元
- **用户实际支付：** 140 X 2 = 280元

用户选择高级版连续包月，由于原有效期剩余1.5个月，需要一次性支付2个月费用（向上取整）。系统退回 105 元到原支付账户。

- **新有效期：** 升配日 + 2个月
- **新积分用量：**
  - 全量发放9000积分
  - 旧剩余3000积分 + 未生效的4000积分 回收（基础用量和赠送用量都会回收）
- 加量包不受影响

**示例3：标准版连续包月升级高级版连续包年**

>
> 标准版 连续包月用户，月价70元/月，本月总积分4000(2000基础用量+2000赠送用量)，已使用基础积分2000(100%)。升级为 高级版 连续包年(1344元/年)。该用户剩余的有效期为7.5个月。

- **剩余价值金额** = 70 X (1 - 2000/2000) + 7 X 70= 0+490 =490 元

用户实际支付 1344元，系统退回 490元 到原支付账户

- **新有效期：** 升配日 + 一年
- **新积分用量：**
  - 高级版用户 按月全量发放9000积分
  - 旧剩余2000积分 + 未来周期积分全量回收
- 加量包不受影响
- 权益赠送包不受影响

**示例4：标准版连续包年升级为高级版连续包年**

>
> 标准版 连续包年用户，年付672元/年，每月总积分4000(2000基础用量+2000赠送用量)，1月1日购买，2月初升配(刚用了1个月出头，还剩10.5个月)。升级为高级版 连续包年(1344元/年)

- 月均价 = 672/12 = 56元/月
- 已过去1个月（1月）费用不可抵扣，当月（2月）已用积分 1000/2000 ，则当月抵扣 = 56 X (1 - 1000/2000) = 56 X 0.5 = 28元
- 未来10个月（3-12月）全额抵扣 = 10x56 = 560元
- **总剩余价值费用** = 560 + 28 = 588元

用户实际支付 1344元，系统退回 588元 到原支付账户。

- **新有效期：** 升配日 + 一年
- **新积分用量：**
  - 高级版用户 按月全量发放9000积分
  - 旧剩余3000积分回收，未生效周期的旧积分也回收
- 加量包不受影响

**示例5：标准版连续包年升级高级版连续包月**

>
> 标准版 连续包年用户，年付672元/年，每月总积分4000(2000基础用量+2000赠送用量)，1月1日购买，2月初升配（还剩10.5个月）。升级为高级版连续包月（140元/月）

该场景用户选择高级版 连续包月，需要至少购买11个月。

- **总剩余价值** = 560 + 28 = 588元
  - 月均价 = 672/12 = 56元/月
  - 已过去1个月（1月）不可抵扣，当月（2月）已用积分1000/4000，则当月抵扣 = 56 X (1 - 1000/2000) = 56 X 0.5 = 28元
  - 未来10个月(3-12月)全额抵扣 = 10 X 56 = 560元

用户实际支付 140 X 11 = 1540元，系统退回 588元 到原支付账户。

- **新有效期：** 升配日 + 11个月
- **新积分用量：**
  - 高级版用户 按月全量发放9000积分
  - 剩余3000积分回收
- 加量包不受影响

## 手动续期

在[官网](https://www.workbuddy.cn/)的**个人主页**进行手动续期，详细步骤如下：

1. 登录 [WorkBuddy官网](https://www.workbuddy.cn/) ，从右上角头像处进入 **个人主页-套餐与用量** 。
2. 在当前套餐右侧点击 **续费** ，点击 **确认并支付** 后使用 **微信扫码** 完成支付。
3. 支付成功，您的订阅将延长一个月。

## 自动续费

自动续费是指您所购买的套餐每次即将到期时，系统将自动从您签约的账户中扣取下一续费周期的费用。

在[官网](https://www.workbuddy.cn/)的**个人主页**开启自动续费，详细步骤如下：

1. 登录 [WorkBuddy官网](https://www.workbuddy.cn/) ，从右上角头像处进入 **个人主页-套餐与用量** 。
2. 在 **订阅计划** 中管理自动续费。

## 退款指引

WorkBuddy 订单支持通过腾讯云官网发起工单退款，具体操作步骤如下：

1. 登录腾讯云官网，进入 [腾讯云-提交工单](https://console.cloud.tencent.com/workorder/category) 页面，在 **产品分类** 处找到需要退款的产品。
2. 填写问题详情和联系方式后 **提交工单** 。
3. 提交退款工单后，工单将进入审核阶段，腾讯云客服人员将会在 **3个工作日** 内处理您提交的申请。
4. 工单审核通过后，系统将执行退款操作，退款将在 **5-10 个工作日** 内原路退回。
5. 可在 [腾讯云-订单管理](https://console.cloud.tencent.com/expense/deal) 页面查看退款成功的订单，订单状态为 **已退款** ；退款到账的款项在 [腾讯云-主页](https://console.cloud.tencent.com/expense/overview) 查看。
6. 若审核不通过，您可在 [腾讯云-我的工单](https://console.cloud.tencent.com/workorder) 里查看审核结果。

### 退款规则

- 同一账号下的每个商品订单仅有 **1次** 退款权益。
- **月付会员（含自动续费）：** 自订单实际支付后 **24小时内** 且未使用任何订单内积分（含订单下活动赠送积分），可申请退款。
- **年付会员（含自动续费）：** 自订单实际支付后 **7个自然日内** 且未使用任何订单内积分（含订单下活动赠送积分），可申请退款；当前定价方案生效前已完成订阅的年付会员不支持退款。
- **加量包、兑换码（WorkBuddy 提货券）** 不支持退款。

> **Note: 说明**
>
> - 上述积分包括套餐赠予积分和套餐基础用量。
> - 更多细则请以 [订阅协议](https://rule.tencent.com/rule/202606290002) 原文为准。
