# WorkBuddy 更新日志

## 5.4.3 版本发布 🚀（2026-08-26）

- 修复升级后已置顶的任务和会话丢失的问题
- 提升专家团会话稳定性，修复首次发起无响应、连接超时及重开后无法继续协作的问题
- 优化自动化任务体验，支持搜索并选择专家团，减少自定义 MCP 确认卡住及任务中断后重复补跑的问题
- 修复超长会话压缩后无法继续发送消息，以及翻页查看历史时消息或产物不完整的问题
- 优化产物分享体验，补齐分享入口、微信唤起和本地文件快捷操作，并改进分享开关与超时提示
- 提升连接器和 MCP 稳定性，修复断网、取消授权、自定义授权及插件或专家能力加载异常
- 修复 HTML 产物删除后展示原始错误页的问题，改为显示清晰的空状态
- 修复使用中文输入法重命名资料库时，确认候选词会误提交名称的问题
- 优化设计类会话续聊速度，减少继续追问时的消息等待
- 修复新建会话流式回复缺失或多条消息顺序错乱的问题
- 修复桌面端 Office 文件因系统防火墙限制而无法预览的问题
- 修复网页端任务完成后无法继续追问，以及会话恢复后 Max 模式失效的问题
