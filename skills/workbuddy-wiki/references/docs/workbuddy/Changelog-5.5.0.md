# WorkBuddy 更新日志

## 5.5.0 版本发布 🚀（2026-09-01）

- 新增行业 Buddy 应用，可按场景提供专属首页、专家、技能和连接器，进入应用后可直接发起更贴合行业需求的任务
- 支持通过 macOS 和 Windows 系统分享入口，将微信聊天记录发送到 WorkBuddy，并优化转发内容预览
- 新增图片处理能力，支持去文字或水印、图片修复、增强、美颜和透明背景抠图
- 增强腾讯文档编辑能力，支持更多内容读取、写入和文档操作场景
- 提升桌面端冷启动、快速问答及斜杠命令面板的响应速度，减少打开应用和开始提问时的等待
- 优化内置浏览器多标签切换和后台资源占用，低配置设备使用更流畅
- 隔离行业 Buddy 应用与通用版的输入框草稿，切换应用时不再互相覆盖内容
- 修复升级后首次启动可能长时间白屏，以及 Windows 安装或卸载时弹出黑色终端窗口的问题
- 修复企业腾讯文档首次预览停留在登录页，以及连接器授权失效后无法重新授权的问题
- 修复编辑后重新发送时内容错位、旧回复恢复，或发送失败后输入内容丢失的问题
