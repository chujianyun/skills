# WorkBuddy 更新日志

## 5.4.0 版本发布 🚀（2026-08-20）

- 支持创建 Worktree 任务，在同一工作区并行处理多个开发任务，代码改动互不干扰
- 新增代码开发模式下的 Git 分支展示与安全切换，并提供独立本地终端和后台命令运行面板
- 新增全新系统设置页、客户端自检工具和系统通知，环境排查与待确认任务处理更便捷
- 新增 3D 模型生成、创意设计 PPT 模板和「媒体运营」场景，并支持本地 PPT AI 编辑撤销与重做
- 优化输入体验，支持拖拽添加文件、将粘贴的长文本收起为标签，以及通过微信聊天记录发起对话
- 增强腾讯文档与资料库能力，支持更多内容加入会话，并可通过「一键做同款」快速复刻网页
- 优化专家、工作空间和任务管理，支持最近使用专家搜索、工作空间重命名及任务右键操作
- 增强模型选择，清晰展示会员权益档位，并支持为复杂任务选择更高推理强度和上下文长度
- 新增自动化任务每月多日期执行周期，定时安排更灵活
- 提升启动、建连、历史加载和会话切换速度，长对话浏览及多任务切换更流畅
- 优化产物分享和长耗时 MCP 工具执行，减少分享等待及工具被提前中断
- 修复输入草稿丢失、上下文压缩消息错序、账号或连接器切换后信息未刷新，以及部分文件无法预览的问题
