# WorkBuddy 更新日志

## 5.4.1 版本发布 🚀（2026-08-23）

- 提升多轮对话稳定性，修复取消后无法继续发送、切换模型或专家时任务中断等问题
- 优化专家使用体验，修复专家链接无法召唤、专家改名后启动旧版本及历史署名丢失的问题
- 提升连接器授权与开关稳定性，修复授权失败后状态卡住、反复跳转授权页或开关延迟的问题
- 优化资料库与腾讯文档使用流程，待办中的资料库链接可展示为文档卡片，上传后可自动启用连接器
- 优化任务列表与历史会话，归档任务可完整加载，未读状态、会话分类和链接跳转更准确
- 优化输入框与消息展示，切换场景时保留已输入内容，复制链接不再丢失原地址
- 优化工作区权限处理，无访问权限时提前引导授权，并减少同类权限重复弹窗
- 提升移动端连接电脑的同步稳定性，修复附件、图片、重复消息及上传超时等问题
- 优化自动化任务的默认权限、工作空间展示和会话定位，运行记录与任务状态更清晰
- 提升流式对话和产物加载性能，减少长回复期间的界面卡顿
- 修复表格新增行和图表预览异常，跨端查看结果更一致
