# 产品概述

WorkBuddy Enterprise 是腾讯云面向企业打造的一站式 AI 智能体平台。它以腾讯混元大模型为核心并支持多模型混合接入，将 Agent 能力深度融入企业的研发、办公与业务全流程，帮助企业构建可控、可运营、可规模化落地的生产级 AI 能力。

## 产品能力

作为总品牌与统一底座，WorkBuddy Enterprise 由三款产品构成，覆盖从个人开发者、办公用户到企业研发团队的全场景需求：**CodeBuddy** 面向智能编码，**WorkBuddy** 面向 AI 办公协同，**WorkBuddy Managed Agents** 面向智能体托管与规模化运行。三款产品既可独立使用，也可在企业内统一管理与协同，实现从编码、办公到智能体运营的一体化闭环。
