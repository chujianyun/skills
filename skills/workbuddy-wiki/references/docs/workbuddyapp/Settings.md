# 设置

## 入口

点击左上角菜单（≡）打开侧边栏 → 点击用户名称旁的 **⚙ 齿轮图标**

![设置入口](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/settings-1.XA08hPjm.png)

## 账号设置

### 注销账号

进入**账号设置**，选择**注销账号**，按页面提示完成注销申请。

注销后果、15 天注销冷静期、各端（网页端 / PC 客户端 / 移动端 App）操作步骤与注销受阻处理，详见[账号注销](./../workbuddy/Account-Cancellation)。

## 记忆库

>
> **记忆**让 WorkBuddy 记住你的偏好和习惯，对话越多，它就越懂你。

**我的记忆**每晚重新生成，点击可查看、编辑记忆内容。通过对话的方式告诉 WorkBuddy 要记住或忘记什么。

![记忆库](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/settings-6.DZ0ICu5L.png)

## 隐私政策、服务协议及各项清单

在这一部分中，包含**隐私**、**服务协议**、**隐私政策**、**个人信息收集清单**和**第三方信息共享清单**，点击各自卡片，可以查看对应的协议内容

![隐私政策与服务协议](https://download.codebuddy.cn/web/docs/729f1aaad145b1c8092712d0da1c125fe9ebc748/docs/static/settings-7.CZFXwyFI.png)

## 主题和语言

| 选项 | 说明 |
| --- | --- |
| **主题** | 切换浅色/深色/跟随系统 |
| **语言** | 切换界面语言（跟随系统/简体中文/繁体中文/英文） |

## 消息通知设置

点击消息通知设置，可跳转到手机系统对于 WorkBuddy 的消息通知设置策略

## 其他设置

| 选项 | 说明 |
| --- | --- |
| **分享日志** | 可以按时间范围导出日志文件（最近1小时/24小时/3天/全部日志） |
| **清除日志** | 点击可删除所有本地日志文件，请注意，此操作不可恢复 |
| **意见反馈** | 点击可反馈意见 |
| **退出登录** | 退出当前账号 |
