# 三、云端定时任务

## 一、场景

需要每天定时执行重复性工作（如行业早报、待办汇总、竞品监控）。

## 二、操作步骤

1. 在小程序中选择 **云上模式**
2. 设置定时任务，指定执行内容和时间
3. WorkBuddy 在云端按时自动执行，结果推送至小程序

定时任务示例：

- **早上 8:00 — 行业早报** ：自动抓取关注的行业信息源，筛选过去 24 小时的重要动态，整理为简报推送
- **早上 9:00 — 今日待办汇总** ：读取日历、项目看板和邮件，汇总当日需要关注的事项
- **晚上 10:00 — 竞品监控日报** ：检查指定竞品的官网和社交媒体，有变化才推送

云端任务不依赖个人电脑是否开机，全天候自动执行。
