# folotoy-ai-passport-wiki

FoloToy AI Passport 中文教程的本地知识 Skill。来源为 <https://ai-passport.folotoy.cn/guides/>，收录教程目录和 8 篇指南，共 9 页、28 张本地图片。

可以询问：设备按键与充电、微信小程序连接与身份内容同步、恢复默认固件、安装社区玩法，或用 Codex、Claude Code、TRAE 开发玩法的流程。

## 使用示例

- `$folotoy-ai-passport-wiki 第一次使用时怎样同步头像和全屏图片？`
- `$folotoy-ai-passport-wiki 恢复默认固件需要什么浏览器和线材？`
- `$folotoy-ai-passport-wiki 用 Codex 创造玩法，什么才算开发完成？`

入口见 [SKILL.md](SKILL.md)，页面目录见 [文档索引](references/INDEX.md)，覆盖与版权边界见 [来源说明](references/SOURCE.md)。

检索脚本只依赖 Python 3.10+ 标准库；Markdown 和本地图片可直接阅读。自带哈希同步脚本，更新规则见 [更新协议](references/UPDATE.md)。

这是教程区的离线快照，不包含完整 SDK、硬件接口和构建工具链，也不会自行刷写设备。上游保留版权；本快照的公开再分发已由发布者确认授权，详细边界见来源说明。
