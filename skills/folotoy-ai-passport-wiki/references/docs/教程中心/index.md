# 教程中心.

从开机到创造，一步一步来。了解设备、安装社区玩法，再用 AI 把自己的想法变成作品。

### [第一次使用 AI Passport](<第一次使用 AI Passport.md>)

用微信小程序同步名称、头像、简介和全屏图片，了解按键、内置游戏与充电。

### [恢复出厂固件](<恢复出厂固件.md>)

扫描设备二维码后，把专属链接拷贝到电脑上，再用电脑上的 Chrome 或 Edge 浏览器和 Type-C 线恢复默认固件。

### [安装社区玩法](<安装社区玩法.md>)

在玩法社区发现用户分享的小游戏、工具与创意互动，选择喜欢的安装到设备；安装后会覆盖设备当前的全部内容。

### [创造自己的玩法](<创造自己的玩法.md>)

跟着官方文档创造玩法，把自己的小游戏和交互真正装进 AI Passport。

### [用 AI Agent 创造专属玩法](<用 AI Agent 创造专属玩法.md>)

从一句清晰的需求开始，让 AI 编程 Agent 完成开发与构建，再把玩法安装到真实的 AI Passport。

### [用 Codex 创造 AI Passport 玩法](<用 Codex 创造 AI Passport 玩法.md>)

在 Codex 中打开玩法项目，把想法写成可验收任务，完成构建、安装与实机迭代。

### [用 Claude Code 创造 AI Passport 玩法](<用 Claude Code 创造 AI Passport 玩法.md>)

让 Claude Code 理解玩法项目与硬件约束，生成可安装版本，并根据真实设备反馈继续完善。

### [用 TRAE 创造 AI Passport 玩法](<用 TRAE 创造 AI Passport 玩法.md>)

在 TRAE Work 中描述玩法、完成代码与构建，再把新体验装进随身的 AI Passport。
