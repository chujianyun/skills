# 安装社区玩法

在玩法社区发现用户分享的小游戏、工具与创意互动，选择喜欢的安装到设备；安装后会覆盖设备当前的全部内容。

<a id="step-1"></a>

## 01 · 使用 Chrome 或 Edge 浏览器

请使用最新版本的 Chrome 或 Edge 浏览器打开此网页。

<a id="step-2"></a>

## 02 · 在玩法社区选择玩法

前往[玩法社区↗](<https://ai-passport.folotoy.cn/plays/>)浏览用户分享的小游戏、随身工具和创意互动。选好玩法后，可以查看详情了解操作方法，也可以直接点击卡片上的「安装」。

<a id="step-3"></a>

## 03 · 连接设备，开始安装

先将 AI Passport 开机，用能传输数据的 Type-C 线连接电脑。点击「安装」后，在浏览器左上角的弹窗中选择设备并点击「连接」，网页会自动开始安装。

<a id="step-4"></a>

## 04 · 等待安装完成

安装期间保持设备连接，不要拔线或关闭页面。等待页面提示安装完成、设备自动重启后，即可体验新的玩法。

> **提示**
> 安装新玩法会覆盖设备当前的全部内容。要再次使用小程序的通行证功能，需要先恢复默认固件。
