# Five Perspective Analysis

一个用于扩大问题视野、提升决策深度的通用分析 Skill。

它会从用户、业务负责人、一线执行者、技术负责人和公司经营者五种角色出发，找出目标差异、现实约束、成本转移和长期影响，再给出有取舍的综合判断。

适合用于：

- 评估产品方向或功能方案
- 审视技术选型和架构决策
- 复盘项目失败或推进阻力
- 分析业务问题和组织协作
- 训练更高职级所需的全局思考

这个 Skill 不会用五段相似观点制造“全面感”，也不能替代真实用户研究、利益相关者访谈或专业领域核验。

示例：

```text
使用 $five-perspective-analysis 分析：我们是否应该让 AI Agent 自动回复所有售后问题？
```
