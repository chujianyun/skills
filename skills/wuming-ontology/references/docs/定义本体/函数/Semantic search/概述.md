# 概述

语义搜索是一种基于内在意义或上下文的文本搜索方式，而不仅仅依赖于关键词或其他传统的搜索方法。

语义搜索通过使用AI模型将文本变换为向量来实现，这些向量是数字数组，被称为“嵌入”。如果模型有效，那么在N维空间中彼此接近的向量，它们具有相似的基础或语义意义。例如，“面罩”的嵌入向量将比“呼吸器”更接近“面部覆盖物”的嵌入向量。

[官方图片已失效：嵌入可视化](https://www.palantir.com/docs/resources/foundry/functions/aip-embeddings-visualization.png)

如果嵌入的文本与[Ontology](../../../Ontology%E6%90%AD%E5%BB%BA.md)中的特定Object相关联，那么您的搜索驱动的操作流程将变得更加有用。找到相关实体或与特定搜索查询相关的实体就如同在N维空间中找到最近的向量。
