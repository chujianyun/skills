# 概览

**Object视图**是与特定Object相关的所有信息和工作流程的中心枢纽。Object视图包括有关Object的关键信息、链接的Objects、相关指标、分析、仪表盘和应用程序。

例如，一个`Airport` Object视图（基于交通运输统计局的开源数据）可能提供以下信息：

* 机场名称、城市和位置
* 飞机延误操作工作流程的链接
* 到达和出发航班的时间线
