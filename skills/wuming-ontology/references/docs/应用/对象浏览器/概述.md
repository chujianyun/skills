# 概述

**Object Explorer** 是一个用于解答关于Ontology中任何问题的搜索和分析工具。

* 用户可以通过运行查询轻松找到感兴趣的Objects，查询范围从简单的关键词搜索到综合的属性筛选，全部通过直观的点击界面完成。用户可以使用探索视图来探索生成的对象集，或将其视为结果表，或选择特定对象查看其[Object视图](../%E5%AF%B9%E8%B1%A1%E8%A7%86%E5%9B%BE/%E6%A6%82%E8%A7%88.md)。
* 此外，用户可以比较和对比对象集，对对象集进行批量操作（如数据输出），并在其他兼容应用程序中打开对象集（如Quiver），或以特定格式导出。用户还可以保存他们的探索，并随时重新访问以查看最新结果。
* 探索视图是一组预设和可配置的可视化（例如图表或地图），用户可以进一步利用它们深入研究特定Object的子集。
* Object Explorer 需要的配置极少，并面向技术水平较低的用户。

通过浏览[Object Explorer 界面的概述](%E5%85%A5%E9%97%A8.md)来开始使用。
