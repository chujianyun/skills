# 概述

有几个基本概念对于Foundry Rules至关重要：

* **[Object模型](Object%E6%A8%A1%E5%9E%8B.md)：** Foundry规则是具有**属性**的**Objects**，可以通过**规则提案**进行管理。
* **[Workshop应用程序](Workshop%20%E5%BA%94%E7%94%A8.md)：** Foundry规则由**Workshop应用程序**管理，通常包括**规则编辑器**和**提案审阅器**功能。
* **[规则逻辑](%E8%A7%84%E5%88%99%E9%80%BB%E8%BE%91.md)：** Foundry规则编码旨在执行[特定工作流程](../Foundry%20Rules.md#example-use-cases)的业务逻辑。此逻辑遵循特定结构，并定义了一组数据变换。
* **[Foundry Rules工作流程配置](Foundry%20Rules%20%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%85%8D%E7%BD%AE.md)：** 使用工作流程配置编辑器配置Foundry规则。编辑器是工作流程所有者用来将Foundry Rules定制到他们的应用案例的界面。

  ![Foundry Rules工作流程概述列表](../../../../assets/foundry/foundry-rules/overview%402x.png)
