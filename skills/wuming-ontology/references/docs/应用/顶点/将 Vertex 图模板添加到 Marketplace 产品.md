# 将 Vertex 图模板添加到 Marketplace 产品 \[Beta]

使用 [Foundry DevOps](https://www.palantir.com/docs/foundry/devops/overview/) 将您的 [Vertex 图模板](Graphs/%E5%88%9B%E5%BB%BA%E5%9B%BE%E6%A8%A1%E6%9D%BF.md) 包含在 [Marketplace 产品](https://www.palantir.com/docs/foundry/devops/core-concepts/#product) 中，以供其他用户安装和重复使用。[了解如何创建您的第一个产品。](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)

## 支持的功能

除了已保存的 Search Arounds 之外，所有 Vertex 图模板功能均受支持。

## 将 Vertex 图模板添加到产品中

要将 Vertex 图模板添加到产品中，首先 [创建一个产品](https://www.palantir.com/docs/foundry/foundry-devops/create-products/)，然后选择如下所示的 **图模板** 内容类型。
