# 网页端：网盘与网页

资料核对：2026-09-16。配额、附件数及发布能力须核对当前页面。

## 个人网盘 / 我的网盘

任务文件进入 Agent 工作区；Office 文件可在线编辑并自动保存。对话通过“+”选择网盘资料复用。网盘专页记载每条消息共用 9 个附件额度，本地附件单个最多 500 MB；基础教程却写 20 个网盘文件，属于已发现的文档冲突。

空文件不能上传，同目录不允许同名；文件夹暂不能打包下载。Agent 工作区根目录受保护。删除文件或文件夹不可恢复，文件夹删除包含全部子内容；重要资料应先下载。网盘不按操作扣积分，但受存储配额限制。

来源：[个人网盘](https://qwenwork.cn/docs/web/drive)。

## Pages 创建与管理

在任务对话中创建网页，管理入口用于已有网页。静态/动态类型创建后不能互换；修改发布产生新版本，默认域名采用 `*.qwenwork.host`。动态页面文档列出 Node.js 后端，可挂载独立数据库。

数据库最多一个，挂载后不能卸载或换绑；删除网页会连带删除数据库。访问密码针对整站，清空密码会恢复公开访问。自定义域名涉及所有权校验、DNS 和证书，具体要求从原页核对；私钥只在安全界面配置。

回滚状态有矛盾：专页部分段落标注“即将上线”，基础教程却描述为已有功能。先查看账号实际菜单，不保证可用。

来源：[我的网页](https://qwenwork.cn/docs/web/pages)。

## Pages 访问故障

| 提示 | 初步检查 |
|---|---|
| 503 / 部署中 | 发布状态、动态实例是否就绪；已发布仍异常时稍后检查 |
| 429 / 用量上限 | 当前周期请求数和流量；不要将其当成通用 API 限流 |
| 403 / 暂不可用 | 暂停状态、套餐权益与网页数；自定义域名和默认域名可能状态不同 |

暂停不等于资源被删除；不要为了恢复访问直接删除重建。

来源：[我的网页故障说明](https://qwenwork.cn/docs/web/pages)。
