# 桌面端

资料核对：2026-09-16。以下是产品文档说明，不表示当前助手已经获得系统权限。

## 系统设置

侧栏底部设置包含外观、代理、保持唤醒、通知、快捷键、默认工作台、安全工作环境与实验功能。权限按用途开启：磁盘用于文件，录屏和辅助功能用于屏幕交互，麦克风用于语音，自动化用于原生应用协作。某些偏好需新会话生效。

安全工作环境的本地隔离描述不能推导成“整个产品离线”或“所有模型调用不出设备”。企业隐私模式可能只能由管理员配置。

来源：[系统设置](https://qwenwork.cn/docs/desktop/settings)。

## 意识 / Awareness / 记忆

意识模式管理协作风格与跨会话记忆，自动记忆开关控制画像和记忆维护。文档给出的根目录为 `~/.qwenworkcn/awareness/main`：`SOUL.md` 管风格，`AGENTS.md` 管工作规范，`USER.md` 是画像，`MEMORY.md` 是长期记忆，`memory/` 保存日记式记录。

索引可重建，目录可导出备份或导入。重置工作手册会覆盖现有内容；清空记忆会删除画像、长期记忆和日志。回答路径问题不需要读取用户实际记忆文件。

来源：[意识](https://qwenwork.cn/docs/desktop/memory)。

## 应用快照

设置全局快捷键后，可把前台应用截图和可读文本附到当前输入框。macOS 需要辅助功能和屏幕录制权限。快照用于输入上下文，不等同于已授权操作目标应用。

来源：[应用快照](https://qwenwork.cn/docs/desktop/app-snapshots)。

## 电脑操控 / Computer Use

专页列出 macOS 14+，在扩展中的连接器启用“计算机控制”，并授予辅助功能和屏幕录制权限。执行策略包括每次询问、自动执行与禁用。网页任务可优先使用浏览器连接器。验证码、扫码或二次认证需要用户介入；修改登录应用内的数据、发送或删除仍需对应任务授权。

来源：[电脑操控](https://qwenwork.cn/docs/desktop/computer-use)。

## 语音输入

需要麦克风权限和系统语音识别能力，支持语种取决于系统语言配置。转录文字可先编辑再发送。快捷键与按住/切换式操作在不同页面描述不一致，查询时以“设置 → 语音输入”的当前配置为准。

来源：[语音输入](https://qwenwork.cn/docs/features/voice-input)、[系统设置](https://qwenwork.cn/docs/desktop/settings)。

## 模型选择

桌面专页列出基础、高级、经济和具体型号选项，模型会持续调整，不把本地目录当作实时型号清单。切换用于当前任务后续对话，保留上下文。复杂分析与简单整理可分阶段选择；估算周期任务成本前先核对单次用量。

来源：[桌面模型选择](https://qwenwork.cn/docs/desktop/model-selection)。
