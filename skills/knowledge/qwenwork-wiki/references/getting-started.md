# 入门与安装

资料核对：2026-09-16。系统门槛和客户端入口可能变化，安装前核对原页。

## 产品与端的选择

千问办公以任务和交付文件为中心，覆盖文档、数据分析、演示、网页与多媒体工作。网页端从浏览器进入，桌面端可处理本地文件并使用浏览器自动化；网页制作的端支持状态不能直接外推到桌面端。千问办公与用于模型 API 接入的千问AI平台是不同产品。

来源：[产品简介](https://qwenwork.cn/docs/product-introduction)、[常见问题](https://qwenwork.cn/docs/faq)。

## Web 首次任务

访问 [Web 应用](https://qwenwork.cn/app)，按页面选择钉钉扫码或大陆手机号登录；首次扫码可能需要绑定手机号。进入个人或所属企业空间，再创建任务、附资料、提出目标与交付格式。同一成果的修改留在原任务中，新目标另开任务。生成后核对内容、数字和文件可用性，成果可从网盘复用。

基础教程里的附件数量与网盘专页不同，不能直接把教程中的数值当作当前上限；见来源说明的冲突记录。

来源：[Web端使用链路](https://qwenwork.cn/docs/getting-started/basic-workflow)。

## 桌面首次任务

从官方下载页安装，完成浏览器认证后返回客户端。任务监控显示执行计划、工具与产物；产物是真实的本地文件。桌面任务历史保存在当前设备，换电脑登录不会自动带来另一台设备的历史。

来源：[桌面端使用链路](https://qwenwork.cn/docs/getting-started/desktop-workflow)。

## macOS

安装指南列出 macOS 14+，支持 Apple Silicon 和 Intel，应用约占 700 MB，另留成果空间。选匹配芯片的 DMG，拖入应用程序目录。文档同时出现英文和中文应用包名，实际路径以本机安装结果为准。系统阻止启动时，先确认安装包来自官方，再按系统提示处理；不要默认关闭系统保护。

来源：[macOS 安装](https://qwenwork.cn/docs/install/macos)、[官方下载](https://qwenwork.cn/download)。

## Windows

安装指南列出 Windows 10+、64 位 x86_64 和 500 MB 可用空间。从官方获取 EXE，按安装向导完成，再从开始菜单打开。安装文档的登录方式可能与实际区域/版本不同，以当前登录页为准。

来源：[Windows 安装](https://qwenwork.cn/docs/install/windows)。

## HarmonyOS

对应鸿蒙电脑及 HarmonyOS 6.1+，安装包约 1 GB，通过 AppGallery 获取。首次磁盘权限用于将历史、产物和记忆保存到用户目录，授权完成可能重启。卸载应用不等于清除用户目录数据；彻底清除会影响历史与配置，不能当作普通排障第一步。

来源：[HarmonyOS 安装](https://qwenwork.cn/docs/install/harmonyos)。
