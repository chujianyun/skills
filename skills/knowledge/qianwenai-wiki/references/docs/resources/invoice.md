# 发票管理

> 申请、下载和管理千问AI平台消费发票

千问AI平台支持为实际消费金额申请电子发票。

- **千问AI平台部署模型**：发票由**通义云启（杭州）信息技术有限公司**开具，税目为"其他软件服务 \* 软件服务费"，税率 6%。
- **三方直供模型**：发票由对应的第三方模型供应商开具。

## 发票类型与开具条件

千问AI平台支持以下发票类型，不同用户类型的开具条件不同：

### 个人用户

指未进行实名认证或已认证为个人的用户。

| 发票类型      | 可用抬头                      | 开具条件          |
| --------- | ------------------------- | ------------- |
| 个人普通发票    | 未认证：默认"个人"抬头；认证后：可修改为本人姓名 | 直接申请，无需额外审核   |
| 企业普通发票    | 自行填写的企业名称                 | 直接申请，无需提交审核材料 |
| 企业增值税专用发票 | 自行填写的企业名称                 | 需上传盖章协议并通过审批  |

<Note>
  个人用户开具企业增值税专用发票，需提交加盖公章的纸质协议，审批通过后方可开票。
</Note>

### 企业用户

指已完成企业实名认证的用户。

| 发票类型      | 可用抬头      | 开具条件        |
| --------- | --------- | ----------- |
| 企业普通发票    | 实名认证的企业名称 | 直接申请，无需额外审核 |
| 企业增值税专用发票 | 实名认证的企业名称 | 直接申请，无需额外审核 |

<Note>
  企业用户只能开具与实名认证一致的企业抬头发票。如需变更开票抬头，请先完成企业实名认证变更。
</Note>

## 配置发票抬头

申请发票前，须先完成发票抬头（发票上显示的名称）和接收邮箱的配置。

- **个人用户**：未认证时默认抬头为"个人"，完成个人实名认证后可修改为本人姓名。如需开具企业发票，可在发票抬头页面添加企业名称。
- **企业用户**：抬头固定为实名认证的企业名称，不可使用其他名称。

发票信息仅影响后续新申请的发票，历史发票不受影响。

<Note>
  千问AI平台的发票抬头与阿里云官网独立管理，在千问AI平台配置的发票抬头不会同步到阿里云官网，反之亦然。
</Note>

## 可开票金额

**可开票金额**基于实际消费，规则如下：

- **可开票**：已消耗的按量付费金额
- **不可开票**：充值余额（未消费部分不符合开票条件，依据《中华人民共和国发票管理办法》）

**欠票说明**：若已开票的订单发生退款，差额部分记为"欠票"。后续新产生的可开票金额将优先抵扣欠票。若欠票导致可开票金额为负，将暂停开票直至欠票清零。

## 申请发票

1. 进入发票管理页面，确认已配置发票抬头和接收邮箱。
2. 选择需要开票的账单月份或金额。
3. 确认发票信息并提交申请。
4. 电子发票通常在 1 个工作日内发送至接收邮箱，可在**开票记录**中下载。

<Note>
  通过第三方服务商购买的产品，开票周期最长为 7 个工作日。
</Note>

电子发票支持 **PDF**、**OFD**、**XML** 格式，可一次性批量下载多种格式，无需逐个选择。

<Note>
  千问AI平台的收款主体为**阿里云计算有限公司**，与开票主体不同：千问AI平台部署模型的开票主体为**通义云启（杭州）信息技术有限公司**，三方直供模型的开票主体为对应的**第三方模型供应商**。如开票主体为通义云启且需要报销，可下载[关联公司证明文件（PDF）](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20240508/bvrddx/20240507124843.pdf)作为佐证材料。
</Note>

## 查看和管理发票

在**开票记录**页面可查看所有申请历史及当前状态：

| 状态  | 说明      | 可执行操作               |
| --- | ------- | ------------------- |
| 开票中 | 正在处理    | 可取消申请               |
| 已开票 | 已成功开具   | 下载（PDF / OFD / XML） |
| 已作废 | 申请已取消   | —                   |
| 退票中 | 退票申请处理中 | —                   |
| 已红冲 | 发票已冲销   | —                   |

## 退票与红冲

若需撤销已开具的发票（如信息有误），可申请退票。退票成功后，对应发票将被红冲（状态变为"已红冲"），可开票金额相应恢复。

## 常见问题

### 个人用户能否开具企业抬头的发票？

可以。个人用户可以开具企业普通发票和企业增值税专用发票，但条件不同：

- **企业普通发票**：在发票抬头页面填写企业名称即可直接申请，无需提交审核材料。
- **企业增值税专用发票**：需提交加盖公章的纸质协议，审批通过后方可申请。

### 充值金额能否开票？

不能。充值余额属于预付资金，尚未产生消耗，不符合开票条件。只有实际消费后产生的金额才可开票。

### 发生退款后，原发票如何处理？

退款金额会产生"欠票"，从下次可开票金额中优先扣除。如欠票金额较大导致可开票金额为负，将暂停新发票申请，直至欠票清零。

### 企业用户能否开具与认证主体不同的发票？

不能。企业用户只能开具与实名认证一致的企业抬头发票。如需更改开票抬头，请先完成企业实名认证变更。

### 为什么收款方是阿里云计算有限公司，开票主体却不是阿里云？

为方便客户付款，阿里云以阿里云计算有限公司提供专属账户代为收款。实际开票主体因消费的商品类型而不同：千问AI平台部署模型由通义云启（杭州）信息技术有限公司开具，三方直供模型由对应的第三方模型供应商开具。如开票主体为通义云启且发现开票主体与收款主体不一致，可下载[关联公司证明文件（PDF）](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20240508/bvrddx/20240507124843.pdf)辅助财务报销。

### 千问AI平台的发票抬头和阿里云官网是共用的吗？

不是。千问AI平台与阿里云官网的发票抬头各自独立管理，两边的配置互不影响。

### 企业信息变更后如何修改发票抬头？

需先完成千问AI平台账号的企业实名认证变更，再同步更新发票抬头。

### 如何修改发票接收邮箱？

前往发票抬头页面修改接收邮箱并保存即可。
