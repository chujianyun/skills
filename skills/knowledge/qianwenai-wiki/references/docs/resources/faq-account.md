# 账号与访问

> API Key、权限、访问相关常见问题

## 账号登录

### 千问AI平台支持哪些登录方式？

千问AI平台账号即阿里云账号，无需单独注册。支持以下登录方式：

- **手机号 + 验证码**：输入手机号，接收短信验证码登录。如果该手机号尚未关联阿里云账号，将自动注册新账号。
- **账号密码**：使用阿里云账号名和密码登录。
- **支付宝扫码**：使用支付宝 App 扫码授权登录。

<Note>
  仅支持阿里云主账号登录，不支持 RAM 子账号。
</Note>

### 手机号登录时提示多个账号怎么办？

如果您的手机号关联了多个阿里云账号，系统会在登录页面内显示账号选择列表。选择您需要登录的账号即可。您也可以在列表底部点击"创建新账号"。

### 首次登录需要做什么？

首次登录千问AI平台（包括新注册用户和已有阿里云账号但从未登录过千问AI平台的用户），需要阅读并同意《千问AI平台服务协议》和《隐私政策》，之后即可进入控制台。

### 如何设置或更新手机号？

前往[账号](https://platform.qianwenai.com/home/settings/account)页面，找到**手机号**部分，根据提示完成操作。

### 忘记密码怎么办？

在登录页面点击"忘记密码"，输入账号信息后验证身份，然后设置新密码。完成后将自动跳转到登录页面。

### 如何注销账号？

前往[账号](https://platform.qianwenai.com/home/settings/account)页面，点击**注销账号**。注销需要跳转到阿里云官网完成操作，注销后您将无法再登录千问AI平台与阿里云。

<Warning>
  注销账号后，您将无法继续使用相关服务。您的数据和个人信息将被永久删除，且无法恢复。
</Warning>

### 千问AI平台是否有手机端应用？

千问AI平台目前没有提供官方的独立手机应用，主要通过 Web 控制台访问。

## 实名认证

### 什么是实名认证？什么时候需要？

千问AI平台使用阿里云的实名认证体系。未认证用户无法购买付费服务。以下场景会触发实名认证引导：

- 点击购买模型服务时，系统会弹出认证引导。
- 控制台概览页的未认证提示条，点击后可直接发起认证。

<Note>
  如果您的阿里云账号已完成实名认证，千问AI平台会直接读取认证结果，无需再次操作。
</Note>

### 实名认证有哪些类型？

| 认证类型 | 认证方式  | 说明                                              |
| ---- | ----- | ----------------------------------------------- |
| 个人认证 | 支付宝授权 | 使用支付宝 App 扫码授权，系统自动获取身份信息，无需手动输入证件信息            |
| 企业认证 | 法人扫脸  | 填写企业信息后，法定代表人使用支付宝扫码完成人脸识别，支持转发二维码给法人操作         |
| 企业认证 | 银行卡收款 | 上传营业执照、填写对公账户信息，平台打入随机金额后填写到账金额完成验证，通常 1-7 个工作日 |

<Note>
  每个账号只能完成一种认证类型（个人或企业），认证完成后不可更改。个人认证可升级为企业认证，反之不可。
</Note>

## API Key

### 如何查看、创建或删除 API Key？

- **查看**：前往 [API Key](https://platform.qianwenai.com/home/api-keys) 页面，切换到目标业务空间即可查看。
- **创建**：切换到目标业务空间，点击**创建 API Key**，输入描述信息，点击**生成 API Key**。
- **删除**：切换到目标业务空间，选择目标 Key，点击**删除**。删除后无法恢复或继续使用。

### API 返回 `InvalidApiKey` / `API key invalid` 怎么办？

API Key 输入有误。可能原因：第三方工具兼容性问题或 API 端点填写错误。

### API 返回 `401-NOT AUTHORIZED` / 业务空间访问错误怎么办？

**可能原因**：

- WorkspaceId 无效，或您的账号不是该业务空间的成员。
- 请求中的端点（服务访问地址）不正确。

**解决方案**：

- 确认 WorkspaceId 正确，且您的账号是该业务空间的成员。

### 模型调用返回 `AccessDenied` / 权限不足怎么办？

检查 API、模型、服务或业务空间的访问授权。

## 业务空间

### 如何配置业务空间的模型权限？

前往[业务空间](https://platform.qianwenai.com/home/settings/workspaces)，找到目标子业务空间，点击**编辑**，在**模型权限**中配置可用模型及速率限制。

### 业务空间有数量限制吗？

每个千问AI平台账号最多 20 个业务空间（含 1 个默认业务空间）。

### 业务空间收费吗？

创建和管理业务空间免费。费用来自模型调用、训练、部署等资源使用。

### 如何隔离业务数据，避免不同用户的数据关联？

为不同用户分配不同的业务空间权限。业务空间之间相互隔离，数据无法跨业务空间访问。权限管理详见[业务空间](/developer-guides/administration/workspace)。

### 能否删除业务空间？

暂不支持删除业务空间。业务空间本身免费，如需停止计费，可使用具有 `Admin` 或 `API-Key` 权限的千问AI平台账号删除 API Key，并停止训练、部署等消耗资源的任务。

## 数据安全与隐私

### 数据是否安全？千问AI平台会用我的数据训练模型吗？

我们严格保护数据隐私，不会使用您的数据进行模型训练。应用构建和训练过程中传输的数据均已加密。

### 如何加密 API 调用以保护传输中的数据？

千问AI平台提供混合加密（AES 对称加密 + RSA 非对称加密）的模型推理加密方案。

### 如何通过内网访问千问AI平台？

创建 VPC 终端节点进行内网访问。所有流量在内网传输，不经过公网。

## 合规与权益

### 调用平台上的第三方模型是否构成侵权？

不构成侵权。平台上所有第三方模型均遵循合规的开源许可证。

### 如何获取将大模型应用发布到应用商店所需的材料？

请参阅平台合规文档。

### 内容安全如何确保输出合规？

大语言模型内置了合规检查机制。

### 如何为 AI 生成的内容（图片、视频）添加可见水印？

在 `parameters` 参数中设置 `"watermark": true`。具体用法请参阅对应模型的 API 文档。
