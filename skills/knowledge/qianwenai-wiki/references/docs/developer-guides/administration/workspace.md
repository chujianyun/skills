# 业务空间

> 管理模型权限、速率限制和 API Key

## 概述

业务空间是千问AI平台中管理资源、权限和计费的基本单元。每个业务空间拥有独立的：

- **API Key** 和用量上下文
- **模型访问权限**和模型级速率限制
- **用量配额**（API Key 数量等）

通过业务空间，您可以按项目、团队或环境（开发/测试/生产）隔离资源，并对每个空间进行精细化管控。

## 创建业务空间

<Steps>
  <Step title="进入业务空间页面">
    前往**设置** > [业务空间](https://platform.qianwenai.com/home/settings/workspaces)。
  </Step>

  <Step title="创建业务空间">
    点击**创建业务空间**，输入业务空间名称（最多 30 个字符），然后点击**提交**。
  </Step>
</Steps>

您的账号包含一个自动创建的默认业务空间。**创建业务空间**按钮上的计数器（例如 1/20）显示当前已创建数量和上限，达到上限后按钮将不可点击。

## 管理业务空间

在[业务空间](https://platform.qianwenai.com/home/settings/workspaces)页面，您可以查看所有业务空间的列表，包括名称、业务空间 ID 和创建日期。

- **搜索**：按名称或业务空间 ID 查找业务空间。
- **编辑**：点击业务空间旁的**编辑**，打开编辑面板。

业务空间列表中的状态标签含义：

| 标签     | 说明                                |
| ------ | --------------------------------- |
| **当前** | 当前活跃的业务空间，影响 API Key、用量分析等页面的数据范围 |
| **默认** | 账号默认业务空间，注册时自动创建，不可删除             |

## 编辑业务空间

点击任意业务空间的**编辑**按钮，打开编辑面板。

### 基本信息

- **业务空间名称**：重命名业务空间（最多 30 个字符）。
- **API Key 总数**：显示当前 API Key 数量及上限（例如 0/20），只读。

### 模型权限

控制该业务空间的 API Key 可调用哪些模型。默认业务空间可访问所有模型，使用账号级别的速率限制，不显示模型权限设置。如需自定义模型访问权限和速率限制，请创建子业务空间。

对于非默认业务空间：

1. 点击**全部模型**打开模型选择对话框。
2. 按模型名称搜索，或使用**模型厂商**和**模型类型**筛选。
3. 勾选要添加的模型，使用**全选当前结果**可批量选择当前页的所有模型。
4. 为每个模型设置速率限制：
   - **次/分钟**（RPM）：每分钟最大 API 请求数。
   - **Token/分钟**（TPM）：每分钟最大处理 Token 数。部分模型类型（如图像生成）不使用 Token 计量，可能不显示此字段。
5. 点击**选择 (N)** 确认，然后在面板上点击**提交**。

<Tip>
  模型选择对话框采用分页显示，切换页面时之前的选择可能不会保留。建议使用搜索和筛选缩小结果范围，或在每页选择后保存。
</Tip>

您设置的 RPM 和 TPM 值不能超过该模型的账号级别限制。可在[用量分析](https://platform.qianwenai.com/home/analytics)页面查看每个模型的当前限制。

## 切换业务空间

在[业务空间](https://platform.qianwenai.com/home/settings/workspaces)页面，使用**当前业务空间**下拉菜单选择目标业务空间。

切换业务空间后，API Key、用量分析等数据都会切换为所选业务空间的数据。

## API Key 与业务空间

每个 API Key 归属于一个业务空间。通过 API 调用模型时，所使用的 API Key 决定了哪个业务空间的模型访问权限和速率限制生效。

- 默认业务空间的 API Key 可调用所有可用模型。
- 子业务空间的 API Key 只能调用该业务空间已授权的模型。

要管理特定业务空间的 API Key，请先切换到该业务空间，然后前往 [API Key](https://platform.qianwenai.com/home/api-keys) 页面。

## 限制

| 资源                | 限制           |
| ----------------- | ------------ |
| 每个账号的业务空间数        | 20（包含默认业务空间） |
| 每个业务空间的 API Key 数 | 20           |
| 业务空间名称长度          | 30 个字符       |

默认业务空间自动创建，不可删除，但可以重命名。

## 常见问题

### 如何获取业务空间 ID？

前往[业务空间](https://platform.qianwenai.com/home/settings/workspaces)页面，**业务空间 ID** 列会显示对应的 ID。

### 如何从特定业务空间调用模型？

使用属于该业务空间的 API Key。API 调用时，API Key 决定了所使用的业务空间上下文。

### 如何限制团队可使用的模型？

为团队创建一个业务空间，点击**编辑**，然后在**模型权限**中只添加需要的模型。该业务空间中的所有 API Key 只能调用已授权的模型。

### 编辑面板中为什么没有模型权限？

您正在编辑默认业务空间。默认业务空间可访问所有模型，因此不显示模型权限设置。

### 能否删除默认业务空间？

不能。默认业务空间不可删除，但可以重命名。
