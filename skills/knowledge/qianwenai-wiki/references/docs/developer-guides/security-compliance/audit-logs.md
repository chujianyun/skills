# 审计与访问日志

> 追踪 API 使用情况，满足合规要求

千问AI平台通过用量分析和限流提额页面提供用量追踪功能，帮助您监控 API 消耗、排查异常并满足合规报告需求。

## 用量分析

[用量分析](https://platform.qianwenai.com/home/analytics)页面展示业务空间的汇总用量指标：

- **Token 消耗量**：输入和输出 Token 总量的变化趋势。
- **请求次数**：按模型和时间段统计的 API 调用量。
- **延迟**：平均响应时间。
- **成功率**：请求成功与失败的比例。

支持按时间范围和模型筛选，便于分析特定趋势。页面还展示各模型的运行指标，包括平均 TPM、平均 RPM、失败率等。

## 限流提额

[限流提额](https://platform.qianwenai.com/home/settings/rate-limit)页面用于管理频率限制提升申请和查看历史记录。
