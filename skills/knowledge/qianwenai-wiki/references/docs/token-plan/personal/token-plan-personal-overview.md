# Token Plan 个人版

> Token Plan 个人版是面向个人开发者的 AI 大模型订阅服务，以 Credits 统一计量，支持文本、多模态模型及 Harness 工具，适配主流 AI 编程和智能体工具。

## 核心特性

- **Credits 统一计量**：通过 Credits 统一抵扣不同模型和 Harness 工具的费用。
- **多模态模型支持**：覆盖文本生成、推理、视觉理解、图片生成、语音合成、实时语音对话、语音识别、视频生成等能力。
- **Harness 工具集成**：支持联网搜索、文搜图、图搜图、网页抓取、代码解释器。
- **限额重置**：使用限额重置权益，7天限额将立即刷新恢复。
- **加油包**：超出限额后可购买加油包，不受限制继续使用。
- **兼容多种工具**：适配 Claude Code、Cursor、Qwen Code、Qoder、Qoder CN、OpenClaw 等主流 AI 编程和智能体工具。

## Credits 计费机制

<Note>
  不同模型按分档抵扣系数计费，视频生成等多模态模型的单次消耗明显高于文本对话，使用时需重点关注以下两点：

  - **单次消耗高**：视频生成的 Credits 随时长和分辨率上升，可能在短时间内占用较多限额。建议首次使用时以较短时长、较低分辨率试跑，通过控制台订阅页用量详情确认单次实际消耗后，再决定后续用量。
  - **异步任务集中结算**：视频生成等异步任务的 Credits 在任务完成后统一结算，而非提交时立即扣除。短时间内提交多个异步任务时，集中结算的 Credits 可能导致限额快速触顶。
</Note>

### 计费说明

单次消耗的 Credits 由模型类型、Token 用量、思考模式及工具调用等动态决定，实际消耗以控制台订阅页用量详情为准。

### 抵扣顺序

1. 每次调用消耗的 Credits 计入每 7 天限额。
2. 限额触顶后，服务暂停，可使用限额重置权益立即刷新恢复额度，或购买加油包补充额度，或升级至更高档位套餐，或等待窗口周期结束后额度自动重置。

### 额度重置

可自主使用额度重置功能，将 7 天限额归零重新计算。额度重置后，当前窗口内已消耗的 Credits 清零，限额从零开始重新累计。

额度重置需消耗重置次数。2026 年 8 月 5 日前订阅的用户，将于 8 月 5 日起获发 1 次 7 天额度重置权益，可在权益有效期内按需使用。后续重置次数请关注官方公告或活动。

## 订阅管理

### 升级

支持从低档位升级到更高档位。前往 [Token Plan 个人版购买页面](https://platform.qianwenai.com/pricing/token-plan) 选择目标档位完成升级。升级按剩余时长补缴差价，升级后限额立即提升至新档位对应额度。

升级发放的 Credits 并非新档位的全额周期额度，而是按实付补差金额和当前订阅周期的实际剩余有效时长折算得出，折算公式如下：

```
折算 Credits = (升级总差额 / 30 天) x 实际剩余有效时长
```

例如：从 Lite 套餐升级到 Standard 套餐补缴差价 100 元，当前订阅周期剩余 15 天，则本次折算发放的 Credits 对应金额为 (100 / 30) x 15 = 50 元，而非新档位当期的全额 Credits。

### 续费

续费支持切换续费周期，也可一次续费多个周期。

- **手动续费**：支持选择不同续费时长，可续费多个周期。
- **自动续费**：开启后到期前系统自动扣款续费。

续费仅延长订阅有效期，不会叠加补充至当前计费周期的额度。

### 其他

- 个人版暂不支持退订。
- 订阅到期后重新购买，API Key 会发生变更，需在工具中重新配置。新 API Key 可在[控制台 Token Plan 管理页面](https://platform.qianwenai.com/home/billing/subscription/token-plan)的 API Key 区域获取。
