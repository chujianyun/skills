# Token Plan 团队版

> AI 大模型订阅服务

Token Plan 团队版是千问AI平台推出的 AI 大模型订阅服务，以 Credits 统一计量，支持文本生成、图像生成、视频生成、语音识别与实时语音对话模型，兼容主流 AI 编程与智能体工具，提供团队管理后台、数据安全保障，调用平稳运行。

## 产品简介

- **多模型灵活切换**：支持多模型按需切换，按 Credits 统一抵扣。
- **兼容多种工具**：控制台提供快速接入 AI 工具入口，支持 Qwen Code、Claude Code、Qoder、Qoder CN、OpenClaw 等工具接入。详见[配置 AI 工具](/token-plan/team/token-plan-team-quickstart#步骤三-配置-ai-工具)。
- **多档位套餐**：提供标准席位、高级席位、尊享席位多档位套餐，匹配不同使用强度。
- **团队管理**：提供管理后台，支持席位分配与回收、成员用量分析等团队管理能力。
- **预算可控**：支持按月或按年订阅，预算可控。
- **数据安全**：承诺不使用对话数据进行模型训练，满足企业级数据隐私要求。
- **平稳运行**：多租户隔离架构，调用高峰期间不排队。

Token Plan 团队版提供套餐专属 Base URL，兼容 OpenAI、Anthropic 接口标准，具体地址可在控制台**API Key**页面查看，详见[获取 API Key 与 Base URL](/token-plan/team/token-plan-team-quickstart#步骤二-获取-api-key-与-base-url)。

## 订阅管理

在 [Token Plan 管理](https://platform.qianwenai.com/home/billing/subscription/token-plan) 页面，可对团队版订阅进行以下操作：

- **增购席位**：点击**增购席位**，选择席位类型和数量。新增席位与现有订阅统一到期，费用按剩余时长折算。
- **升级席位**：在用量详情的席位列表中，点击对应席位的**升级**，将低档位席位升级为高档位，按差价补缴费用。升级新增的 Credits 额度同步按剩余时长折算后发放，实际可用额度以控制台展示为准。
- **退订席位**：在席位列表中，点击席位的**退席位**进行退订。已有用量消耗的席位不可退订。退款原路退回支付账户。
- **续费**：点击**续费**，续费周期与订阅时一致（按月订阅则按月续费）。到期前完成续费可避免服务中断。续费仅延长订阅有效期，不会叠加补充至当前计费周期的额度。
- **自动续费**：开启**自动续费**开关，到期前系统自动扣款续费。
- **购买加油包**：在加油包区域点击**购买加油包**，每个加油包有效期为 1 个月。

<Note>
  团队版与个人版可同时持有，各自独立计费。
</Note>

## Credits 计费机制

### 计费说明

单次请求消耗的 Credits **并非固定值**，由模型类型、Token 用量、思考模式及工具调用等动态决定。其中 Token 用量会随多轮对话累积的上下文（历史消息、代码、工具返回、检索内容等）持续增长，且部分模型按**上下文长度阶梯计费**（上下文越长，单价档位可能越高），因此同一模型在不同请求下的消耗可能相差较大。实际消耗以[账单](https://platform.qianwenai.com/home/billing/subscription/token-plan)为准。

### 计算示例

以 qwen3.6-plus 为例，预估单次请求消耗明细如下（不同模型的单价不同，实际以账单为准）：

| Token 类型  | 数量     | 消耗 Credits         |
| --------- | ------ | ------------------ |
| 输入 tokens | 8,349  | 1.67               |
| 缓存 tokens | 40,794 | 0.82               |
| 输出 tokens | 573    | 0.69               |
| **合计**    |        | **约 3.18 Credits** |

<Note>
  上表仅为单次请求的示例，并不代表每次请求都固定消耗约 3 Credits。在 AI 编程、智能体等多轮对话场景中，每次请求都会携带累积的上下文（历史对话、代码、工具返回等），随着对话进行输入 Token 持续增多，单次消耗的 Credits 也会相应上升；若模型按上下文长度阶梯计费，长上下文可能进入更高价位档，消耗速度进一步加快。

  如需控制消耗，建议：任务切换或话题变更时及时开启新会话、清理无关历史，以缩短上下文；对长文档、大代码库按需拆分输入；并在下方[查看额度消耗情况](#查看额度消耗情况)中关注各模型的实时消耗趋势。
</Note>

### 抵扣顺序

1. 优先从席位套餐的月度额度中抵扣。
2. 席位额度用尽后，从加油包中抵扣。持有多个加油包时，优先抵扣最近到期的用量包。
3. 全部额度用尽后，服务将暂停至下一计费周期或购买加油包补充额度。

### 查看额度消耗情况

登录千问AI平台控制台，进入 [Token Plan 管理](https://platform.qianwenai.com/home/billing/subscription/token-plan) 页面，即可查看当前套餐的状态、到期时间、Credits 剩余量和总量。

页面下方的**用量详情**区域支持按以下维度查看用量：

| 分组   | 说明                                                  |
| ---- | --------------------------------------------------- |
| 套餐   | 按席位查看各席位的 Credits 剩余量、分配状态和分配人员                     |
| 成员   | 按成员查看每位成员的 Credits 消耗情况                             |
| 模型   | 按模型查看各模型的 Credits 消耗分布                              |
| 使用明细 | 逐条记录的详细用量，含成员、模型、原始用量、转换系数、Credits 消耗、席位/加油包 ID 等字段 |

支持按套餐类型、时间范围筛选，并可导出数据。

### 查看成员消耗明细

在 [Token Plan 管理平台](https://tokenplan-enterprise.qianwenai.com/organization/usage)的**组织用量**页面，可查看用量趋势、各模型消耗，以及每个成员的 Credits 消耗明细。席位分配、SSO 配置、成员管理等完整功能仍在管理平台操作。详见[团队管理](/token-plan/team/team-management)。

## 使用细则

1. **使用范围**：仅限在兼容的 AI 编程和智能体工具中交互式使用，不可用于自动化脚本或应用后端。违规使用可能导致订阅暂停或 API Key 封禁。
2. **数据安全**：Token Plan 团队版不会使用对话数据训练模型。
3. **账号规范**：API Key 仅限已分配席位的成员本人使用，不可共享或公开泄露。
4. **服务地域**：Token Plan 团队版目前仅在特定地域提供服务，如需从海外调用，请确认符合当地法律法规要求。
5. **退订重购**：退订重购后，API Key 和 Base URL 会发生变更，需在工具中重新配置。新 API Key 和 Base URL 均可在控制台[**我的订阅**](https://platform.qianwenai.com/home/billing/subscription/token-plan)页面的 API Key 区域获取。
